🎬 THE REAL-WORLD STORY

Imagine two people standing at opposite ends of a long hallway looking for a pair of numbers that add up to a target sum.

💡 THE TWO POINTERS AHA
If the array is sorted, comparing `arr[left] + arr[right]` tells us EXACTLY which pointer to move! If sum is too small → `left++`. If sum is too large → `right--`. Replaces O(N²) loops with O(N) single pass!
🤔 WHY NOT NESTED LOOPS?
  • Nested Loops O(N²): Checks every pair `(i, j)`. For N = 100,000 → 10,000,000,000 operations → TLE!
  • Two Pointers O(N): Moves inward deterministically. Total steps ≤ N. Executes in < 5ms!
  • Auxiliary Space O(1): Reuses array pointers with 0 extra memory allocation.
📌 3 MAIN POINTER VARIATIONS
1. Opposite Direction (Converging):
left -> [ 1,  2,  4,  6,  8, 11 ] <- right
Sum = 1 + 11 = 12 > Target 10 → right--
Sum = 1 + 8  = 9  < Target 10 → left++
2. Same Direction (Fast & Slow):
[ slow, fast -> ] (In-place array modification)

1 TEMPLATE A: OPPOSITE DIRECTION
public int[] twoSumSorted(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left < right) {
        int sum = nums[left] + nums[right];

        if (sum == target) {
            return new int[]{left + 1, right + 1}; // 1-indexed
        } else if (sum < target) {
            left++;  // Need larger value
        } else {
            right--; // Need smaller value
        }
    }
    return new int[0];
}
2 TEMPLATE B: FAST & SLOW
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;

    int slow = 0; // Points to last unique element

    for (int fast = 1; fast < nums.length; fast++) {
        // When we find a new element, move slow forward
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast]; // Overwrite in-place!
        }
    }
    return slow + 1; // Number of unique elements
}

⚡ 5-STEP TWO POINTERS THINKING FRAMEWORK
  1. Is the array sorted? If not, can we sort it? (Cost O(N log N))
  2. What's the condition? Sum too small/large? Duplicate? Height?
  3. Which direction? Opposite (converging) or Same (fast/slow)?
  4. How to move pointers? `left++`, `right--`, or both?
  5. Dry run with small example: Step line-by-step to verify logic.

PATTERN 1 — VALID PALINDROME LC 125 · EASY
When to Use: Check symmetry from ends inward, skipping non-alphanumeric characters.
Input: "A man, a plan, a canal: Panama"
Output: true
💡 AHA
Converge pointers inward. Skip non-alphanumeric chars. Compare characters (case-insensitive)! 
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        // Skip non-alphanumeric from left
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        // Skip non-alphanumeric from right
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }

        // Compare characters (case-insensitive)
        if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
            return false;
        }

        left++;
        right--;
    }
    return true;
}
PATTERN 2 — TWO SUM II (SORTED) LC 167 · EASY
When to Use: Array is ALREADY sorted. Find target sum in O(N) time.
Input: numbers=[2,7,11,15], target=9
Output: [1,2] (1-indexed)
💡 AHA
`left++` if sum small, `right--` if large. Since sorted, this is the only correct move! 
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;

    while (left < right) {
        int sum = numbers[left] + numbers[right];

        if (sum == target) {
            return new int[]{left + 1, right + 1}; // 1-indexed
        } else if (sum < target) {
            left++; // Need larger sum → move left right
        } else {
            right--; // Need smaller sum → move right left
        }
    }
    return new int[0];
}

Input: [1,1,2]
Output: 2 (array becomes [1,2,_])

`slow` tracks last unique position. `fast` scans ahead. When new value found, move `slow++` and copy! 
public int removeDuplicates(int[] nums) {

PATTERN 4 — 3SUM LC 15 · MEDIUM
When to Use: Find all unique triplets summing to zero in O(N²).
Input: [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
💡 AHA
Sort → Fix outer pointer `i` → Use two pointers for remaining array. Skip duplicates on all 3 pointers! 
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums); // Sort first!
    List<List<Integer>> res = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        // Skip duplicate i
        if (i > 0 && nums[i] == nums[i - 1]) continue;

        int left = i + 1, right = nums.length - 1;

        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));

                // Skip duplicate left and right
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;

                left++;
                right--;
            } else if (sum < 0) {
                left++; // Need larger sum
            } else {
                right--; // Need smaller sum
            }
        }
    }
    return res;
}
PATTERN 5 — CONTAINER WITH MOST WATER LC 11 · MEDIUM
When to Use: Find max area between two vertical lines.
Input: [1,8,6,2,5,4,8,3,7]
Output: 49
💡 AHA
Area = min(height[left], height[right]) × width. Moving the taller wall CANNOT increase area because height is capped by the shorter wall. Always move the shorter wall! 
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;

    while (left < right) {
        // Calculate current area
        int h = Math.min(height[left], height[right]);
        int width = right - left;
        maxWater = Math.max(maxWater, h * width);

        // Move the pointer with the shorter wall
        if (height[left] < height[right]) {
            left++; // Shorter wall is left → move left
        } else {
            right--; // Shorter wall is right → move right
        }
    }
    return maxWater;
}
PATTERN 6 — TRAPPING RAIN WATER LC 42 · HARD
When to Use: Calculate trapped water between walls.
Input: [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
💡 AHA
Maintain `leftMax` and `rightMax`. Water trapped at a position = min(leftMax, rightMax) - height[pos]. Compare `leftMax` and `rightMax` to decide which side to process! 
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        if (height[left] < height[right]) {
            // Left side is limiting
            if (height[left] >= leftMax) {
                leftMax = height[left]; // Update max
            } else {
                water += leftMax - height[left]; // Water trapped
            }
            left++;
        } else {
            // Right side is limiting
            if (height[right] >= rightMax) {
                rightMax = height[right]; // Update max
            } else {
                water += rightMax - height[right]; // Water trapped
            }
            right--;
        }
    }
    return water;
}

PATTERN 7 — 3SUM CLOSEST LC 16 · MEDIUM
When to Use: Find triplet sum closest to target.
Input: [-1,2,1,-4], target=1
Output: 2 (-1+2+1=2)
💡 AHA
Sort → Fix outer pointer → Two pointers for remainder. Track minimum absolute difference! 
public int threeSumClosest(int[] nums, int target) {
    Arrays.sort(nums);
    int closest = nums[0] + nums[1] + nums[2];

    for (int i = 0; i < nums.length - 2; i++) {
        int left = i + 1, right = nums.length - 1;

        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];

            // Update closest if better
            if (Math.abs(target - sum) < Math.abs(target - closest)) {
                closest = sum;
            }

            if (sum < target) {
                left++; // Need larger sum
            } else {
                right--; // Need smaller sum
            }
        }
    }
    return closest;
}
PATTERN 8 — MOVE ZEROES LC 283 · EASY
When to Use: Move all zeroes to end while preserving order.
Input: [0,1,0,3,12]
Output: [1,3,12,0,0]
💡 AHA
`slow` tracks position for next non-zero. `fast` scans. Swap when non-zero found! 
public void moveZeroes(int[] nums) {
    int slow = 0; // Position to place next non-zero

    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            // Swap non-zero with position at slow
            int temp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = temp;
            slow++;
        }
    }
}

⭐ LC 344 · Reverse String EASY
Input: ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
Pattern: Opposite Pointers
💡 AHA
Swap characters at left and right, then move inward. The simplest two-pointer pattern! 
public void reverseString(char[] s) {
    int left = 0, right = s.length - 1;

    while (left < right) {
        // Swap characters
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;

        left++;
        right--;
    }
}
⭐ LC 345 · Reverse Vowels EASY
Input: "hello"
Output: "holle"
Pattern: Opposite Pointers + Skip Logic
💡 AHA
Skip non-vowels from both ends. When both are vowels, swap and move inward! 
public String reverseVowels(String s) {
    char[] chars = s.toCharArray();
    int left = 0, right = chars.length - 1;
    String vowels = "aeiouAEIOU";

    while (left < right) {
        // Skip non-vowels from left
        while (left < right && !vowels.contains(String.valueOf(chars[left]))) {
            left++;
        }
        // Skip non-vowels from right
        while (left < right && !vowels.contains(String.valueOf(chars[right]))) {
            right--;
        }

        // Swap vowels
        char temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;

        left++;
        right--;
    }
    return new String(chars);
}
⭐ LC 977 · Squares of a Sorted Array EASY
Input: [-4,-1,0,3,10]
Output: [0,1,9,16,100]
Pattern: Opposite Pointers + Fill from End
💡 AHA
Compare absolute values at left and right. The larger square goes to the end of result array. Fill from right to left! 
public int[] sortedSquares(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    int left = 0, right = n - 1;

    // Fill from the end because largest squares are at ends
    for (int i = n - 1; i >= 0; i--) {
        int leftSquare = nums[left] * nums[left];
        int rightSquare = nums[right] * nums[right];

        if (leftSquare > rightSquare) {
            result[i] = leftSquare;
            left++;
        } else {
            result[i] = rightSquare;
            right--;
        }
    }
    return result;
}

Rule 1 — For 3Sum / 4Sum, Sort First
Sorting costs O(N log N) but enables O(N²) 2-pointer scan and avoids complex hash set duplicates.
Rule 2 — Guard Against Out-of-Bounds
When skipping duplicates inside while loops, ALWAYS include `while (l < r && nums[l] == nums[l + 1]) l++` to prevent index out of bounds!
Rule 3 — Move the Shorter Wall for Water
In Container With Most Water, moving the taller wall cannot increase area. ALWAYS move the shorter wall pointer!
