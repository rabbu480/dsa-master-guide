# ARRAYS & HASHING – PATTERNS CHEAT SHEET
Core Patterns, When to Use, Key Ideas & Common Formulas

## 1 DUPLICATE DETECTION (HashSet)

**When to use**
* Find if any element appears more than once.

**Key Idea**
* Insert into set, if already present → duplicate.

**How it Works / Formula / Code**
```java
Set<Integer> set = new HashSet<>();
for (int x : nums) {
    if (set.contains(x)) return true;
    set.add(x);
}
return false;
```

**Example**
Input: `[1, 2, 3, 1]`
Output: `true`

Visual:
Array `1`, `2`, `3`, `1` with an arrow pointing to the second `1` labeled `duplicate`

**Complexity**
Time: O(n) | Space: O(n)

---

## 2 FREQUENCY COUNTING (HashMap / int[26])

**When to use**
* Count occurrences of elements.

**Key Idea**
* Map each element → its frequency.

**How it Works / Formula / Code**
**A) HashMap (any values)**
```java
Map<Integer, Integer> map = new HashMap<>();
for (int x : nums) {
    map.put(x, map.getOrDefault(x, 0) + 1);
}
```

**B) Frequency Array (only for small range e.g. a-z)**
```java
int[] freq = new int[26];
for (char c : s.toCharArray()) {
    freq[c - 'a']++;
}
```

**Example**
Input: `[1, 2, 2, 3, 3, 3]`
Output: `1→1, 2→2, 3→3`

| Num | Freq |
|---|---|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |

**Complexity**
Time: O(n) | Space: O(n)

---

## 3 COMPLEMENT / PAIR SEARCH (HashMap)

**When to use**
* Find pair with given sum / target.

**Key Idea**
* For each x, check if `(target - x)` exists in map.

**How it Works / Formula / Code**
```java
Map<Integer, Integer> map = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int complement = target - nums[i];
    if (map.containsKey(complement))
        return new int[]{map.get(complement), i};
    map.put(nums[i], i);
}
return new int[]{};
```

**Example**
Input: `nums=[2,7,11,15]`, target=9
Output: `[0,1]`

| Idx | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| | 2 | 7 | 11 | 15 |

9 - 2 = 7
found at idx 1

**Complexity**
Time: O(n) | Space: O(n)

---

## 4 GROUPING / BUCKETING (HashMap<Key, List>)

**When to use**
* Group elements by key (e.g., anagrams, indices, values).

**Key Idea**
* Map key → list of elements.

**How it Works / Formula / Code**
```java
Map<String, List<String>> map = new HashMap<>();
for (String s : strs) {
    String key = ...; // e.g. sorted string
    map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}
```

**Example (Group Anagrams)**
Input: `["eat", "tea", "tan", "ate", "nat", "bat"]`
Output: `[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]`

Visual mapping:
* `[eat, ate]` → `key: aet`
* `[tan, nat]` → `key: ant`
* `[bat]` → `key: bat`

**Complexity**
Time: O(n * k log k) | Space: O(n * k)
*(n = #strings, k = avg length)*

## 5 ENCODING / DECODING STRINGS (StringBuilder)

**When to use**
* Store and retrieve list of strings in single string.

**Key Idea**
* Prefix each string with its length.

**How it Works / Formula / Code**
**Encode:**
```java
for (String s : strs)
    sb.append(s.length()).append('#').append(s);
```
**Decode:**
Read number until '#', then next that many chars is the string.

**Example**
Input: `["we", "love", "leetcode"]`
Encode: `"2#we4#love8#leetcode"`
Decode: `["we", "love", "leetcode"]`

Visual mapping:
`2#we4#love8#leetcode`

**Complexity**
Time: O(n) | Space: O(n)

## 6 PREFIX / SUFFIX PATTERNS (Arrays)

**When to use**
* Product except self, prefix sums, suffix sums, etc.

**Key Idea**
* Precompute left and right contributions.

**How it Works / Formula / Code (Product Except Self)**
```
left[i] = product of all nums [0 ... i-1]
right[i] = product of all nums [i+1 ... n-1]
ans[i] = left[i] * right[i]
```

```java
int n = nums.length;
int[] left = new int[n];
int[] right = new int[n];
int[] ans = new int[n];
left[0] = 1;
for (int i = 1; i < n; i++) left[i] = left[i-1] * nums[i-1];
right[n-1] = 1;
for (int i = n-2; i >= 0; i--) right[i] = right[i+1] * nums[i+1];
for (int i = 0; i < n; i++) ans[i] = left[i] * right[i];
```

**Example**
`nums = [1,2,3,4]`
`ans = [24,12,8,6]`

| i | nums | left | right | ans |
|---|---|---|---|---|
| 0 | 1 | 1 | 24 | 24 |
| 1 | 2 | 1 | 12 | 12 |
| 2 | 3 | 2 | 4 | 8 |
| 3 | 4 | 6 | 1 | 6 |

**Complexity**
Time: O(n) | Space: O(n)

## 7 LONGEST CONSECUTIVE SEQUENCE (HashSet)

**When to use**
* Find length of longest consecutive elements.

**Key Idea**
* Only start counting from the first element of a sequence (i.e., num-1 not present).

**How it Works / Formula / Code**
```java
Set<Integer> set = new HashSet<>();
for (int x : nums) set.add(x);
int longest = 0;
for (int x : set) {
    if (!set.contains(x - 1)) { // start
        int count = 1, cur = x;
        while (set.contains(cur + 1)) {
            cur++; count++;
        }
        longest = Math.max(longest, count);
    }
}
return longest;
```

**Example**
Input: `[100,4,200,1,3,2]`
Output: `4`
`(1,2,3,4)`

Visual mapping:
Boxes array: `100`, `4`, `200`, `1`, `3`, `2`
Sequence: `1`, `2`, `3`, `4`
`length = 4`

**Complexity**
Time: O(n) | Space: O(n)

## 8 MATRIX VALIDATION (SUDOKU) (HashSet (Rows, Cols, Boxes))

**When to use**
* Validate Sudoku board.

**Key Idea**
* No duplicates in rows, columns and 3x3 boxes.

**How it Works**
1. Check each row using set
2. Check each column using set
3. Check each 3x3 box using set

**3x3 Box Traversal**
```java
for (int r = 0; r < 9; r += 3)
    for (int c = 0; c < 9; c += 3)
        for (int i = r; i < r + 3; i++)
            for (int j = c; j < c + 3; j++)
                validate(board[i][j]);
```

**Visual - 3x3 Boxes**
| (0,0) | (0,3) | (0,6) |
|---|---|---|
| (3,0) | (3,3) | (3,6) |
| (6,0) | (6,3) | (6,6) |

**Complexity**
Time: O(9*9) = O(1) | Space: O(1)

## WHEN TO USE WHAT?
* **HashSet**: Fast lookup, duplicates, membership
* **HashMap**: Counts, mapping, complement search, grouping, index mapping
* **Frequency Array**: Small fixed range (e.g., a-z, 0-26)
* **Sorting**: Order matters, two pointers after sort, grouping
* **Heap / PQ**: Top K frequent, K largest/smallest
* **Arrays**: Prefix/Suffix, sliding window, simulation

## COMMON HASHING FORMULAS / TRICKS
* **Get or Insert**: `map.getOrDefault(key, 0) + 1`
* **Insert List**: `map.computeIfAbsent(key, k -> new ArrayList<>()).add(val)`
* **Check Key**: `map.containsKey(key)`
* **Check Value in Set**: `set.contains(val)`
* **Remove Key**: `map.remove(key)`
* **Iterate Entries**: `for (Map.Entry<K,V> e : map.entrySet())`
* **Convert Values to List**: `new ArrayList<>(map.values())`
* **Sort Map by Value**:
```java
map.entrySet().stream()
    .sorted((a,b) -> b.getValue() - a.getValue())
    .collect(Collectors.toList());
```

## CHAR / ASCII TRICKS
* **char to index**: `c - 'a'` // 0 to 25
* **index to char**: `(char)('a' + i)`
* **char to int digit**: `c - '0'`
* **int to char digit**: `(char)('0' + x)`
* **Uppercase**: `c - 'A'` // 0 to 25

### FREQUENCY ARRAY TEMPLATE (a-z)
```java
int[] freq = new int[26];
for (char c : s.toCharArray())
    freq[c - 'a']++;
```

## TIME COMPLEXITY QUICK GUIDE (Average Case)
| Operation | HashSet | HashMap |
|---|---|---|
| Add / Put | O(1) | O(1) |
| Remove | O(1) | O(1) |
| Contains / Get | O(1) | O(1) |
| Iterate All | O(n) | O(n) |

### IMPORTANT NOTES
* Hashing gives O(1) average lookup but O(n) worst case (rare with good hash function).
* Choose the right pattern - it saves time and code.
* Think: Can I transform this into a lookup problem?

---
**Golden Rule:** Understand the Pattern → Choose the Right Data Structure → Code Clean → Analyze Complexity → Optimize if Needed
