## 1 ALGORITHM DECISION TREE (How to choose the right algorithm)
- **Start With Problem**
  - **Is it a Graph Problem?**
    - **NO** -> Use other DS (Array, Tree, String...)
    - **YES** -> **Do edges have weights?**
      - **NO**
        - **Need shortest path?**
          - **YES** -> **BFS (Unweighted)**
          - **NO**
            - **Need ordering / sequence?**
              - **YES** -> **Topological Sort (DAG only)**
              - **NO**
                - **Need connectivity / components?**
                  - **YES** -> **Union Find (DSU) (Connectivity / Merge)**
                  - **NO**
                    - **Explore all nodes / components?**
                      - **YES** -> **DFS / BFS (Traversal / Components)**
                      - **NO** -> **Re-evaluate Problem Constraints**
      - **YES**
        - **Need shortest path?**
          - **YES** -> **Dijkstra (Positive Weights)**
          - **NO** -> **Topological Sort (DAG with weights)**

💡 Golden Rule: Understand the problem 80%, thinking 15%, coding only 5%.

## 3 REPRESENTATION SELECTION GUIDE
- **Is graph dense? (E ≈ V²)**
  - **YES** -> Use Adjacency Matrix (Better for dense graphs)
  - **NO**
    - **Need fast edge existence check (u,v) frequently?**
      - **YES** -> Use Adjacency Matrix (O(1) check)
      - **NO**
        - **Iterate neighbors of a node often?**
          - **YES** -> Use Adjacency List (Better iteration)
          - **NO**
            - **Default Choice** -> Adjacency List (Space efficient & flexible)

## 4 HELPER STRUCTURE SELECTION
| IF YOU NEED TO... | USE | WHY? |
| --- | --- | --- |
| Traverse all nodes deeply | Stack / Recursion | DFS, Backtracking |
| Traverse level by level | Queue (FIFO) | BFS, Level order |
| Get minimum quickly | Priority Queue (Min Heap) | Dijkstra, Prim's MST |
| Group / Merge components | Union Find (DSU) | Efficient connectivity |
| Store visited nodes | Visited Array / Set | Avoid cycles / repeats |
| Store parent / path | Parent Array / Map | Reconstruction |
| Store distances | Distance Array / Map | Shortest path |
| Store indegree | Array / Map | Topological Sort |

## 5 ALGORITHM CHOOSER AT A GLANCE

### DFS (Depth First Search)
- **USE WHEN**
  - Explore all nodes
  - Find components
  - Backtracking
  - Cycle detection (directed)
  - Topological Sort (DFS)
- **TIME**: O(V + E)
- **SPACE**: O(V) Recursion

### BFS (Breadth First Search)
- **USE WHEN**
  - Shortest path (unweighted)
  - Level order traversal
  - Minimum steps / levels
  - Find components
- **TIME**: O(V + E)
- **SPACE**: O(V) Queue

### TOPOLOGICAL SORT (Kahn's BFS / DFS)
- **USE WHEN**
  - DAG ordering
  - Course schedule
  - Build order
  - Task dependencies
- **TIME**: O(V + E)
- **SPACE**: O(V)

### DIJKSTRA (Min Heap)
- **USE WHEN**
  - Shortest path
  - Weighted graph
  - Positive weights
  - Single source
- **TIME**: O((V + E) log V)
- **SPACE**: O(V)

### UNION FIND (DSU) (Disjoint Set Union)
- **USE WHEN**
  - Connectivity check
  - Components count
  - Merge groups
  - Dynamic connectivity
- **TIME**: O(α(V)) per op
- **SPACE**: O(V)

### GRID DFS / BFS (Matrix Problems)
- **USE WHEN**
  - Islands / regions
  - Flood fill
  - Surrounded regions
  - Shortest path in grid
- **TIME**: O(M * N)
- **SPACE**: O(M * N)

## 6 FAANG GRAPH SOLVING PIPELINE (Follow this every time)

7. **OPTIMIZE & FINALIZE**
   - Check complexity
   - Optimize if needed
   - Submit with confidence

## 7 KEY NOTATIONS
- **V** = Number of Vertices (Nodes)
- **E** = Number of Edges
- **O(V)** = Linear in vertices
- **O(E)** = Linear in edges
- **α(V)** = Inverse Ackermann (≈ constant)

## 8 COMPLEXITY SNAPSHOT
| Algorithm | Time Complexity | Space Complexity |
| --- | --- | --- |
| DFS | O(V + E) | O(V) |
| BFS | O(V + E) | O(V) |
| Topo Sort (Kahn's BFS) | O(V + E) | O(V) |
| Topo Sort (DFS) | O(V + E) | O(V) |
| Dijkstra (Min Heap) | O((V + E) log V) | O(V) |
| Union Find (DSU) | O(α(V)) per op | O(V) |
| Grid DFS / BFS | O(M * N) | O(M * N) |

## 9 BIGGEST INTERVIEW PITFALLS
- ❌ Not marking visited → infinite loop
- ❌ Wrong data structure (Stack vs Queue vs PQ)
- ❌ Index out of bounds in grid
- ❌ Forgetting disconnected components
- ❌ Ignoring edge direction in directed graph
- ❌ Topo sort: not all nodes processed (cycle)
- ❌ Dijkstra with negative weights
- ❌ Union Find without path compression / rank
- ❌ Modifying list while iterating
