# Visual Layout Specification: Graph BFS Problem Guide (Page 7)

## 1. Overall Page Structure
- **Grid System:** The page is structured using a flexible grid system, primarily divided into a header, a top informational section (2 columns), a main content area (3 equal columns), a lower reference section (3 columns), and a bottom flowchart section (full width).
- **Color Palette:**
  - **Primary Accents:** Dark Blue (`#002060` approx) for main titles and headers.
  - **Secondary Accents:** Purple, Green, Orange, and Red used for categorization and badges.
  - **Background:** White background with light gray borders for panels.

## 2. Header Section
- **Top Left Badge:** A rectangular dark blue block with white text "PAGE 7".
- **Main Title:** Centered, large, bold dark blue text "GRAPH PATTERN GUIDE" next to an open book icon.
- **Subtitles:** Below the main title, "PAGE 7 - GRAPH BFS PROBLEM GUIDE (APPLY TEMPLATES)" in dark blue.
- **Tagline:** Centered, italicized dark blue text below the subtitle.

## 3. Top Informational Section (2 Columns)
- **Left Column (approx. 35% width):** "HOW TO USE THIS PAGE"
  - **Header:** Dark blue background, white text, centered.
  - **Content:** Numbered list with purple circled numbers (1 to 6).
- **Right Column (approx. 65% width):** "TEMPLATE LEGEND (From Page 6)"
  - **Header:** Dark blue background, white text, centered.
  - **Content:** A horizontal flex layout containing 5 legend items. Each item consists of a colored square badge and black text.
    - **Gb:** Dark Blue
    - **Gr:** Green
    - **Ms:** Orange
    - **Lv:** Purple
    - **Ds:** Red

## 4. Main Content Area (3-Column Grid)
- **Layout:** A 3-column by 2-row grid displaying 6 problem panels.
- **Problem Panel Structure (applies to all 6 panels):**
  - **Panel Header:**
    - **Left:** Dark green/blue square badge with the problem number (1-6).
    - **Center/Left:** Problem title in bold, colored text (colors vary: green, red, dark blue).
    - **Right:** A colored square badge (e.g., Ms, Gb, Gr, Ds) corresponding to the template legend.
  - **Sub-header:** Centered text indicating the "Base Template".
  - **Sections:** "Problem" and "Changed Lines (from Template)" in bold black text.
  - **Code Block:** Monospace font for code, utilizing syntax highlighting (blue for keywords, green for comments, black for variables).
  - **Summary Table:** A 4-column borderless table with column headers: "Caller", "Return", "Visited", "Key Idea". Light gray dividing lines.
  - **AHA Section:** A light yellow highlighted row starting with a lightbulb "AHA" icon, followed by bold text.
  - **Footer (2 Columns):** "Complexity" on the left and "Interview Tip" on the right, both with bold headers and normal text underneath.
- **Borders:** Each panel is enclosed in a thin light gray border.

## 5. Lower Reference Section (3 Columns)
- **Layout:** 3 unequal columns.
- **Column 1 (approx. 40% width):** "7 CHANGED LINES SUMMARY (QUICK REFERENCE)"
  - **Header:** Purple background, white text.
  - **Content:** A striped table (white and light gray rows) with 3 columns: "# Problem", "Base Template", "Only What Changes".
- **Column 2 (approx. 30% width):** "8 BFS TEMPLATES USED (FROM PAGE 6)"
  - **Header:** Green background, white text.
  - **Content:** A list of templates, each preceded by its corresponding colored square badge (Gb, Gr, Ms, Lv, Ds) matching the top legend.
- **Column 3 (approx. 30% width):** "9 INTERVIEW CHECKLIST"
  - **Header:** Red background, white text.
  - **Content:** A checklist with custom square checkbox icons and corresponding text.

## 6. Bottom Flowchart Section (Full Width)
- **Header:** "BFS PROBLEM SOLVING FLOW (INTERVIEW APPROACH)" centered, dark blue text.
- **Primary Flowchart (Row 1):**
  - A horizontal sequence of nodes connected by right-pointing arrows.
  - **Nodes:** Consist of icons (Question mark, Graph/Grid branching, Decision diamonds, Document/Code icons, Magnifying glass, Rocket) with descriptive text below each.
  - **Branching:** The "Input Type?" node branches into "Graph" and "Grid".
- **Secondary Flowchart (Row 2):**
  - A smaller, linear sequence of icons and text connected by right-pointing arrows.
  - **Nodes:** Question mark -> Keyboard -> Grid icon -> Gear icon -> Target icon -> Logic/Code icon -> Play button -> Stopwatch icon.
  - **Style:** Minimalist line-art icons with brief text labels beneath.

## 7. Typographic Alignment & Spacing
- **Headers:** Mostly centered within their respective container blocks.
- **Body Text:** Left-aligned.
- **Tables:** Headers and cell content are centered for visual balance.
- **Code:** Left-aligned with standard indentation.
- **Margins/Padding:** Uniform padding inside panels, with consistent gutters between the 3 main columns.
