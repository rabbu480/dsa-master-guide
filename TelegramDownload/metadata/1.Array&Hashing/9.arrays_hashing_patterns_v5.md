Essential Java APIs, Syntax & Utilities you use in Arrays + Hashing problems

## 1. DATA STRUCTURES – QUICK REFERENCE

### HashSet<E> (Unique Elements)
```java
Set<Character> set = new HashSet<>();
set.add('a');          // true if added
set.contains('a');     // O(1) avg
set.remove('a');
set.size();
set.isEmpty();
set.clear();
```
Time Complexity: `add/contains/remove -> O(1) avg`

### HashMap<K, V> (Key -> Value)
```java
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);             // insert/update
map.get("a");                // returns value or null
map.getOrDefault("a", 0);    // default if not present
map.containsKey("a");
map.containsValue(1);
map.remove("a");
map.size(); map.isEmpty(); map.clear();
```
Time Complexity: `put/get/containsKey -> O(1) avg`

### LinkedHashMap<K, V> (Maintains Insertion Order)
```java
Map<Integer, Integer> lhm = new LinkedHashMap<>();
lhm.put(1, 10); lhm.put(2, 20);
// Iterates in insertion order
```

### TreeMap<K, V> (Sorted by Key)
```java
Map<Integer, String> tm = new TreeMap<>();
tm.put(3, "c"); tm.put(1, "a"); tm.put(2, "b");
// Keys iterated in sorted order: 1, 2, 3
```
Time Complexity: `O(log n)`

### PriorityQueue<E> (Min-Heap by default)
```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.add(5); pq.add(1); pq.add(3);
pq.peek();    // 1 (min)
pq.poll();    // 1
pq.size();    pq.isEmpty();

// For Max-Heap:
PriorityQueue<Integer> pqMax = new PriorityQueue<>(
        Collections.reverseOrder());
```
Time Complexity: `add/poll/peek -> O(log n)`

## 3. USEFUL JAVA PATTERNS & METHODS

### computeIfAbsent() – Very Important!
```java
Map<Character, List<Integer>> map = new HashMap<>();
map.computeIfAbsent('a', k -> new ArrayList<>()).add(1);
// If key 'a' not present, creates new ArrayList<>
// then adds 1. Else, directly adds to existing list.
```

### getOrDefault()
```java
int count = map.getOrDefault(key, 0);
// returns value if key exists, else default (0)
```

### merge() – Another Powerful One
```java
map.merge(key, 1, Integer::sum);
// If key absent -> put(key,1)
// If present -> oldVal + 1
```

### forEach() with Lambda
```java
map.forEach((key, val) -> {
    System.out.println(key + " -> " + val);
});
```

### Stream APIs (Often Used)
```java
List<Integer> list = new ArrayList<>(map.values());
list.stream().sorted().toList();
list.stream().sorted(Comparator.reverseOrder()).toList();
list.stream().limit(k).toList();
list.stream().mapToInt(i -> i).toArray();
Arrays.stream(arr).boxed().collect(Collectors.toList());
```

### Arrays Utility
```java
Arrays.sort(arr);
Arrays.sort(arr, Comparator.reverseOrder());
Arrays.fill(arr, 0);
Arrays.copyOf(arr, newLength);
Arrays.equals(arr1, arr2);
```

### Queue / Deque
```java
Queue<Integer> q = new LinkedList<>();
q.offer(1); q.poll(); q.peek();
Deque<Integer> dq = new ArrayDeque<>();
dq.offerFirst(1); dq.offerLast(2);
dq.pollFirst(); dq.pollLast(); dq.peekFirst(); dq.peekLast();
```

### Stack (Legacy) or Deque (Preferred)
```java
Stack<Integer> st = new Stack<>();
st.push(1); st.pop(); st.peek(); st.isEmpty();
Deque<Integer> st2 = new ArrayDeque<>(); // better
st2.push(1); st2.pop(); st2.peek(); st2.isEmpty();
```

## 4. FREQUENCY ARRAY (For Lowercase Letters)
```java
int[] freq = new int[26];
for (char c : s.toCharArray()) {
    freq[c - 'a']++;
}
// index = char - 'a' (0 to 25)
// Works for 'a' to 'z' only
```

## 5. BUCKET / GROUPING PATTERN
```java
Map<String, List<String>> map = new HashMap<>();
for (String s : strs) {
    char[] arr = s.toCharArray();
    Arrays.sort(arr);
    String key = new String(arr);
    map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}
List<List<String>> res = new ArrayList<>(map.values());
```

## 6. TOP K FREQUENT – TEMPLATE (HashMap + PQ)
```java
Map<Integer, Integer> freq = new HashMap<>();
for (int n : nums) {
    freq.merge(n, 1, Integer::sum);
}
PriorityQueue<int[]> pq = new PriorityQueue<>(
    (a, b) -> a[1] - b[1] // min-heap by freq
);
for (int[] e : freq.entrySet().stream()
           .map(e -> new int[]{e.getKey(), e.getValue()})
           .toList()) {
    pq.offer(e);
    if (pq.size() > k) pq.poll();
}

// Extract from pq (smallest to largest freq)
int[][] ans = new int[k][2];
for (int i = k - 1; i >= 0; i--) ans[i] = pq.poll();
```

## 7. CHECKLIST – WHEN SOLVING
- [x] Understand constraints (n, values, range).
- [x] Think: Can I use HashSet for O(1) lookups?
- [x] Need counts? -> Use HashMap / int[26]
- [x] Need order? -> LinkedHashMap / TreeMap
- [x] Top K / Min/Max? -> PriorityQueue (Heap)
- [x] Need grouping? -> HashMap<Key, List>
- [x] Need encoding? -> length#string
- [x] Can I do prefix/suffix to avoid re-computation?
- [x] Always analyze time & space complexity.
