# Visual Layout Specification: BST Bible

## 1. Document Overview
* **Type:** Infographic / Cheat Sheet
* **Grid System:** 3-column layout with a full-width header and full-width footer.
* **Orientation:** Portrait
* **Theme:** Educational, structured, block-based card layout.

## 2. Color Palette
* **Background:** Solid white (`#FFFFFF`)
* **Header/Title Text:** Navy Blue
* **Card Header Backgrounds:**
  * Green (BST Rule, Validate BST)
  * Deep Purple (Search in BST, Inorder = Sorted Order)
  * Teal / Dark Green (Insert into BST)
  * Orange / Vermilion (Delete from BST)
  * Navy Blue (Kth Smallest Element)
  * Crimson Red (LCA in BST)
  * Bright Blue (BST Cheat Sheet)
* **Callout Boxes / Highlights:**
  * Light Purple background (Complexity blocks, Some Idea blocks)
  * Pale Yellow background (Remember box, Final Mantra banner)
  * Light Green background (Valid range formula box)
* **Diagram Elements:**
  * Black/Grey (Standard nodes and edges)
  * Red/Orange dashed lines (Highlights for insertion/deletion/search paths)

## 3. Typography
* **Main Title:** Extra large, bold, uppercase, sans-serif (Navy Blue).
* **Card Headers:** Bold, uppercase, sans-serif, white text on colored background. Numbered sequentially.
* **Subheadings (Idea, Steps, Example, Complexity):** Bold, smaller font, dark grey/black.
* **Body Text & Annotations:** Regular sans-serif, well-spaced, mostly left-aligned.
* **Code/Formulas:** Monospaced or distinctly formatted for logical operations (e.g., `if key == root.val`).

## 4. Component Layout
### 4.1. Global Header (Top)
* **Alignment:** Center aligned.
* **Structure:** A dark blue square enclosing the number "6" on the far left. Followed by a massive "BST BIBLE (BINARY SEARCH TREE)" title.
* **Divider:** A thin horizontal line spanning the width beneath the title with the subtitle embedded in the middle.

### 4.2. Main Grid
The main content is distributed across a 3-column, 3-row masonry-style grid. Each section is encapsulated in a distinct card with a colored header and rounded borders.

#### Row 1 (3 Columns)
* **Column 1:** "1. BST RULE" (Green header). Contains text, a tree diagram, and a bulleted checklist.
* **Column 2:** "2. SEARCH IN BST" (Purple header). Contains conditional logic text, a tree diagram with path highlighting, and a Complexity box at the bottom.
* **Column 3:** "3. INSERT INTO BST" (Teal header). Contains steps, before-and-after tree diagrams, and a Complexity box.

#### Row 2 (3 Columns)
* **Column 1:** "4. DELETE FROM BST" (Orange header). Contains 3 distinct cases with before-and-after tree diagrams illustrating node replacement. Complexity box at the bottom.
* **Column 2:** "5. Kth SMALLEST ELEMENT" (Navy Blue header). Contains text, a tree diagram, mathematical annotations, and a Complexity box.
* **Column 3:** "6. VALIDATE BST" (Green header). Contains a highlighted formula box, text steps, a tree diagram with range annotations, and a Complexity box.

#### Row 3 (3 Columns)
* **Column 1:** "7. LCA IN BST" (Red header). Contains conditional logic, a tree diagram with path highlighting, and a Complexity box.
* **Column 2:** Two stacked sections.
  * **Top Section:** "BST CHEAT SHEET" (Bright Blue header). A 4-column data table summarizing operations.
  * **Bottom Section:** Split into two smaller blocks. Left: "BST PROPERTIES" (Checklist). Right: "REMEMBER" (Pale yellow highlight box with bullet points).
* **Column 3:** "8. INORDER = SORTED ORDER" (Purple header). Contains a tree diagram, mathematical sequences, and a rounded text box explaining "Why?".

### 4.3. Global Footer (Bottom)
* **Alignment:** Full width, horizontal flow.
* **Structure:** A pale yellow banner titled "FINAL MANTRA" with a trophy icon. Followed by four distinct textual steps connected by horizontal orange arrows.

## 5. Visual Elements & Representations
* **Tree Diagrams:** Used universally across all cards to represent Binary Search Trees.
  * Nodes are white circles with black borders containing integer values.
  * Edges are straight black lines.
  * Null/Empty nodes in deletions are sometimes represented by lack of connections.
  * **Interactive/Dynamic State Representation:** Red dashed arrows and red text represent the "action" (e.g., traversing left/right, replacing a node, inserting a new node).
* **Complexity Boxes:** Standardized light-colored rectangular boxes placed at the bottom of almost every card, summarizing Time and Space complexities.
* **Table:** Standard grid table used in the Cheat Sheet section with column headers and striped/separated rows.
* **Icons:** Small checkmarks (green) for rules/properties, trophy icon in the footer mantra.
