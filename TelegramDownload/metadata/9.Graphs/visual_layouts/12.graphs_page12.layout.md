# Visual Layout Specification: Graph DFS Problem Guide

## Overview
This document specifies the visual structure, layout grid, and block alignments for the "Graph DFS Problem Guide" page. The page uses a multi-column layout with distinct sections for instructions, templates, problem breakdowns, and reference checklists.

## Global Layout Structure
The page is organized into the following major horizontal zones (top to bottom):
1.  **Header Zone:** Full-width container spanning the top of the page.
2.  **Instruction & Legend Zone:** A two-column grid.
3.  **Problem Grid Zone (Rows 1 & 2):** A three-column grid layout for problem breakdowns.
4.  **Mixed Grid Zone (Row 3):** A three-column grid layout featuring a problem breakdown, a reference table, and a checklist.
5.  **Footer Zone:** A full-width horizontal flowchart.

---

## Zone 1: Header
*   **Alignment:** Center-aligned content.
*   **Elements:**
    *   **Page Badge:** Top left corner, white text on dark blue rectangular background (`PAGE 5`).
    *   **Main Title:** Large, bold, dark blue font, centered with a book icon on the left.
    *   **Subtitle:** Medium bold font below the main title.
    *   **Tagline:** Italicized font below the subtitle, bracketed by horizontal lines.

---

## Zone 2: Instruction & Legend Grid
*   **Grid Layout:** Two columns (approx. 35% left, 65% right).
*   **Left Column (How to Use):**
    *   **Header:** White text on a purple background block.
    *   **Content:** Numbered list with a target/bullseye icon at the bottom right.
*   **Right Column (Template Legend):**
    *   **Header:** White text on a dark blue background block.
    *   **Content:** Horizontal arrangement of circular legend badges with accompanying labels.
    *   **Badges:** Distinct colors for different templates (Purple 'G', Green 'Gd', Orange 'N', Blue 'OL', Red 'Bd').

---

## Zone 3: Problem Grid (Rows 1 & 2)
*   **Grid Layout:** Three equal-width columns. Each column contains a self-contained "Problem Card" bounded by a light gray border.

### Problem Card Internal Structure
Each card strictly follows this internal layout:
1.  **Card Header:**
    *   **Left:** Number badge (colored square) and capitalized problem title.
    *   **Right:** Circular template badge corresponding to the legend.
    *   *Divider line below header.*
2.  **Base Template:** Centered, bold text indicating the base template used.
3.  **Problem Statement:** Short text description under the "Problem" label.
4.  **Code Block (Changed Lines):**
    *   Header: "Changed Lines (from Template)" with red/purple text.
    *   Content: Syntax-highlighted code block with comments.
5.  **Parameters Table:**
    *   A three-column mini-table showing `Caller`, `Return`, and `Visited` states.
6.  **Key Insight / Aha Moment:**
    *   Left-aligned lightbulb icon followed by a bolded tip or insight.
7.  **Footer Grid:**
    *   Two columns divided by a vertical line.
    *   **Left:** Complexity (Time and Space).
    *   **Right:** Interview Tip.

---

## Zone 4: Mixed Grid (Row 3)
*   **Grid Layout:** Three equal-width columns.

*   **Column 1 (Problem Card):** Follows the exact structure of the cards in Zone 3 (Problem 7).
*   **Column 2 (Quick Reference Table):**
    *   **Header:** White text on dark blue background block.
    *   **Content:** A multi-row table summarizing all problems.
    *   **Columns:** Problem name, Base Template (with badges), Main Change, Return type.
    *   **Footer:** Legend badges repeated at the bottom.
*   **Column 3 (Interview Checklist):**
    *   **Header:** White text on dark blue background block, with a number '8' badge.
    *   **Content:** Vertical list of checklist items with blue checkmark icons.

---

## Zone 5: Footer (Flowchart)
*   **Layout:** Full-width horizontal sequence.
*   **Structure:** A linear flowchart representing the problem-solving lifecycle.
*   **Elements:** Individual step blocks containing an icon, title, and subtext, connected by right-pointing arrows.
*   **Alignment:** Centered horizontally across the bottom margin of the page.

---

## Color Palette & Typography Conventions
*   **Primary Accent Colors:** Used consistently for numbering, headers, and badges to group related concepts.
    *   Dark Blue: Main headers, checklist, page numbers.
    *   Purple: Graph DFS (G)
    *   Green: Grid DFS (Gd)
    *   Orange: Node DFS (N)
    *   Red: Border DFS (Bd)
*   **Fonts:** Sans-serif for maximum legibility. Bold weights used extensively for titles, subtitles, and key terms. Monospace font used for code blocks.
*   **Borders & Dividers:** Thin, light gray lines used heavily to separate sections within problem cards and between grid columns.
