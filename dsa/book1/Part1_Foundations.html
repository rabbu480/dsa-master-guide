Big-O notation describes the upper bound performance scaling of an algorithm as input size $N$ grows towards infinity. In interviews, drop non-dominant terms and constant multipliers.

Nested Loop Complexity Rules

Rule 1: Sequential Loops (Add)

// O(N) + O(M) = O(N + M)
for (int i = 0; i < n; i++) { ... }
for (int j = 0; j < m; j++) { ... }

Rule 2: Nested Loops (Multiply)

// O(N * M)
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) { ... }
}

Rule 3: Halving Loops (Logarithmic)

// O(log N)
while (n > 0) {
    n /= 2;
}

1.3A GCD & LCM (Euclidean Algorithm)
public int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
public int lcm(int a, int b) {
    return (a / gcd(a, b)) * b; // Divide first to prevent overflow
}
1.3B Sieve of Eratosthenes O(N log log N)
public boolean[] sieve(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = isPrime[1] = false;
    for (int p = 2; p * p <= n; p++) {
        if (isPrime[p]) {
            for (int i = p * p; i <= n; i += p) isPrime[i] = false;
        }
    }
    return isPrime;
}
