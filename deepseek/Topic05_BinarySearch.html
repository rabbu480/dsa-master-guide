💡 WHY BINARY SEARCH?

Imagine guessing a number between 1 and 1,000,000. Linear search takes 1,000,000 guesses. Binary search takes only 20 guesses by halving the search space each time!

💡 THE BINARY SEARCH AHA
Binary Search is NOT just array search! It's a general search-space reduction paradigm. Evaluate the middle element against a monotonic property to discard half the search space in O(1) time!
🤔 WHY NOT LINEAR SEARCH?
  • Linear Search O(N): For N = 10⁹, takes 10⁹ operations → 10 seconds!
  • Binary Search O(log N): For N = 10⁹, takes only 30 operations → microseconds!
  • Requires: Sorted data or a monotonic predicate.

🔧 SAFE MID FORMULA
// ❌ WRONG — Overflows for large left + right
int mid = (left + right) / 2;

// ✅ CORRECT — Overflow-safe
int mid = left + (right - left) / 2;

// ✅ CORRECT — Using unsigned shift (Java)
int mid = (left + right) >>> 1;
💡 Always use the safe formula. Integer overflow is a common interview trap!
🔧 LOWER BOUND & UPPER BOUND
// Lower Bound: First index where arr[i] >= target
int lowerBound(int[] arr, int target) {
    int lo = 0, hi = arr.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

// Upper Bound: First index where arr[i] > target
int upperBound(int[] arr, int target) {
    int lo = 0, hi = arr.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

⚡ 5-STEP BINARY SEARCH THINKING FRAMEWORK
  1. Is the data sorted or monotonic? If not, BS doesn't work.
  2. What are we searching for? Exact value? First occurrence? Feasibility?
  3. What's the search space? Array indices? Value range [lo, hi]?
  4. What's the mid condition? `arr[mid] == target`? `arr[mid] < target`? `isValid(mid)`?
  5. How to update bounds? `lo = mid + 1`, `hi = mid - 1`, or `hi = mid`?

PATTERN 1 — CLASSIC BINARY SEARCH LC 704 · EASY
When to Use: Find exact element in sorted array.
Input: [-1,0,3,5,9,12], target=9
Output: 4
💡 AHA
Classic template: `while (left <= right)`. If `mid == target` return. If `mid < target`, search right. Else search left. 
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1; // Search right half
        } else {
            right = mid - 1; // Search left half
        }
    }
    return -1; // Not found
}

public int guessNumber(int n) {
    int left = 1, right = n;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        int result = guess(mid); // API call

        if (result == 0) {
            return mid;
        } else if (result < 0) {
            right = mid - 1; // Guess is too high
        } else {
            left = mid + 1; // Guess is too low
        }
    }
    return -1;
}

PATTERN 4 — 1D MATRIX FLATTENING LC 74 · MEDIUM
When to Use: Search in fully sorted matrix (row i end < row i+1 start).
Input: matrix=[[1,3,5,7],[10,11,16,20],[23,30,34,60]], target=3
Output: true
💡 AHA
Convert 1D index to 2D: `row = mid / cols`, `col = mid % cols`. This is O(1) mapping! 
public boolean searchMatrix(int[][] matrix, int target) {
    int rows = matrix.length, cols = matrix[0].length;
    int left = 0, right = rows * cols - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        int val = matrix[mid / cols][mid % cols]; // 1D → 2D mapping

        if (val == target) return true;
        else if (val < target) left = mid + 1;
        else right = mid - 1;
    }
    return false;
}
PATTERN 5 — ROTATED SORTED ARRAY LC 33 · MEDIUM
When to Use: Search in rotated sorted array with unique values.
Input: [4,5,6,7,0,1,2], target=0
Output: 4
💡 AHA
At least ONE half (left or right) is ALWAYS sorted! Check which half, then search within it. 
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) return mid;

        // Left half is sorted
        if (nums[left] <= nums[mid]) {
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1; // Target in left half
            } else {
                left = mid + 1; // Target in right half
            }
        }
        // Right half is sorted
        else {
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1; // Target in right half
            } else {
                right = mid - 1; // Target in left half
            }
        }
    }
    return -1;
}
PATTERN 6 — FIND MIN IN ROTATED LC 153 · MEDIUM
When to Use: Find minimum element in rotated sorted array.
Input: [3,4,5,1,2]
Output: 1
💡 AHA
If `nums[mid] > nums[right]`, min is in right half. Else, min is in left half (including mid). 
public int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] > nums[right]) {
            left = mid + 1; // Min is in right half
        } else {
            right = mid; // Min is in left half (including mid)
        }
    }
    return nums[left];
}

PATTERN 7 — BS ON ANSWER LC 875 · MEDIUM
When to Use: Find minimum value that satisfies a condition.
Input: piles=[3,6,7,11], h=8
Output: 4
💡 AHA
Binary search the answer space [1, max(piles)]. Check feasibility with `isValid(mid)`! 
public int minEatingSpeed(int[] piles, int h) {
    int left = 1, right = 0;
    for (int p : piles) right = Math.max(right, p);

    int res = right;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        long hours = 0;

        // Check if speed = mid is feasible
        for (int p : piles) {
            hours += (p + mid - 1) / mid; // Ceiling division
        }

        if (hours <= h) {
            res = mid;
            right = mid - 1; // Try slower speed
        } else {
            left = mid + 1; // Need faster speed
        }
    }
    return res;
}
PATTERN 8 — SLOPE SEARCH LC 162 · MEDIUM
When to Use: Find any peak element (greater than neighbors).
Input: [1,2,3,1]
Output: 2
💡 AHA
If `nums[mid] < nums[mid+1]`, a peak exists on the right. Otherwise, a peak exists on the left. Move towards the ascending slope! 
public int findPeakElement(int[] nums) {
    int left = 0, right = nums.length - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        // Ascending slope → peak is on the right
        if (nums[mid] < nums[mid + 1]) {
            left = mid + 1;
        } else {
            right = mid; // Peak is on the left (including mid)
        }
    }
    return left;
}

⭐ LC 34 · First & Last Position MEDIUM
Input: [5,7,7,8,8,10], target=8
Output: [3,4]
Pattern: Boundary Search
💡 AHA
Two passes: one for first occurrence (move left), one for last occurrence (move right). 
public int[] searchRange(int[] nums, int target) {
    int first = firstOccurrence(nums, target);
    int last = lastOccurrence(nums, target);
    return new int[]{first, last};
}

private int firstOccurrence(int[] nums, int target) {
    int l=0, r=nums.length-1, ans=-1;
    while (l <= r) {
        int m = l + (r-l)/2;
        if (nums[m] == target) { ans = m; r = m-1; }
        else if (nums[m] < target) l = m+1;
        else r = m-1;
    }
    return ans;
}

private int lastOccurrence(int[] nums, int target) {
    int l=0, r=nums.length-1, ans=-1;
    while (l <= r) {
        int m = l + (r-l)/2;
        if (nums[m] == target) { ans = m; l = m+1; }
        else if (nums[m] < target) l = m+1;
        else r = m-1;
    }
    return ans;
}

class TimeMap {
    Map<String, List<Pair>> map = new HashMap<>();

    public void set(String key, String val, int time) {
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(new Pair(time, val));
    }

    public String get(String key, int time) {
        if (!map.containsKey(key)) return "";
        List<Pair> list = map.get(key);
        int l=0, r=list.size()-1;
        String res = "";
        while (l <= r) {
            int m = l + (r-l)/2;
            if (list.get(m).time <= time) {
                res = list.get(m).val;
                l = m + 1;
            } else {
                r = m - 1;
            }
        }
        return res;
    }

    private static class Pair { int time; String val; Pair(int t, String v){time=t;val=v;} }
}

public int splitArray(int[] nums, int k) {
    int l=0, r=0;
    for (int n : nums) { l = Math.max(l, n); r += n; }
    int ans = r;
    while (l <= r) {
        int m = l + (r-l)/2;
        if (canSplit(nums, k, m)) { ans = m; r = m-1; }
        else l = m+1;
    }
    return ans;
}

private boolean canSplit(int[] nums, int k, int maxSum) {
    int count = 1, sum = 0;
    for (int n : nums) {
        if (sum + n > maxSum) { count++; sum = n; }
        else sum += n;
    }
    return count <= k;
}
