# Visual Layout Specification: Arrays & Hashing Cheat Sheet

## 1. Global Document Properties
- **Theme/Style**: Dark mode aesthetic, high contrast.
- **Background Color**: Very dark gray/black.
- **Grid System**: A primary tabular grid with thin, solid, light-gray/white borders dividing rows and columns.
- **Typography Palette**: Sans-serif for headers and standard text; monospace for code blocks.
- **Color Coding**: Semantic color coding is extensively used to differentiate data types (e.g., complexity metrics, headers, code syntax, difficulty levels).

## 2. Header Section
- **Position**: Top, full-width span.
- **Alignment**: Center-aligned.
- **Styling**: Large, bold, uppercase typography. Uses a dual-color scheme (yellow and white) to emphasize different words in the title.
- **Spacing**: Generous padding above and below the text before the main table begins.

## 3. Main Content Table Layout
The core of the document is a 6-column grid containing 9 data rows.

### Column Specifications
- **Column 1: Problem**
  - **Relative Width**: Narrow.
  - **Alignment**: Left-aligned.
  - **Content Layout**: Three vertical elements: Number (cyan), Title (white), and Difficulty Level (color-coded: green for Easy, yellow for Medium, red for Hard).
- **Column 2: Key Idea**
  - **Relative Width**: Medium-narrow.
  - **Alignment**: Left-aligned.
  - **Visuals**: Paragraph text, predominantly in a cyan/light-green hue.
- **Column 3: Approach / Formula / Pattern**
  - **Relative Width**: Widest column (spans roughly 30-40% of the table width).
  - **Alignment**: Left-aligned text within blocks.
  - **Visuals**: Contains monospace code blocks and structured algorithms. Syntax highlighting applied (keywords in cyan, variables/operators in white, comments in gray).
- **Column 4: Time Complexity**
  - **Relative Width**: Narrow.
  - **Alignment**: Center-aligned horizontally and vertically.
  - **Visuals**: Header in orange. Values in orange, often split across two lines (main Big-O notation on top, variable explanation below in parentheses).
- **Column 5: Space Complexity**
  - **Relative Width**: Narrow.
  - **Alignment**: Center-aligned horizontally and vertically.
  - **Visuals**: Header in light blue. Values in light blue, similarly split across two lines like Column 4.
- **Column 6: Key Takeaways / Patterns**
  - **Relative Width**: Medium.
  - **Alignment**: Left-aligned.
  - **Visuals**: Header in pink/red. Content rendered as a bulleted list with pink/red text.

### Row Layout
- 9 horizontal rows, equal minimum height, expanding vertically to accommodate the code block lengths in Column 3.
- Thin horizontal lines separate each row.

## 4. Supplementary Bottom Grid
Located immediately below the main table, this section features a single row divided into 5 separate bounding boxes.
- **Grid Layout**: 1 row x 5 columns.
- **Box Headers**: Each box has a center-aligned header in cyan text.
- **Box 1 (Data Structures)**: Left-aligned bulleted list mapping concepts using right-arrows. White text.
- **Box 2 (Frequency Pattern)**: Left-aligned monospace code block with syntax highlighting.
- **Box 3 (Bucket Sort)**: Left-aligned monospace code block with syntax highlighting.
- **Box 4 (3x3 Box Traversal)**: Left-aligned monospace code block. Employs deep indentation steps to visually represent nested loops.
- **Box 5 (Complexity Reminder)**: Left-aligned bulleted list. Includes a mix of yellow headers and white text, mapping operations to Big-O complexities using right-arrows.

## 5. Footer Section
- **Position**: Bottom edge, full-width span.
- **Alignment**: Left-aligned.
- **Layout**: Contains a prominent yellow star icon on the far left, followed by a bolded key phrase in yellow, and standard text in white.
- **Spacing**: Modest padding separating it from the supplementary bottom grid.
