## Color Palette & Visual Coding
- **Headers**: Deep blue backgrounds with white text.
- **Block Headers**: Numbered badges in dark blue squares (e.g., [ 1 ] MASTER IDEA). The block titles are typically dark blue on a light background.
- **Tables**: Use light alternating row colors or clear grid lines for separation.
- **Callout Boxes**:
  - **TIP boxes**: Light green or light blue borders/backgrounds.
  - **AHA MOMENTS**: Purple header background.
  - **COMMON MISTAKES**: Red header background.
  - **Interview Tip**: Outline box with a star icon.
- **Icons**: Used extensively for list items (checkmarks, warning signs, lightbulbs) and flowchart steps.
- **Code Blocks**: Formatted with monospace font and keyword highlighting.
- **Diagrams**: Graph nodes are outlined circles connected by lines; matrices are structured grid boxes.

## Alignments & Spacing
- **Padding**: Each block has a distinct margin separating it from adjacent blocks, creating a clean white-space gutter around all elements.
- **Alignment**:
  - Code text is strictly left-aligned.
  - Table headers are mostly center-aligned.
  - Flowcharts use center alignment for vertical flow nodes.
