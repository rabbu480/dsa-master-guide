# Visual Layout Specification: Tree Foundations

## Overall Structure
- A vertical single-page document divided into a main header, three major rectangular layout blocks (panels), and a footer block.
- The document uses a light background (white) with dark blue accents for primary section headers and varying accent colors (green, purple, orange, teal, red) for distinct concepts.
- A thin, light gray bounding box encloses the main content area of the three primary blocks.

## Header Area
- **Top Left:** A dark blue square block containing a large numeral.
- **Top Center:** A large top-level title centered horizontally.
- **Below Title:** A horizontal line broken in the center by a subtitle text block.

## Block 1: Section 1.1
- **Section Header:** A full-width dark blue rectangular banner with centered, white uppercase text.
- **Layout Grid:** A three-column grid. The columns are separated by vertical dotted lines.
- **Column 1:**
  - Column header text colored in green, centered.
  - A bulleted list block aligned left.
  - Visual representation at the bottom: A graph diagram with 4 circular nodes having green borders, connected by black edges in a general tree structure.
- **Column 2:**
  - Column header text colored in purple, centered.
  - A bulleted list block aligned left.
  - Visual representation: A graph diagram with 6 circular nodes having purple borders, structured as a binary tree.
- **Column 3:**
  - Column header text colored in orange, centered.
  - A bulleted list block aligned left.
  - Visual representation: A graph diagram with 6 circular nodes having orange borders, structured as a binary search tree.

## Block 2: Section 1.2
- **Section Header:** A full-width dark blue rectangular banner with centered, white uppercase text.
- **Layout Grid:** A five-column grid. The columns are separated by thin, solid vertical gray lines.
- **Column 1:**
  - Header text in green, centered.
  - Descriptive text block, center-aligned.
  - Visual representation: A binary tree diagram with 7 nodes, green borders.
- **Column 2:**
  - Header text in purple, centered.
  - Descriptive text block, center-aligned.
  - Visual representation: A binary tree diagram with 6 nodes, purple borders.
- **Column 3:**
  - Header text in orange, centered.
  - Descriptive text block, center-aligned.
  - Visual representation: A binary tree diagram with 7 nodes, orange borders.
- **Column 4:**
  - Header text in teal, centered.
  - Descriptive text block, center-aligned.
  - Visual representation: A binary tree diagram with 6 nodes, teal borders.
- **Column 5:**
  - Header text in red, centered.
  - Descriptive text block, center-aligned.
  - Visual representation: Two separate binary tree diagrams positioned side-by-side (separated by text), showing 4 nodes each (left-skewed and right-skewed), with red borders.

## Block 3: Section 1.3
- **Section Header:** A full-width dark blue rectangular banner with centered, white uppercase text.
- **Layout Grid:** A two-column grid layout, divided by a vertical dotted line down the center.
- **Row Structure:** Each column consists of multiple rows acting as a glossary. Each row follows a standard internal structure:
  - **Left (Icon/Diagram):** A small graphical icon or tree fragment diagram illustrating the specific concept (e.g., solid circles, hollow circles, lines, nodes labeled with letters, double arrows, or dashed lines).
  - **Middle (Term):** A bolded keyword, colored green in the left column and blue in the right column.
  - **Separator:** A colon (`:`) aligning vertically down the column.
  - **Right (Description):** A descriptive text block aligned left.

## Footer Area
- **Background:** A full-width light blue rectangular banner.
- **Left Element:** A dark blue circular badge containing a white lightbulb icon.
- **Center Element:** A text block consisting of a bolded keyword and standard text, aligned to the left of the center space.
- **Right Element:** A dark blue icon depicting a target or bullseye with an arrow.
