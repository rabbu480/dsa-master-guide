💡 WHY QUEUE & DEQUE?

A Queue processes elements in FIFO (First In, First Out) order — like a line at a checkout. A Deque (Double-Ended Queue) allows insertion and removal from BOTH ends!

💡 THE ARRAYDEQUE AHA
Always use `Deque deque = new ArrayDeque<>()` for both Queue and Deque. It's faster than `LinkedList` and more memory-efficient!
1 3 CORE USE CASES
  • FIFO Queue: BFS, task scheduling, request processing.
  • Deque (Double-Ended): Monotonic Deque for Sliding Window Maximum.
  • Circular Queue: Fixed-size buffer with modulo arithmetic.

  2. Do I need access to both ends? Sliding Window → Deque.

  4. Is it monotonic? Sliding Window Max → Monotonic Deque.
  5. What's the answer? Max? Min? Count?

🧠 BFS TEMPLATE — LEVEL ORDER TRAVERSAL
When to Use: Tree/Graph traversal, shortest path in unweighted graph, level-order processing.
💡 THE BFS AHA
Always freeze the queue size at the start of each level: int size = queue.size();. This is critical for level-by-level processing! 
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int size = queue.size(); // ⭐ CRITICAL: freeze level size
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);

            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        result.add(level);
    }
    return result;
}

// Graph BFS (shortest path in unweighted graph)
public void bfsGraph(int start, List<Integer>[] adj) {
    boolean[] visited = new boolean[adj.length];
    Queue<Integer> queue = new ArrayDeque<>();

    visited[start] = true; // ⭐ Mark visited BEFORE enqueuing!
    queue.offer(start);

    while (!queue.isEmpty()) {
        int u = queue.poll();

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                queue.offer(v);
            }
        }
    }
}

PATTERN 1 — QUEUE USING STACKS LC 232 · EASY
When to Use: Implement FIFO queue using two stacks.
Input: push(1), push(2), peek(), pop()
Output: 1
💡 AHA
Two LIFO reversals cancel out to form a perfect FIFO Queue! Use `input` for push, `output` for pop/peek. 
class MyQueue {
    private Deque<Integer> input = new ArrayDeque<>();
    private Deque<Integer> output = new ArrayDeque<>();

    public void push(int x) {
        input.push(x);
    }

    public int pop() {
        peek(); // Ensure output has elements
        return output.pop();
    }

    public int peek() {
        if (output.isEmpty()) {
            while (!input.isEmpty()) {
                output.push(input.pop());
            }
        }
        return output.peek();
    }

    public boolean empty() {
        return input.isEmpty() && output.isEmpty();
    }
}
PATTERN 2 — QUEUE RANGE EXPIRY LC 933 · EASY
When to Use: Count recent requests within time range [t-3000, t].
Input: ping(1), ping(100), ping(3001)
Output: 1, 2, 3
💡 AHA
Queue stores timestamps. Always remove expired timestamps from front before returning size! 
class RecentCounter {
    private Queue<Integer> queue = new ArrayDeque<>();

    public int ping(int t) {
        queue.offer(t);

        // Remove timestamps older than t - 3000
        while (!queue.isEmpty() && queue.peek() < t - 3000) {
            queue.poll();
        }
        return queue.size();
    }
}
PATTERN 3 — CIRCULAR QUEUE LC 622 · MEDIUM
When to Use: Fixed-size queue with modulo arithmetic.
Input: enQueue(1), enQueue(2), enQueue(3), enQueue(4)
Output: true, true, true, false
💡 AHA
Use modulo to wrap around: `tail = (tail + 1) % capacity`. Track `size` separately. 
class MyCircularQueue {
    private int[] data;
    private int head = 0, tail = 0, size = 0, capacity;

    public MyCircularQueue(int k) {
        capacity = k;
        data = new int[k];
    }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        data[tail] = value;
        tail = (tail + 1) % capacity;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % capacity;
        size--;
        return true;
    }

    public int Front() { return isEmpty() ? -1 : data[head]; }
    public int Rear() { return isEmpty() ? -1 : data[(tail - 1 + capacity) % capacity]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == capacity; }
}

PATTERN 4 — MONOTONIC DEQUE LC 239 · HARD
When to Use: Find maximum in every sliding window of size K.
Input: [1,3,-1,-3,5,3,6,7], k=3
Output: [3,3,5,5,6,7]
💡 AHA — Monotonic Decreasing Deque
Any smaller value behind a larger value can never become the maximum while the larger value remains in the window. Pop them! 
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>(); // Stores indices

    for (int i = 0; i < n; i++) {
        // 1. Expire old indices (outside window)
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // 2. Maintain decreasing order: pop smaller from back
        while (!deque.isEmpty() && nums[i] >= nums[deque.peekLast()]) {
            deque.pollLast();
        }

        // 3. Add current index
        deque.offerLast(i);

        // 4. Record result once window is full
        if (i >= k - 1) {
            res[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return res;
}
PATTERN 5 — TWO QUEUES SIMULATION LC 649 · MEDIUM
When to Use: Simulate round-robin voting with two parties.
Input: "RDD"
Output: "Dire"
💡 AHA
Use two queues for positions. Compare front indices. The smaller index bans the larger, re-enqueues with +n offset. 
public String predictPartyVictory(String senate) {
    int n = senate.length();
    Queue<Integer> radiant = new ArrayDeque<>();
    Queue<Integer> dire = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        if (senate.charAt(i) == 'R') radiant.offer(i);
        else dire.offer(i);
    }

    while (!radiant.isEmpty() && !dire.isEmpty()) {
        int rIdx = radiant.poll();
        int dIdx = dire.poll();

        if (rIdx < dIdx) {
            radiant.offer(rIdx + n); // Radiant bans Dire, goes to back
        } else {
            dire.offer(dIdx + n); // Dire bans Radiant, goes to back
        }
    }

    return radiant.isEmpty() ? "Dire" : "Radiant";
}
PATTERN 6 — DEQUE INDEX SIMULATION LC 950 · MEDIUM
When to Use: Reorder deck so revealed cards are in increasing order.
Input: [17,13,11,2,3,5,7]
Output: [2,3,5,7,11,13,17]
💡 AHA
Sort deck. Use deque of indices. Place smallest card at pollFirst index, then move next index to back. 
public int[] deckRevealedIncreasing(int[] deck) {
    int n = deck.length;
    Arrays.sort(deck);

    Deque<Integer> indexDeque = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        indexDeque.offer(i);
    }

    int[] res = new int[n];

    for (int card : deck) {
        // Place smallest card at front index
        res[indexDeque.pollFirst()] = card;

        // Move next index to back
        if (!indexDeque.isEmpty()) {
            indexDeque.offerLast(indexDeque.pollFirst());
        }
    }
    return res;
}

PATTERN 7 — PREFIX SUM + DEQUE LC 862 · HARD
When to Use: Shortest subarray with sum >= K (handles negative numbers).
Input: nums=[2,-1,2], k=3
Output: 3
💡 AHA
Build prefix sum array. Use monotonic increasing deque. When sum - deque.peekFirst >= k, update answer and pop front. 
public int shortestSubarray(int[] nums, int k) {
    int n = nums.length;
    long[] prefix = new long[n + 1];

    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }

    Deque<Integer> deque = new ArrayDeque<>();
    int minLen = n + 1;

    for (int i = 0; i <= n; i++) {
        // Check if current prefix - previous prefix >= k
        while (!deque.isEmpty() && prefix[i] - prefix[deque.peekFirst()] >= k) {
            minLen = Math.min(minLen, i - deque.pollFirst());
        }

        // Maintain monotonic increasing prefix sums
        while (!deque.isEmpty() && prefix[i] <= prefix[deque.peekLast()]) {
            deque.pollLast();
        }

        deque.offerLast(i);
    }

    return minLen == n + 1 ? -1 : minLen;
}
PATTERN 8 — DP + DEQUE LC 1425 · HARD
When to Use: Max sum of subsequence with index difference <= K.
Input: nums=[10,2,-10,5,20], k=2
Output: 37
💡 AHA
DP + Monotonic Deque. `dp[i] = nums[i] + Math.max(0, max(dp[j]) for j in [i-k, i-1])`. 
public int constrainedSubsetSum(int[] nums, int k) {
    int n = nums.length;
    int[] dp = new int[n];
    Deque<Integer> deque = new ArrayDeque<>();
    int maxSum = nums[0];

    for (int i = 0; i < n; i++) {
        // Remove indices outside window
        while (!deque.isEmpty() && deque.peekFirst() < i - k) {
            deque.pollFirst();
        }

        // dp[i] = nums[i] + max(0, best previous dp)
        dp[i] = nums[i] + (!deque.isEmpty() ? Math.max(0, dp[deque.peekFirst()]) : 0);
        maxSum = Math.max(maxSum, dp[i]);

        // Maintain decreasing order of dp values
        while (!deque.isEmpty() && dp[i] >= dp[deque.peekLast()]) {
            deque.pollLast();
        }
        deque.offerLast(i);
    }

    return maxSum;
}

Monotonic Deque — The Most Important Pattern
PAGE 6 OF 9
🧠 MONOTONIC DEQUE — THE COMPLETE GUIDE
What is a Monotonic Deque? A deque that maintains elements in strictly decreasing or increasing order. Used for Sliding Window Maximum/Minimum in O(N) time.
📉 Monotonic Decreasing
Pop smaller from back. Front = MAX.
LC 239, LC 1438
📈 Monotonic Increasing
Pop larger from back. Front = MIN.
LC 862, LC 1425
📐 PROOF — O(N) COMPLEXITY
Each element is offered to the deque once. An element can be polled from the deque at most once (from front or back). Total operations = N offers + at most N polls = 2N → O(N)!
💡 Key Intuition: Any smaller value behind a larger value can never become the maximum while the larger value remains in the window. This is why we can safely pop smaller values from the back!

class MyCircularQueue {
    int[] data; int head=0, tail=0, size=0, cap;
    MyCircularQueue(int k) { cap=k; data=new int[k]; }
    boolean enQueue(int v) {
        if (isFull()) return false;

}

⭐ LC 1438 · Longest Continuous Subarray MEDIUM
Input: nums=[8,2,4,7], limit=4
Output: 2
Pattern: Two Deques (Max + Min)
💡 AHA
Use two monotonic deques simultaneously: max deque (decreasing) and min deque (increasing). Shrink left when `max - min > limit`. 
public int longestSubarray(int[] nums, int limit) {
    Deque<Integer> maxDq = new ArrayDeque<>();
    Deque<Integer> minDq = new ArrayDeque<>();
    int left = 0, maxLen = 0;

    for (int right = 0; right < nums.length; right++) {
        // Maintain max deque (decreasing)
        while (!maxDq.isEmpty() && nums[right] > nums[maxDq.peekLast()]) {
            maxDq.pollLast();
        }
        maxDq.offerLast(right);

        // Maintain min deque (increasing)
        while (!minDq.isEmpty() && nums[right] < nums[minDq.peekLast()]) {
            minDq.pollLast();
        }
        minDq.offerLast(right);

        // Shrink window if difference exceeds limit
        while (nums[maxDq.peekFirst()] - nums[minDq.peekFirst()] > limit) {
            if (maxDq.peekFirst() == left) maxDq.pollFirst();
            if (minDq.peekFirst() == left) minDq.pollFirst();
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
