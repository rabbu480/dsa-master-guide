# Visual Layout Specification: Graph Pattern Guide - Master BFS Template Guide

## 1. Global Layout Properties
- **Document Type**: Infographic / Cheat Sheet
- **Orientation**: Portrait
- **Grid System**: Multi-row, variable column layout (typically 1 to 4 columns depending on the row).
- **Color Palette**:
  - **Primary Base**: White (background)
  - **Primary Accent**: Dark Blue (used for block headers, numbering, titles, borders)
  - **Secondary Accents**: 
    - Light Green (code block titles)
    - Very Light Blue/Gray (AHA callout backgrounds)
    - Red (mistake icons)
  - **Text Colors**: Dark Blue/Black for primary text, White for headers, syntax-highlighted colors for code blocks.
- **Typography**: Sans-serif fonts used throughout. Headers are bolded, uppercase. Code blocks use monospaced fonts.

## 2. Header Section
- **Span**: Full width (100%)
- **Alignment**: Center-aligned (title), Left-aligned (page tag)
- **Elements**:
  - **Page Tag**: Top left, "PAGE 6" in white text inside a dark blue rounded rectangle.
  - **Main Title**: Center-aligned, very large dark blue bold text.
  - **Subtitle**: Medium-large dark blue bold text below the main title.
  - **Quote**: Italicized dark blue text below the subtitle, flanked by small decorative lines/dots.

## 4. Footer Section
- **Span**: Full width (100%)
- **Layout**: Horizontal sequential process flow.
- **Elements**: 8 distinct steps, each containing an icon (left) and text (right). Connected by thin right-pointing arrows.
- **Alignment**: Centered horizontally across the bottom margin.
- **Styling**: Minimalist icons, dark blue/black text, no background containers for the steps, just white space.
