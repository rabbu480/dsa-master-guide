# Visual Layout Specification

## Overall Structure
- A structured, grid-based cheat sheet for tree DFS pattern problems.
- Consists of a header section, a legend bar, five identically-structured data rows (problem sections), a summary section with three columns, and a final footer.
- Colors: Dark blue for primary headers and title bars, light gray for borders, white backgrounds for content. Small colored accents are used for icons and specific formula boxes. Code snippets feature syntax highlighting.

## Header Section
- Top left: A prominent dark blue square with a white number "4" inside.
- Title: Large, bold, dark blue text horizontally centered next to the number block.
- Subtitle: Smaller, dark gray text below the title, flanked by horizontal lines to the left and right.

## Legend Bar
- A full-width rectangular box with a thin gray border positioned below the header.
- Layout: 4 evenly spaced columns, each containing an icon followed by "Term = Definition" format text.

## Main Content Grid (Problem Sections 1-5)
Each problem section follows an identical layout structure:

### Title Bar
- A full-width, dark blue rectangular bar with white, bold, centered text indicating the problem number and name.

### Data Row Grid
- A 6-column grid underneath each title bar.
- Columns are separated by thin vertical gray lines.
- **Column 1: Example**
  - Contains a visual representation of a binary tree (circles with numbers for nodes, lines for edges).
  - Below the tree, a rectangular box with a gray border containing the output value.
  - In some sections (e.g., section 3), two trees are shown side-by-side with an arrow pointing from the left tree (Input) to the right tree (Output).
- **Column 2: AHA**
  - Header: Contains an icon (light bulb) and the text "AHA", centered.
  - Content: Left-aligned, wrapping text explaining the key insight.
- **Column 3: Pattern**
  - Header: Contains an icon (gear) and the text "Pattern", centered.
  - Content: Centered text indicating the traversal type and the specific path direction.
- **Column 4: Formula**
  - Header: Contains an icon (sigma) and the text "Formula", centered.
  - Content: Stacked rectangular boxes with thin gray borders containing text or mathematical conditions (formulas and base cases). Some boxes have a subtle light background fill.
- **Column 5: Code (Java)**
  - Header: Text "Code (Java)" centered.
  - Content: A block of monospaced code snippet, left-aligned, with syntax highlighting (e.g., green for comments).
- **Column 6: Complexity**
  - Header: Text "Complexity" centered.
  - Content: Lines of left-aligned text detailing Time and Space complexity.

## Bottom Summary Section
- A layout with three rounded-corner rectangular panels placed side-by-side at the bottom.
- **Panel 1 (Left): Postorder - When to use?**
  - Header: Icon with bold text.
  - Content: A bulleted list of points, left-aligned.
- **Panel 2 (Center): Quick Recap**
  - Header: Bold text centered.
  - Content: A 2-column tabular alignment without borders. Left side: Problem name. Right side: Key formula/operation.
- **Panel 3 (Right): Complexity Legend**
  - Header: Icon with bold colored text.
  - Content: Stacked lines of text defining variables and specific case complexities.

## Footer
- A single centered line of text at the very bottom.
- Starts with a star icon, followed by bold text, and then a sequence of text steps separated by right-pointing arrows.
