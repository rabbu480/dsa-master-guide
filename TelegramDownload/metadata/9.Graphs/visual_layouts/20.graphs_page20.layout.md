# Visual Layout Specification: Graph Pattern Guide (Page 16)

## 1. Global Visual Structure & Grid
- **Document Type:** Cheat Sheet / Quick Reference Guide.
- **Overall Layout:** Multi-row, multi-column grid layout, highly structured with distinct modular blocks.
- **Color Palette:**
  - **Primary:** Dark Blue (used for headers, primary text, and accents).
  - **Background:** White or very light gray, allowing high contrast.
  - **Accents:** Multi-colored squares for index (blues, greens, oranges, purples, etc.), light yellow/gray shading for table headers and alternate rows.

## 2. Header Section
- **Top-Left Badge:** A solid dark blue rectangular badge with white text "PAGE 16".
- **Main Title:** Centered, large dark blue sans-serif text "GRAPH PATTERN GUIDE" accompanied by a line-art open book icon.
- **Subtitle:** Centered, bold blue text "PAGE 16 — GRAPH CHEAT SHEETS & QUICK REFERENCE".
- **Tagline:** Centered, italicized text providing an encouraging slogan.

## 3. Block Level Analysis

### Row 1: Introduction & Index
- **Grid Setup:** 2 unequal columns (approx 1:3 ratio).
- **Left Column (How to Use):** 
  - Dark blue header bar with white text.
  - Numbered list using purple circular numbers.
  - A target/dartboard graphic icon positioned in the bottom right corner.
- **Right Column (Template Quick Index):** 
  - Dark blue header bar.
  - 3-column internal grid. Each item features a colored square badge containing a white letter (A to L), followed by the template name.

### Row 2: Core Algorithm Templates
- **Grid Setup:** 3 equal columns.
- **Blocks (1, 2, 3):**
  - **Headers:** Dark blue with a rounded number badge on the left.
  - **Content:** Code snippets aligned left, syntax highlighted subtly.
  - **Footer (Tips):** A light grey/yellow tinted horizontal bar at the bottom with a lightbulb icon and a short tip text.

### Row 3: Complexity & Comparisons
- **Grid Setup:** 4 equal columns.
- **Blocks (4, 5, 6, 7):**
  - **Headers:** Dark blue header bars.
  - **Content:** Tables. Header rows have a light blue/grey background. Columns are aligned with alternating row shading or clear grid lines for readability. Block 6 uses mathematical notations and symbols.
  - **Footer:** Block 6 and 7 feature small tip bars at the bottom with icons.

### Row 4: Advanced Algorithm Templates
- **Grid Setup:** 4 equal columns.
- **Blocks (8, 9, 10, 11):**
  - **Headers:** Dark blue header bars with rounded number badges.
  - **Content:** Dense code snippets.
  - **Footer:** Block 11 includes an informational tip bar at the bottom.

### Row 5: Pitfalls & Checklists
- **Grid Setup:** 3 equal columns.
- **Blocks (12, 13, 14):**
  - **Block 12 (Pitfalls):** 4-column table detailing mistakes and fixes.
  - **Block 13 (Edge Cases):** 2-column list of items utilizing checkbox icons for a checklist visual style.
  - **Block 14 (Recall Table):** 2-column mapping table.

### Row 6: Recaps & Tips
- **Grid Setup:** 3 equal columns.
- **Blocks (15, 16, 17):**
  - **Block 15 (Pattern Flow):** A horizontal process diagram (linear flowchart). Includes a sequence of 6 distinct line-art icons connected by directional arrows, with labels below each icon. A tip bar sits at the bottom.
  - **Block 16 (Interview Tips):** Bulleted list utilizing star icons instead of standard bullets.
  - **Block 17 (Next Page Preview):** Text-heavy block with a stylized roadmap/path icon on the right side.

## 4. Footer Section
- **Title:** Centered, small uppercase text indicating the "Cheat Pipeline".
- **Visual Representation:** A horizontal flowchart spanning the full width. Consists of 8 steps.
  - Each step has a circular/square line-art icon, a bold title, and a small subtitle in parentheses.
  - Steps are connected by right-facing arrows indicating sequence.
- **Alignment:** Perfectly centered, evenly spaced across the bottom margin.

## 5. Visual Alignments and Padding
- **Gaps:** Uniform gutters between columns and uniform margins between rows.
- **Borders:** Subtle gray borders outline each major block to enclose content cleanly.
- **Typography:** Sans-serif fonts used universally. Headers are capitalized. Code blocks use monospace fonts.
