1 WHEN TO USE BINARY SEARCH?
  • ✅ Data is sorted or can be converted to sorted.
  • ✅ We can eliminate half of the search space.
  • ✅ Answer looks like → F F F T T T (False → True)
  • ✅ We can check a condition in O(1) time.
  • ✅ Used for exact match, first/last occurrence, or finding answer in search space.
2 CLASSIC BINARY SEARCH TEMPLATE (EXACT MATCH)
int left = 0, right = n - 1;
while (left <= right) {
    int mid = left + (right - left) / 2; // safe mid

    if (nums[mid] == target) {
        return mid; // found
    } else if (nums[mid] < target) {
        left = mid + 1;     // search right half
    } else {
        right = mid - 1;    // search left half
    }
}
return -1; // not found
💡 Why mid = left + (right - left) / 2 ?
To avoid integer overflow that can happen in (left + right) / 2

7. FIRST & LAST OCCURRENCE TEMPLATES
First Occurrence (Lower Bound)
Find the first index where nums[mid] == target
int firstOccurrence(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    int ans = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {
            if (nums[mid] == target) ans = mid;
            right = mid - 1;  // move left
        } else {
            left = mid + 1;   // move right
        }
    }
    return ans;
}
Last Occurrence (Upper Bound)
Find the last index where nums[mid] == target
int lastOccurrence(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    int ans = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            if (nums[mid] == target) ans = mid;
            left = mid + 1;   // move right
        } else {
            right = mid - 1;  // move left
        }
    }
    return ans;
}
💡
PRO TIP: For First occurrence → shrink right when equal
For Last occurrence → shrink left when equal
9. BINARY SEARCH ON ANSWER
When to Use?
  • Answer is not an element from array.
  • We are asked to find minimum / maximum value that satisfies a condition.
  • The condition is monotonic (T...T...T or F...F...F).
General Template
int left = 0;             // minimum possible answer
int right = (int)1e9;     // maximum possible answer
int ans = -1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (isValid(mid)) {       // condition check
        ans = mid;            // store answer
        right = mid - 1;      // try for better (smaller) answer
    } else {
        left = mid + 1;       // try for bigger answer
    }
}
return ans;
Examples
  • Minimum days to make M bouquets
  • Allocate minimum pages
  • Koko eating bananas
  • Split array largest sum
11. COMMON MISTAKES & HOW TO AVOID THEM
Mistake Why It's Wrong Fix
❌ Using (left + right) / 2 Can overflow when left and right are large Use left + (right - left) / 2
❌ Incorrect boundary update Can cause infinite loop or wrong result Be careful with
left = mid + 1 or
right = mid - 1
❌ Not handling edge cases Empty array, size 1 array, target not found Always test edge cases
❌ Confusing first & last occurrence Logic difference in shrinking Remember:
first → shrink right
last → shrink left
❌ Wrong condition in rotated array Leads to eliminating wrong half Check which half is sorted first

14. BINARY SEARCH ON 2D MATRIX (ROW-WISE SORTED)
Example Matrix:
1 3 5 7
10 11 16 20
23 30 34 50
60 65 70 80
Search = 34
Approach:
  1. Treat matrix as 1D array.
  2. Index mapping:
    row = mid / m;
    col = mid % m;
  3. Apply normal Binary Search.
Code: 
int row = matrix.length, col = matrix[0].length;
int left = 0, right = row * col - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    int r = mid / col, c = mid % col;
    if (matrix[r][c] == target) return true;
    else if (matrix[r][c] < target) left = mid + 1;
    else right = mid - 1;
}
return false;
★
Works because each row is sorted and
first element of a row is greater than last of previous row.

Problem:
Array is sorted but size is unknown or very large.

Solution:
  1. Find the range (low, high) where target can exist.
  2. Apply Binary Search in that range.

15. SEARCH IN PEAK ELEMENT (BITONIC ARRAY)
Bitonic Array (First increasing then decreasing)
Array:
1 3 8 12 4 2
←───→
←───→
Search = 4
Steps:
  1. Find the peak element index.
  2. If target == peak → return true
  3. If target < peak → Binary Search in left (increasing part)
  4. If target > peak → Binary Search in right (decreasing part)
Find Peak Index
int l = 0, r = n - 1;
while (l < r) {
    int mid = l + (r - l) / 2;
    if (arr[mid] < arr[mid + 1])
        l = mid + 1;
    else
        r = mid;
}
return l;
Binary Search in Decreasing Order
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (arr[mid] == target)
        return true;
    else if (arr[mid] > target)
        l = mid + 1;
    else
        r = mid - 1;
}

22. COMMON EDGE CASES
  • Array with 1 element
    nums = [5], target = 5 → return 0
  • Target not present
    nums = [1,2,3,4], target = 10 → return -1
  • All elements same
    nums = [7,7,7,7], target = 7 → return first / last as per need
  • First element target
    nums = [1,2,3,4], target = 1 → return 0
  • Last element target
    nums = [1,2,3,4], target = 4 → return n-1
  • Check for overflow in mid calculation
    int mid = left + (right - left) / 2; // safe
23. DRY RUN TIPS

  • Update the pointers.
