LeetCode 1 — Two Sum Easy
Pattern DNA: DNA #15 (Prefix Sum / HashMap) | Template Used: A.13 | Complexity: Time O(N), Space O(N)

Commented Steps: 1. Iterate through numbers array. 2. Calculate complement target - nums[i]. 3. If complement exists in map, return indices. 4. Otherwise, put current number into map.

public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int diff = target - nums[i];
        if (map.containsKey(diff)) {
            return new int[]{map.get(diff), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{};
}
💡 AHA MOMENT: Store complement values to turn an O(N²) search into an O(N) single pass lookup.
LeetCode 15 — 3Sum Medium
Pattern DNA: DNA #13 (Two Pointers) | Template Used: A.11 | Complexity: Time O(N²), Space O(1)

Commented Steps: 1. Sort input array. 2. Fix first element `nums[i]`. 3. Use Two Pointers `left` and `right` to find pair summing to `-nums[i]`. 4. Skip duplicates for all 3 pointers.

public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // Skip dup i
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++; // Skip dup l
                while (l < r && nums[r] == nums[r - 1]) r--; // Skip dup r
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
LeetCode 42 — Trapping Rain Water Hard
Pattern DNA: DNA #13 / DNA #17 | Template Used: A.11 / A.14 | Complexity: Time O(N), Space O(1)

Commented Steps: Maintain leftMax and rightMax. Move smaller side pointer toward center; water trapped at position is maxSide - currentHeight.

public int trap(int[] height) {
    int l = 0, r = height.length - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (l < r) {
        if (height[l] < height[r]) {
            if (height[l] >= leftMax) leftMax = height[l];
            else water += leftMax - height[l];
            l++;
        } else {
            if (height[r] >= rightMax) rightMax = height[r];
            else water += rightMax - height[r];
            r--;
        }
    }
    return water;
}
