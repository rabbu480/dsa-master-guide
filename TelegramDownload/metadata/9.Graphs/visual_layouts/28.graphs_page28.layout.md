# Visual Layout Specification

## Overall Structure
- A dense, cheat-sheet style document utilizing a mostly 3-column grid layout.
- The document is divided into a Header, three main rows of 3-column content blocks, a full-width bottom pipeline block, and a footer string.
- Each content block is numbered 1 through 10, featuring a distinct solid color header and a contrasting light or white background for its body.

## Header
- **Layout**: Full width, split into three horizontal zones (Left, Center, Right).
- **Left**: A dark blue rounded rectangle containing white text.
- **Center**: Prominent dark blue title text, flanked by a book icon on the left. Below the main title, a smaller subtitle is flanked by arrows.
- **Right**: A white rectangular box with a green border containing green text, aligned to the top right.

## Main Grid Layout
The main body is a 3x3 grid of blocks (numbered 1 to 9).

### Row 1
- **Block 1**: 
  - **Header Color**: Dark Blue
  - **Layout**: Single column list.
  - **Visual Elements**: Each list item is prefixed with a yellow lightbulb icon. Left-aligned text. Background is light blue.
- **Block 2**:
  - **Header Color**: Dark Green
  - **Layout**: 3-column table structure.
  - **Visual Elements**: The first column of the table features various icons (grid, graduation cap, people, plane, water drop, link, list, mountain). Text is mostly center-aligned or left-aligned within cells.
- **Block 3**:
  - **Header Color**: Purple
  - **Layout**: Flowchart diagram.
  - **Visual Elements**: Uses rounded rectangles for actions/states, diamonds for decision points, and arrows with "YES"/"NO" labels for flow direction. Nodes are color-coded (purple, teal, orange borders/fills).

### Row 2
- **Block 4**:
  - **Header Color**: Orange
  - **Layout**: 2-column table.
  - **Visual Elements**: Text is center-aligned. A shaded tip box at the bottom containing a lightbulb icon.
- **Block 5**:
  - **Header Color**: Dark Blue
  - **Layout**: 3-column table.
  - **Visual Elements**: Text is center-aligned. A shaded note box at the bottom with a lightbulb icon.
- **Block 6**:
  - **Header Color**: Teal
  - **Layout**: Single column list.
  - **Visual Elements**: Each list item is prefixed with a red 'X' icon. A shaded tip box at the bottom with a lightbulb icon.

### Row 3
- **Block 7**:
  - **Header Color**: Purple
  - **Layout**: 2-column table.
  - **Visual Elements**: Center-aligned text with subtle row dividers.
- **Block 8**:
  - **Header Color**: Orange
  - **Layout**: 2-column table.
  - **Visual Elements**: Center-aligned text. A shaded note box at the bottom with a lightbulb icon.
- **Block 9**:
  - **Header Color**: Dark Green
  - **Layout**: Single column list.
  - **Visual Elements**: Each list item is prefixed with a green square checkmark icon.

## Full-Width Bottom Block (Block 10)
- **Header Color**: Red
- **Layout**: Full page width, horizontal flowchart-style progression spanning the entire width.
- **Visual Elements**: 
  - Contains 7 steps laid out horizontally left-to-right.
  - Each step has a circular outlined icon at the top, a numbered bold title, and a short bulleted list below it.
  - Steps are connected by right-facing arrows placed between the circular icons.
  - Icons represent various stages of problem-solving (e.g., thinking, graph network, list, boxes, code tags, checkmark, trophy).

## Footer
- **Layout**: Centered text lines at the very bottom of the page.
- **Visual Elements**: 
  - First line: Text in orange, bold, center-aligned, framed with a trophy icon on the left.
  - Second line: Contains a star icon on the left, dark blue text, and a rocket icon on the right.
