# Visual Layout Specification

## Overall Grid Structure
- **Global Layout**: A rigid hierarchical grid system.
- **Top Section**: Full-width title and subtitle banner.
- **Main Section**: 4-column x 2-row grid containing 8 distinct panels (cards).
- **Bottom Section**: 4-column x 1-row grid containing reference tables and lists.
- **Footer Section**: Full-width narrow banner at the bottom.
- **Background**: White, with distinct card outlines and color-coded accents.

## Panel Layout Details (8 Pattern Cards)
Each card follows a consistent internal 2-column layout.
- **Header**: Contains a colored number square on the left, an uppercase bold title, and a small colored badge (Data Structure) aligned to the right.
- **Body Grid**: Split into a Left Column (approx 60% width) and Right Column (approx 40% width).
  - **Left Column**: Contains headings "When to use", "Key Idea", and "How it Works / Formula / Code", followed by text or code blocks.
  - **Right Column**: Contains "Example", "Input/Output" text, and custom visual diagrams (e.g., array boxes, tables, arrows showing mappings, 3x3 grids).
- **Footer**: A full-width colored banner at the bottom of the card displaying "Time: O(...) | Space: O(...)".

## Color Coding System
- **Title Banner**: Dark navy blue background, white and yellow text.
- **Panel 1 & 5 (Columns 1)**: Forest Green theme (Header number, badge, footer banner).
- **Panel 2 & 6 (Columns 2)**: Royal Blue theme.
- **Panel 3 & 7 (Columns 3)**: Purple theme.
- **Panel 4 & 8 (Columns 4)**: Orange/Brown theme.
- **Bottom Section Headers**: Black text, bold.
- **Footer Banner**: Dark navy blue background, white text, yellow star icon.

## Visual Representations within Panels
- **Panel 1**: Simple 3-box array diagram with an arrow pointing to a "duplicate" label.
- **Panel 2**: Table diagram showing "Num" and "Freq" columns.
- **Panel 3**: Array diagram with indices above boxes, and mathematical subtraction indicating target minus value.
- **Panel 4**: Input/Output array representations and conceptual mapping (keys pointing to grouped lists).
- **Panel 5**: Array diagram showing length prefix encoding logic.
- **Panel 6**: Table demonstrating prefix and suffix calculations across array indices.
- **Panel 7**: Unordered array boxes converted conceptually into sequence lengths.
- **Panel 8**: 3x3 colored grid matrix representing Sudoku sub-boxes with (row, col) coordinates.

## Bottom Reference Section
- **Block 1**: 2-column table-like layout with icons (checkboxes) and text descriptions.
- **Block 2**: Bulleted list of formulas and code snippets.
- **Block 3**: Split into two parts: top half bulleted list, bottom half code snippet.
- **Block 4**: 3-column table showing operation complexities, followed by an "IMPORTANT NOTES" bulleted section with red warning text.

## Alignments and Spacing
- Strict vertical and horizontal alignments between all grid cells.
- Padding inside cards ensures breathing room around text and diagrams.
- Borders are thin, grey/black lines delineating the distinct blocks and cards.
