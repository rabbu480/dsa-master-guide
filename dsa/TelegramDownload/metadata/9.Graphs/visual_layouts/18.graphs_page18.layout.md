# Visual Layout Specification: Graph Pattern Guide (Page 14)

## Overview
This document specifies the visual structure and layout for "Page 14: Advanced Graph Patterns Guide". The layout utilizes a structured, modular grid system with clearly defined sections, color-coded headers, code blocks, tables, and iconography to present complex algorithmic patterns.

## Global Layout Rules
*   **Grid System**: A predominantly 3-column grid for the main content (pattern examples), transitioning to a 4-column layout for summary tables, and flexible full-width or split sections for headers and footers.
*   **Typography**: Clean sans-serif fonts. Headers use bold, capitalized text, often in white against colored backgrounds. Monospace fonts are used for all code snippets.
*   **Color Palette**:
    *   **Primary Accent**: Deep Blue (used for main headers and section numbers).
    *   **Secondary Accents**: Purple ("How to Use"), Teal (Code comments), Light Blue (Base Template labels).
    *   **Template Badges**: Specific colors mapped to letters (e.g., A=Dark Blue, B=Green, C=Purple, D=Orange, E=Red, F=Teal).
*   **Borders & Dividers**: Thin gray lines separate columns and distinct logical sections within blocks.
*   **Spacing**: Tight but clear padding within code blocks and tables to maximize information density.

## Component Specifications

### 1. Header Section
*   **Type**: Full-width block.
*   **Elements**:
    *   Top left: "PAGE 14" inside a solid dark blue rectangle.
    *   Center: Main title "GRAPH PATTERN GUIDE" accompanied by an open book icon.
    *   Subtitle: "PAGE 14 - ADVANCED GRAPH PATTERNS GUIDE (APPLY TEMPLATES)".
    *   Tagline: Italicized quote centered below the subtitle.

### 2. Top Information Blocks
*   **Layout**: 2-column split (approx. 30% / 70%).
*   **Left Column ("HOW TO USE THIS PAGE")**:
    *   Header: Solid purple block with white text.
    *   Content: A 6-point ordered list with a stylized target/bullseye icon aligned to the right.
*   **Right Column ("TEMPLATE LEGEND")**:
    *   Header: Solid dark blue block with white text.
    *   Content: A 2x3 grid of legend items. Each item consists of a colored square containing a white letter (A-F) followed by descriptive text.

### 3. Main Content Grid (Patterns 1-6)
*   **Layout**: A 3-column by 2-row grid.
*   **Structure per Block**:
    *   **Header Row**: A continuous dark blue strip containing the number (in a lighter blue square), the pattern name, and a corresponding colored letter badge (from the legend) floating on the far right.
    *   **Base Template**: Centered text in blue font immediately below the header.
    *   **Problem**: Short text description.
    *   **Changed Lines**: The core content block featuring monospace Java code. Keywords are highlighted (e.g., blue for types/control flow, green for comments).
    *   **Attributes Table**: A 3-column layout (Caller, Return, Key Idea) without explicit cell borders, separated by whitespace.
    *   **AHA Moment**: A bold line prefaced by a light bulb icon.
    *   **Complexity & Tip**: A 2-column split at the bottom of the block showing Time/Space complexity on the left and an "Interview Tip" on the right.

### 4. Bottom Summary Tables (Sections 7-10)
*   **Layout**: A 4-column row of equal width blocks.
*   **Block Headers**: Solid dark blue strips with section numbers and titles in white.
*   **Block 7 (Changed Lines Summary)**: 3-column table (Problem #, Base Template, Main Changes).
*   **Block 8 (Complexity Quick Guide)**: 3-column table (Pattern, Time, Space) with gray alternating row backgrounds.
*   **Block 9 (Return Type Guide)**: 3-column table (Pattern, Return Type, Use When).
*   **Block 10 (Interview Checklist)**: A vertical list of 5 items, each preceded by a checked box icon.

### 5. Footer Section
*   **Layout**: Two stacked sections with multi-column elements.
*   **Upper Footer (Sections 11 & 12)**:
