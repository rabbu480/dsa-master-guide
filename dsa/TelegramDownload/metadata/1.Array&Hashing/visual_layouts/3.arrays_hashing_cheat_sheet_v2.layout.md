# Visual Layout Specification: Arrays & Hashing Cheat Sheet

## 1. Overall Document Structure
- **Canvas / Background:** Dark theme (deep blue/black background) with neon/bright highlight colors.
- **Typography:** Sans-serif fonts used throughout. Titles are bold and capitalized. Code snippets use monospaced fonts.
- **Grid Layout:** 
  - **Header:** Full width.
  - **Section 1 (Top Row):** 3-column layout.
  - **Section 2 (Middle Row):** Full width (1 column).
  - **Section 3 (Bottom Row):** Masonry or multi-column layout for snippets and tips, spanning the full width but divided into 3 primary columns of varying heights.
  - **Footer:** Full width.

## 2. Global Styling & Theming
- **Section Headers:** Pill-shaped (rounded rectangles) with a distinct background color and white text. Each header is numbered (1 to 5) inside a circular badge or just as a number.
- **Borders:** Thin, glowing or semi-transparent blue borders around major sections and table cells.
- **Icons:** Extensive use of emojis and flat icons (e.g., checkmarks, hash symbols, charts, scales, lightbulbs, cross marks) as bullet points or visual anchors.
