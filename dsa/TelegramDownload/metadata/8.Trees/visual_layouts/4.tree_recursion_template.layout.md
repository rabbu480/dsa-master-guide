# Visual Layout Specification: Tree Recursion Template

## 1. Global Layout Grid
- **Document Structure**: The document utilizes a structured grid, primarily divided into a full-width header and footer, with the main content area arranged in a responsive 2-column layout.
- **Overall Spacing**: Consistent padding around all major sections and uniform margins between columns and rows.
- **Background**: The document background is primarily white with distinct colored headers for grouping.

## 2. Main Header Section (Full Width)
- **Top Bar**:
  - **Left**: A dark purple square badge containing a white number.
  - **Center**: Large, bold, dark navy-blue typography for the main title, horizontally centered.
- **Subtitle**: A smaller tagline centered below the main title, flanked by horizontal lines extending outwards.

## 3. Top Content Section (2-Column Split)
This section is split roughly 55/45 (Left/Right).

### Left Column: Recursion Flow (Section 3.1)
- **Header**: Dark purple background with white text, spanning the width of the column.
- **Content**: A vertical flowchart representing 6 steps.
  - **Left Edge**: A vertical timeline-style connecting line with numbered circles (blue and red).
  - **Middle**: Bold colored text labels (BASE CASE, FAITH, RECUR LEFT, etc.) aligned left.
  - **Right**: A description text block and an adjacent rounded rectangular box containing code snippets.
  - **Colors**: Numbers and text utilize dark blue, green, and red corresponding to the logic flow.

### Right Column: Templates (Universal & Key Idea)
- **Universal Template Block**:
  - **Header**: Dark purple background, white text.
  - **Content**: A light gray bounding box containing monospaced text representing code structure, aligned left.
- **Key Idea Block**:
  - **Placement**: Directly below the template block.
  - **Visuals**: A light gray rectangular box featuring a line-art lightbulb icon on the left, and a bulleted list on the right.

## 4. Interstitial Banner (Full Width)
- **Placement**: A full-width horizontal bar separating the top section from the middle section.
- **Style**: Light yellow background with a thin gold border.
- **Content**: A centered text string accompanied by a small star icon on the left.

## 5. Middle Content Section (2-Column Split)
This section is split equally 50/50.

### Left Column: Return Type Table (Section 3.2)
- **Header**: Dark blue background with white text.
- **Content**: A 3-column table grid with light gray borders.
  - **Columns**: Aligned center or left depending on content.
  - **Colors**: The first column features color-coded text (black, green, brown, red) to denote different types.

### Right Column: Traversal Selection Table (Section 3.3)
- **Header**: Dark green background with white text.
- **Content**: A 4-column table grid with light gray borders.
  - **Visuals**: The first column includes small illustrative vector icons (hierarchy node, bar chart, nodes, list).
  - **Alignment**: Text is centered or left-aligned within cells.

## 6. Bottom Content Section (2-Column Split)
This section is split roughly 60/40 (Left/Right).

### Left Column: Decision Guide Flowchart (Section 3.4)
- **Header**: Dark red background with white text.
- **Content - Flowchart**:
  - A top central rectangular node branching out downwards into four distinct vertical paths.
  - Each path contains three vertically stacked rounded rectangular nodes connected by downward arrows.
  - **Colors**: Node borders are light blue and light green. Text is color-coded.
- **Content - Remember Block**:
  - **Placement**: Below the flowchart.
  - **Visuals**: A target/dart icon on the left, beside a bulleted list of principles.

### Right Column: Base Cases and Tips (Sections 3.5 & 3.6)
- **Section 3.5 (Common Base Cases)**:
  - **Header**: Dark blue background with white text.
  - **Content**: A 2-column borderless table structure. The left column contains monospaced text (code), and the right column contains descriptive text. Rows are separated by thin horizontal gray lines.
- **Section 3.6 (Tips to Master Recursion)**:
  - **Header**: Dark blue background with white text.
  - **Content**: A numbered list using green checkmark icons instead of standard bullets.
- **Golden Rule Callout**:
  - **Placement**: Floating to the right of the Tips list.
  - **Visuals**: A light yellow box with a gold border, containing a trophy icon and bold centered text.

## 7. Footer Section (Full Width)
- **Placement**: At the very bottom of the document.
- **Style**: A full-width light purple banner.
- **Visuals**: A rocket ship icon on the left, followed by bold text ("FINAL MANTRA"), and a horizontally laid out text sequence separated by arrows.
