A.1 — Depth-First Search (DFS) Recursive A.1
Trigger Keywords "all paths", "connected components", "explore deeply", "tree/graph traversal"
Time Complexity O(V + E) Graph / O(N) Tree
Space Complexity O(V) Recursion Stack
public void dfs(int u, List<List<Integer>> adj, boolean[] visited) {
    // Base Case & State Mark
    visited[u] = true;
    // Process Node u (e.g. add to path)
    
    for (int v : adj.get(u)) {
        if (!visited[v]) {
            dfs(v, adj, visited);
        }
    }
}
⚠️ GOTCHA: Always mark visited BEFORE making recursive calls to avoid infinite cycles in undirected or graph cyclic inputs.
A.2 — Depth-First Search (DFS) Iterative A.2
Trigger Keywords "deep recursion protection", "explicit stack DFS", "avoid stack overflow"
Time Complexity O(V + E)
Space Complexity O(V) Explicit Stack
public void dfsIterative(int start, List<List<Integer>> adj, int n) {
    boolean[] visited = new boolean[n];
    Deque<Integer> stack = new ArrayDeque<>();
    
    stack.push(start);
    
    while (!stack.isEmpty()) {
        int u = stack.pop();
        if (visited[u]) continue;
        visited[u] = true;
        
        for (int v : adj.get(u)) {
            if (!visited[v]) {
                stack.push(v);
            }
        }
    }
}
⚠️ GOTCHA: Pop from stack and check `visited[u]` inside the loop because nodes may be pushed multiple times before visiting.
A.3 — Tree DFS (Pre-Order / In-Order / Post-Order) A.3
Trigger Keywords "tree traversal", "bottom-up calculation", "path evaluation"
Time Complexity O(N)
Space Complexity O(H) where H = tree height
public int treeDFS(TreeNode root) {
    if (root == null) return 0; // Base case
    
    // Pre-order work here (Top-down)
    int left = treeDFS(root.left);
    // In-order work here (BST sorted order)
    int right = treeDFS(root.right);
    // Post-order work here (Bottom-up aggregate, e.g. Height = 1 + Math.max(left, right))
    
    return 1 + Math.max(left, right);
}
⚠️ GOTCHA: Use Post-order (bottom-up) when child results are mandatory to compute current node result.
A.4 — 2D Grid DFS (Islands / Matrix Exploration) A.4
Trigger Keywords "connected islands", "matrix traversal", "grid search"
Time Complexity O(R × C)
Space Complexity O(R × C) Stack worst case
private static final int[][] DIRS = {{0,1}, {1,0}, {0,-1}, {-1,0}};

public void gridDFS(char[][] grid, int r, int c) {
    int rows = grid.length, cols = grid[0].length;
    if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] != '1') {
        return;
    }
    
    grid[r][c] = '0'; // Mark visited in-place
    for (int[] d : DIRS) {
        gridDFS(grid, r + d[0], c + d[1]);
    }
}
⚠️ GOTCHA: Check boundary conditions `r < 0 || r >= rows || c < 0 || c >= cols` FIRST before indexing matrix.
A.5 — Breadth-First Search (BFS Standard / Level-Order) A.5
Trigger Keywords "shortest path unweighted", "minimum steps", "level order"
Time Complexity O(V + E)
Space Complexity O(V) Queue size
public int bfsShortestPath(int start, int target, List<List<Integer>> adj, int n) {
    Queue<Integer> queue = new ArrayDeque<>();
    boolean[] visited = new boolean[n];
    
    queue.offer(start);
    visited[start] = true;
    int level = 0;
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int u = queue.poll();
            if (u == target) return level;
            
            for (int v : adj.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    queue.offer(v);
                }
            }
        }
        level++;
    }
    return -1;
}
⚠️ GOTCHA: Mark `visited[v] = true` IMMEDIATELY upon pushing into Queue to prevent duplicate queue entries.

public int[][] updateMatrix(int[][] mat) {
    int r = mat.length, c = mat[0].length;
    Queue<int[]> queue = new ArrayDeque<>();
    boolean[][] visited = new boolean[r][c];
    
    // Add ALL initial sources to queue at step 0
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            if (mat[i][j] == 0) {
                queue.offer(new int[]{i, j});
                visited[i][j] = true;

        }
    }
    // Standard BFS queue drain follows...
    return mat;
}
⚠️ GOTCHA: Push ALL starting sources into the queue before starting the level-by-level loop.
A.7 — Topological Sort (Kahn's BFS Algorithm) A.7
Trigger Keywords "prerequisites", "dependency order", "cycle detection DAG"
Time Complexity O(V + E)
Space Complexity O(V + E)
public int[] findOrder(int numCourses, int[][] prerequisites) {
    int[] indegree = new int[numCourses];
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
    
    for (int[] p : prerequisites) {
        adj.get(p[1]).add(p[0]);
        indegree[p[0]]++;
    }
    
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) q.offer(i);
    }
    
    int[] order = new int[numCourses];
    int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : adj.get(u)) {
            if (--indegree[v] == 0) q.offer(v);
        }
    }
    return idx == numCourses ? order : new int[0]; // If idx != N -> Cycle exists!
}
⚠️ GOTCHA: If `processedCount != V` at the end, the graph has a cycle (not a valid DAG).
A.8 — Topological Sort (DFS Post-Order Reverse) A.8
Trigger Keywords "cycle detection via 3-color DFS", "post-order stack topological"
Time Complexity O(V + E)
Space Complexity O(V)
// State: 0 = Unvisited, 1 = Visiting (In Current Path), 2 = Visited (Done)
public boolean hasCycle(int u, List<List<Integer>> adj, int[] state, Deque<Integer> stack) {
    state[u] = 1; // Mark Visiting
    for (int v : adj.get(u)) {
        if (state[v] == 1) return true; // Cycle detected!
        if (state[v] == 0 && hasCycle(v, adj, state, stack)) return true;
    }
    state[u] = 2; // Mark Visited
    stack.push(u); // Add to result in post-order
    return false;
}
⚠️ GOTCHA: `state == 1` means back-edge found (cycle). Reverse the post-order stack to get valid topological order.
A.9 — Binary Search (Exact, Lower Bound, Upper Bound) A.9
Trigger Keywords "sorted array lookup", "first position >=", "last position <="
Time Complexity O(log N)
Space Complexity O(1)
// Lower Bound: First index where arr[i] >= target
public int lowerBound(int[] arr, int target) {
    int lo = 0, hi = arr.length; // Note: hi = arr.length
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] >= target) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
⚠️ GOTCHA: Use `lo + (hi - lo) / 2` to avoid integer overflow compared to `(lo + hi) / 2`.

A.11 — Two Pointers (Opposite Ends & Same Direction) A.11

public int[] twoSumSorted(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
⚠️ GOTCHA: Opposite direction pointers require array to be SORTED.
A.12 — Sliding Window (Variable Size) A.12
Trigger Keywords "longest substring with at most K...", "minimum window substring"
Time Complexity O(N) Amortized
Space Complexity O(K) Frequency Map
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> counts = new HashMap<>();
    int left = 0, maxLen = 0;
    
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        counts.put(c, counts.getOrDefault(c, 0) + 1);
        
        // Shrink window if constraint is violated
        while (counts.get(c) > 1) { 
            char leftChar = s.charAt(left);
            counts.put(leftChar, counts.get(leftChar) - 1);
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
⚠️ GOTCHA: Both `left` and `right` move rightward only; each element is processed at most twice (O(N) total).

A.14 — Monotonic Stack (Next Greater Element) A.14
Trigger Keywords "next greater / smaller element", "histogram area", "daily temperatures"
Time Complexity O(N) Amortized
Space Complexity O(N)
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    Deque<Integer> stack = new ArrayDeque<>(); // Stores indices
    
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            int prevIdx = stack.pop();
            res[prevIdx] = nums[i];
        }
        stack.push(i);
    }
    while (!stack.isEmpty()) res[stack.pop()] = -1;
    return res;
}
⚠️ GOTCHA: Always store INDICES in stack rather than raw values to easily calculate distances/windows.
A.15 — Monotonic Queue (Sliding Window Maximum) A.15
Trigger Keywords "max/min of every sliding window of size K"
Time Complexity O(N) Total
Space Complexity O(K) Deque size
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> q = new ArrayDeque<>(); // Monotonic Decreasing Deque of indices
    int[] res = new int[nums.length - k + 1];
    
    for (int i = 0; i < nums.length; i++) {
        // Remove indices out of window bounds
        if (!q.isEmpty() && q.peekFirst() < i - k + 1) q.pollFirst();
        // Maintain monotonic decreasing property
        while (!q.isEmpty() && nums[q.peekLast()] <= nums[i]) q.pollLast();
        
        q.offerLast(i);
        if (i >= k - 1) res[i - k + 1] = nums[q.peekFirst()];
    }
    return res;
}
⚠️ GOTCHA: Front of deque `q.peekFirst()` always holds index of maximum element in current window.
A.16 — PriorityQueue / Min-Heap for Top-K Problems A.16
Trigger Keywords "Kth largest element", "top K frequent", "k closest points"
Time Complexity O(N log K)
Space Complexity O(K)
public int findKthLargest(int[] nums, int k) {
    // Min-heap of size K
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();
    
    for (int num : nums) {
        minHeap.offer(num);
        if (minHeap.size() > k) {
            minHeap.poll(); // Evict smallest element
        }
    }
    return minHeap.peek(); // Root is K-th largest
}
⚠️ GOTCHA: Use MIN-HEAP for Kth LARGEST problem to keep memory capped at O(K).
A.17 — K-Way Merge (PriorityQueue) A.17
Trigger Keywords "merge K sorted lists/arrays", "kth smallest in sorted matrix"
Time Complexity O(N log K)
Space Complexity O(K) Heap size
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) {
        if (node != null) pq.offer(node);
    }
    
    ListNode dummy = new ListNode(0), curr = dummy;
    while (!pq.isEmpty()) {
        ListNode node = pq.poll();
        curr.next = node;
        curr = curr.next;
        if (node.next != null) pq.offer(node.next);
    }
    return dummy.next;
}
⚠️ GOTCHA: Offer `node.next` back to heap immediately after polling `node`.
A.18 — Disjoint Set Union (Union-Find with Path Compression & Rank) A.18
Trigger Keywords "connected components", "dynamic connectivity", "redundant connection"
Time Complexity O(α(N)) ≈ O(1) Amortized
Space Complexity O(N)
class UnionFind {
    int[] parent, rank;
    int count;
    
    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        count = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    public int find(int i) {
        if (parent[i] != i) parent[i] = find(parent[i]); // Path compression
        return parent[i];
    }
    
    public boolean union(int i, int j) {
        int rootI = find(i), rootJ = find(j);
        if (rootI == rootJ) return false;
        
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
        else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
        else { parent[rootJ] = rootI; rank[rootI]++; }
        count--;
        return true;
    }
}
⚠️ GOTCHA: Always execute `find(i)` to get root components before doing comparisons or updates.
A.19 — Dijkstra's Algorithm (Single Source Shortest Path) A.19
Trigger Keywords "shortest path non-negative weights", "minimum effort/cost network"
Time Complexity O((V + E) log V)
Space Complexity O(V + E)
public int[] dijkstra(int start, List<List<int[]>> adj, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]); // [node, distance]
    pq.offer(new int[]{start, 0});
    
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int u = curr[0], d = curr[1];
        
        if (d > dist[u]) continue; // Skip stale entries
        
        for (int[] edge : adj.get(u)) {
            int v = edge[0], weight = edge[1];
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
⚠️ GOTCHA: Dijkstra DOES NOT work with negative edge weights. Use `if (d > dist[u]) continue;` to discard stale PQ nodes.
A.20 — Bellman-Ford Algorithm (Handles Negative Edges & Cycles) A.20
Trigger Keywords "negative edge weights", "detect negative weight cycle", "at most K stops"
Time Complexity O(V × E)
Space Complexity O(V)
public int[] bellmanFord(int start, int[][] edges, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    // Relax all edges V-1 times
    for (int i = 1; i < n; i++) {
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    return dist;
}
⚠️ GOTCHA: If an N-th iteration successfully relaxes any edge, a negative weight cycle exists in the graph.
A.21 — Trie (Prefix Tree Canonical Class) A.21
Trigger Keywords "prefix matching", "autocomplete", "word search II dictionary"
Time Complexity O(L) per insert/search
Space Complexity O(N × L × Alphabet)
class Trie {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isWord = false;
    }
    
    private final TrieNode root = new TrieNode();
    
    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
        }
        node.isWord = true;
    }
    
    public boolean startsWith(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return false;
            node = node.children[idx];
        }
        return true;
    }
}
⚠️ GOTCHA: `startsWith` checks for non-null node path, while `search` additionally verifies `node.isWord == true`.
A.22 — Backtracking Universal Template A.22
Trigger Keywords "subsets", "permutations", "combination sum", "n-queens"
Time Complexity O(2^N) or O(N!)
Space Complexity O(N) Recursion Depth
public void backtrack(int start, List<Integer> path, int[] nums, List<List<Integer>> res) {
    // 1. Add valid candidate to result
    res.add(new ArrayList<>(path));
    
    for (int i = start; i < nums.length; i++) {
        // Skip duplicates if array is sorted: if (i > start && nums[i] == nums[i-1]) continue;
        
        // 2. CHOOSE
        path.add(nums[i]);
        // 3. EXPLORE
        backtrack(i + 1, path, nums, res); // Use (i) if elements can be reused
        // 4. UNCHOOSE
        path.remove(path.size() - 1);
    }
}
⚠️ GOTCHA: Always pass a new copy `new ArrayList<>(path)` when adding to final result list.
A.23 — DP Memoization Skeleton (Top-Down) A.23
Trigger Keywords "overlapping subproblems", "min/max profit", "count ways"
Time Complexity O(States × Transitions)
Space Complexity O(States) Cache + Stack
public int solveDP(int i, int j, int[][] memo, int[] nums) {
    if (i >= nums.length) return 0; // Base Case
    if (memo[i][j] != -1) return memo[i][j]; // Cache hit
    
    // Recurrence Relation
    int option1 = solveDP(i + 1, j, memo, nums);
    int option2 = nums[i] + solveDP(i + 2, j, memo, nums);
    
    return memo[i][j] = Math.max(option1, option2); // Store & Return
}
⚠️ GOTCHA: Initialize memo table with a Sentinel value (e.g. `-1`) that cannot be a valid state result.
A.24 — DP Tabulation Skeleton (Bottom-Up) A.24
Trigger Keywords "iterative DP", "space optimization", "no stack overflow"
Time Complexity O(N × M)
Space Complexity O(N × M) or O(M)
public int knapsackTab(int[] wt, int[] val, int W) {
    int n = wt.length;
    int[][] dp = new int[n + 1][W + 1];
    
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            if (wt[i - 1] <= w) {
                dp[i][w] = Math.max(dp[i - 1][w], val[i - 1] + dp[i - 1][w - wt[i - 1]]);
            } else {
                dp[i][w] = dp[i - 1][w];
            }
        }
    }
    return dp[n][W];
}
⚠️ GOTCHA: When optimizing 2D DP to 1D DP array, iterate capacity backwards `for (int w = W; w >= wt[i]; w--)` to avoid overwriting values from current item iteration.
