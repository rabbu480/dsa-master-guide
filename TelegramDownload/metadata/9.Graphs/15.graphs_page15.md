### 1 REDUNDANT CONNECTION [C]
**Base Template:** Cycle Detection (Undirected)
**Problem:** Find the edge that creates a cycle (first redundant edge).
**Changed Lines (from Template)**
```java
// For each edge
for (int[] e : edges) {
    int u = e[0], v = e[1];
    if (connected(u, v)) return e;  // cycle found
    union(u, v);
}
return new int[0];
```
* **Caller:** `findRedundantConnection(edges)`
* **Return:** `int[2]` (edge)
* **Key Idea:** If already connected, this edge is extra.

💡 **AHA:** The first edge connecting two already connected nodes forms a cycle.

* **Complexity:** Time: O(N α(N)), Space: O(N)
* **Interview Tip:** Stop and return immediately when cycle found.

### 2 GRAPH VALID TREE [C]
**Base Template:** Cycle Detection + Components Count
**Problem:** Check if edges form a valid tree.
**Changed Lines (from Template)**
```java
// n = number of nodes
if (edges.length != n - 1) return false;  // must have n-1 edges

for (int[] e : edges) {
    int u = e[0], v = e[1];
    if (connected(u, v)) return false;  // cycle
    union(u, v);
}
return count == 1;  // single component
```
* **Caller:** `validTree(n, edges)`
* **Return:** `boolean`
* **Key Idea:** No cycle + single component

💡 **AHA:** Tree = (n-1 edges) + (No cycle) + (Connected)

* **Complexity:** Time: O(N α(N)), Space: O(N)
* **Interview Tip:** Always check `edges.length == n - 1` first.

### 3 NUMBER OF PROVINCES [D]
**Base Template:** Components Count
**Problem:** Count how many connected components (provinces) exist.
**Changed Lines (from Template)**
```java
// isConnected[i][j] = 1 if i and j are connected
int n = isConnected.length;
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (isConnected[i][j] == 1) union(i, j);
    }
}
return count;  // number of components
```
* **Caller:** `findCircleNum(isConnected)`
* **Return:** `int`
* **Key Idea:** Union every connected pair, return count

💡 **AHA:** Each component represents one province.

* **Complexity:** Time: O(N² α(N)), Space: O(N)
* **Interview Tip:** Matrix input -> check only upper triangle.

### 4 SURROUNDED REGIONS [I]
**Base Template:** Max Area / Island (Union Adjacent Cells)
**Problem:** Flip all 'O' that are surrounded by 'X' to 'X'. 'O' connected to boundary stays 'O'.
**Changed Lines (from Template)**
```java
// 1. Add a dummy node: dummy = m*n
// 2. Union boundary 'O' with dummy
// 3. Union all 'O' with 4 neighbors
// 4. Final: if connected(cell, dummy) -> keep 'O' else ->'X'
```
* **Caller:** `solve(board)`
* **Return:** `void`
* **Key Idea:** Boundary safe 'O' connected to dummy node

💡 **AHA:** Dummy node represents all boundary 'O'.

* **Complexity:** Time: O(M*N α(M*N)), Space: O(M*N)
* **Interview Tip:** Process boundary first, then inner cells.

### 5 MAKING A LARGE ISLAND [I]
**Base Template:** Max Area / Island
**Problem:** Flip at most one 0 to 1 to get the largest island size.
**Changed Lines (from Template)**
```java
// 1. Union all existing 1's and calc size of each root
// 2. For each 0 cell, try making it 1
//    Take unique neighbor roots, sum their sizes + 1
```
* **Caller:** `largestIsland(grid)`
* **Return:** `int`
* **Key Idea:** Merge unique neighboring islands around 0

💡 **AHA:** Use Set to avoid double counting same island.

* **Complexity:** Time: O(M*N α(M*N)), Space: O(M*N)
* **Interview Tip:** Don't forget +1 for the flipped cell itself.

### 6 NUMBER OF OPERATIONS TO CONNECT NETWORK [C]
**Base Template:** Components Count
**Problem:** Return minimum operations to connect all computers.
**Changed Lines (from Template)**
```java
// After processing all connections
int components = count; // number of components
int extra = connections.length - (n - components);
// extra edges available
return (extra >= components - 1) ? components - 1 : -1;
```
* **Caller:** `makeConnected(n, connections)`
* **Return:** `int`
* **Key Idea:** Need (components-1) extra edges

💡 **AHA:** Extra edges = totalEdges - (n - components)

* **Complexity:** Time: O(N α(N)), Space: O(N)
* **Interview Tip:** Check if enough extra edges exist.

### 8 UNION FIND TEMPLATE RECAP (From Page 10)
**Find with Path Compression**
```java
if (parent[x] != x)
    parent[x] = find(parent[x]);
return parent[x];
```
**Union by Rank**
```java
if (rank[a] < rank[b]) parent[a] = b;
else if (rank[a] > rank[b]) parent[b] = a;
else { parent[b] = a; rank[a]++; }
```
