# Visual Layout Specification: Arrays & Hashing Cheat Sheet

## 1. Overall Layout Structure
- **Format**: Dense, landscape-oriented infographic or cheat sheet.
- **Grid System**: A complex multi-column grid, roughly divisible into three main vertical columns for the upper body, and a 4-column split for the lower body, wrapped by a header and footer.
- **Background**: White background for content areas, dark blue/black background for the top title bar and bottom footer bar.

## 2. Header Section
- **Location**: Top of the image, spanning full width.
- **Background Color**: Dark blue/black.
- **Elements**: 
  - Main title centered in large, bold white text.
  - Subtitle centered directly below the main title, featuring smaller text with pink and green accents, and a brain emoji.

## 3. Main Body - Upper Section
The upper section is split into three main vertical columns of unequal width.

### 3.1. Left Column (approx. 40% width)
- **Section A**: "PROBLEM WISE QUICK REFERENCE"
  - **Header Style**: Solid purple background with white text.
  - **Border**: Thin purple border encompassing the section.
  - **Content**: A single large table with 6 columns (#, PROBLEM, KEY IDEA / APPROACH, TIME, SPACE, IMPORTANT NOTES / PATTERN) and 10 main data rows. 
  - **Grid**: Standard table grid with light grey borders separating rows and columns.

### 3.2. Middle Column (approx. 40% width)
- **Section B**: "TEMPLATES YOU SHOULD REMEMBER"
  - **Header Style**: Solid blue background with white text.
  - **Border**: Thin blue border encompassing the section.
  - **Content Layout**: Contains 7 distinct code snippet blocks, arranged internally:
    - **Top Area**: A 2x3 grid of blocks (Blocks 1 & 2 side-by-side, Blocks 3 & 4 side-by-side, Blocks 5 & 6 side-by-side).
    - **Bottom Area**: Block 7 spans the full width of the middle column, and is internally divided into 3 sub-columns (Rows, Columns, 3x3 Boxes) to represent its logic.
  - **Visuals**: Each code block has a dark blue header with a white number and title. Code text uses syntax highlighting (blue, green, brown).

### 3.3. Right Column (approx. 20% width)
This column is stacked vertically into two sections.
- **Section C** (Top): "COMMON PATTERNS SUMMARY"
  - **Header Style**: Solid green background with white text.
  - **Border**: Thin green border encompassing the section.
  - **Content**: A 2-column table (PATTERN, HOW TO THINK) with alternating shaded rows or distinct cell borders.
- **Section D** (Bottom): "COMPLEXITY QUICK GUIDE"
  - **Header Style**: Solid purple background with white text.
  - **Border**: Thin purple border encompassing the section.
  - **Content**: A 2-column table (OPERATION, TIME COMPLEXITY).

## 4. Main Body - Lower Section
Located below the upper sections, this area is divided horizontally into four sections (E, F, G, H).
- **Section E**: "HASHMAP / HASHSET REMINDERS"
  - **Header Style**: Solid purple background.
  - **Content**: Divided into 2 internal columns for list items.
- **Section F**: "FREQUENTLY USED STRUCTURES"
  - **Header Style**: Solid blue background.
  - **Content**: A 2-column table.
- **Section G**: "TIME COMPLEXITY OF COMMON ALGORITHMS"
  - **Header Style**: Solid blue background.
  - **Content**: A 3-column table.
- **Section H**: "MEMORY USAGE GUIDE"
  - **Header Style**: Solid blue background.
  - **Content**: A 2-column table.

## 5. Footer Section
- **Location**: Bottom edge, spanning full width.
- **Background Color**: Dark blue/black.
- **Elements**: 
  - "GOLDEN TIPS" label with a yellow star icon on the left.
  - A horizontal flex-row of various text tips, each preceded by a distinct emoji or icon (e.g., brain, target, magnifying glass, warning triangle, checkmark, trophy).
  - Text color is white.

## 6. Color Palette & Typography
- **Primary Header Color**: Purple (`#4b0082` approx.), Blue (`#0047ab` approx.), Green (`#008000` approx.).
- **Text Color**: Black for main content, white for headers and footers.
- **Typography**: Sans-serif, heavily reliant on bold weights for titles, headers, and key terms to establish visual hierarchy. Code blocks use a monospaced font.
- **Borders**: Light grey `#d3d3d3` used for table inner grid lines. Section outlines match their header colors.
