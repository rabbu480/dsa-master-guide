# Visual Layout Specification: Graph Pattern Guide (Page 17)

## 1. Global Page Structure
- **Orientation:** Portrait
- **Grid System:** Underlying 4-column fluid grid.
- **Color Palette:** Predominantly white background with dark blue (#000080 or similar) used as the primary structural color for section headers and accents. Secondary palette uses a rainbow of distinct colors for categorical indexing (dark blue, green, orange, purple, red, teal, brown, etc.).

## 2. Header Section
- **Top Bar:** 
  - Left-aligned dark blue rectangular block containing "PAGE 17" in white.
  - Centered large title "GRAPH PATTERN GUIDE" next to an open book icon.
- **Subtitle Row:** Centered text "PAGE 17 - COMPLETE GRAPH ALGORITHMS CHEAT SHEET (DSA ONLY)", flanked by thin horizontal dividing lines spanning the remaining width.

## 3. Top Information Section (2-Column Layout)
- **Left Column (Span 1/4):** "HOW TO USE THIS PAGE"
  - **Header Block:** Dark blue background, white text, full width of column.
  - **Content:** Numbered list layout, right-aligned decorative target graphic positioned halfway down the block.
- **Right Column (Span 3/4):** "ALGORITHM INDEX"
  - **Header Block:** Dark blue background, white text, full width of column.
  - **Grid Content:** 4 columns x 3 rows grid of index items. Each item consists of a colored square containing a white number, followed by the algorithm name. The colors directly correspond to the header numbers in the main code grid below.

## 4. Main Code Snippet Grid (3 Rows x 4 Columns)
- **Structure:** 12 independent cards laid out in a responsive 4-column grid.
- **Card Anatomy:**
  - **Header Row:** Flex-row layout. A colored numbered box (matching the Algorithm Index) aligned left, followed by a bold primary title and a smaller secondary subtitle.
  - **Body Content:** Monospaced code block area. Left-aligned, varying heights.
  - **Complexity Row:** Centered text for "Time:" and "Space:" metrics, separated by spacing.
  - **Footer Row:** Full-width light gray/yellowish tinted background strip, featuring a lightbulb icon aligned left, followed by "Use for:" text.

## 5. Bottom Reference Section (3-Column Layout)
- **Overall Container:** Three equal-width columns.
- **Column 1: GRAPH REPRESENTATIONS**
  - **Header:** Dark blue background strip.
  - **Content:** Split into two internal sub-columns (Adjacency List vs Adjacency Matrix). Contains bullet points followed by visual node diagram and matrix table representations.
- **Column 2: COMMON DIRECTIONS (Grid Problems)**
  - **Header:** Dark blue background strip.
  - **Content:** Two side-by-side blocks showing array definitions. Below each array is a geometric visual representation (a 4-point cross and an 8-point star with arrowheads).
- **Column 3: EDGE TYPES**
  - **Header:** Dark blue background strip.
  - **Content:** Left-aligned bulleted list.

## 6. Complexity Quick Reference Section
- **Header Block:** Full-width dark blue background strip with white text, containing the section title and variable definitions (V, E, M, N).
- **Content:** 3-column layout distributing various algorithms and their time complexities. An additional bounded box is float-right containing a specific mathematical note.

## 7. Page Footer
- **Structure:** Full-width horizontal flex container.
- **Content:** A sequence of distinct icons and labels separated by standard chevron (`>`) dividers, acting as a visual workflow or path from left to right, concluding with bold text.
