# Visual Layout Specification: Binary Search Cheat Sheet (Page 3 of 4)

## Global Structure
- **Overall Layout:** A multi-column modular grid with a prominent header, a two-column main content area, and a horizontal footer section.
- **Background Color:** The overall page background is white.
- **Typography & Stylization:** Sans-serif typography, highly structured with bounding boxes, color-coded section headers, and graphical callouts (icons, tables, and array blocks).

## Header Section
- **Span:** Spans the full width of the page.
- **Structure:**
  - **Left Element (Title/Subtitle):** A large magnifying glass icon followed by bold, heavy uppercase title text in dark blue. Below the title is a solid blue rectangular ribbon containing the subtitle in white text.
  - **Right Element (Goal Box):** A rectangular bounding box with a red outline and a red target icon. Contains left-aligned text explaining the goal and time complexity.
  - **Top Right Corner:** A small dark blue rectangular badge indicating the page number.

## Main Content Area (Two-Column Grid)
The core of the document is divided into two primary columns. The left and right columns utilize matching structural designs for their sections (solid color headers over bordered content boxes).

### Left Column
Consists of three major vertical blocks, each enclosed in a bordered box with a solid colored header.

1. **Section 12 (Top Left)**
   - **Header:** Solid purple block with white text.
   - **Content:**
     - A light purple sub-header block.
     - **Array Visualization:** A horizontal row of square cells with solid borders. A continuous block of cells is highlighted in bright yellow. Contains top labels and bottom index numbers.
     - **Table:** A 6-column tabular layout with alternating row background colors (light purple/white) and thin borders.
     - **Answer Badge:** A centered pill-shaped badge with a green checkmark icon.
     - **Callout Box:** A light purple shaded box with a dashed purple border, featuring a yellow lightbulb icon aligned to the left.

2. **Section 14 (Middle Left)**
   - **Header:** Solid dark blue block with white text.
   - **Content:**
     - Split into two visual sub-columns initially.
       - **Left sub-column:** A 2D grid/matrix visualization (4 rows x 2 columns) with thick borders. 
       - **Right sub-column:** Text approach list and a light blue shaded bounding box containing index mapping formulas.
     - **Code Block:** Below the sub-columns is a dark mode (black background) code block spanning the width of the section, with syntax highlighting.
     - **Footer Callout:** A light blue box at the bottom, marked with a blue star icon, spanning the full width of this section.

3. **Section 16 (Bottom Left)**
   - **Header:** Solid red block with white text.
   - **Content:**
     - A horizontal array representation with dashed outer borders, containing a block highlighted in yellow. Below the array are arrows depicting an "Expanding Range".
     - Text content organized in a two-column layout below the array diagram, describing steps and range expansion.
     - A green pill-shaped badge with a checkmark for time complexity at the bottom.

### Right Column
Consists of three major vertical blocks.

1. **Section 13 (Top Right)**
   - **Header:** Solid green block with white text.
   - **Content:**
     - Divided into three vertically stacked sub-sections.
     - Each sub-section contains a horizontal split:
       - **Left:** A dark mode (black background) code block with monospace syntax highlighting.
       - **Right:** A vertical text list indicating return values and use cases.

2. **Section 15 (Middle Right)**
   - **Header:** Solid orange block with white text.
   - **Content:**
     - **Array Visualization:** A horizontal row of cells. Below the cells are two horizontal arrows pointing in opposite directions (green for increasing, red for decreasing).
     - Textual steps list.
     - **Code Area:** A two-column split, each containing a dark mode code block with a centered orange/red title text above it.

3. **Section 17 (Bottom Right)**
   - **Header:** Solid dark purple block with white text.
   - **Content:**
     - A two-column numbered list. The background of the entire box is very light purple.
     - **Callout Box:** A rectangular white bounding box at the bottom, featuring a gold trophy icon on the left and a bulleted list on the right.

## Footer Section
- **Span:** Spans the full width of the page, acting as a footer base.
- **Structure:** Divided into three horizontal zones, separated by subtle spacing or vertical divider lines.
- **Left Zone:** A red bullseye icon beside a bold heading and body text.
- **Middle Zone:** A pink brain icon beside a bold heading and a bulleted list.
- **Right Zone:** Contains two vertically aligned or side-by-side blue rectangular boxes with light blue backgrounds, displaying complexity metrics in bold, large text.
