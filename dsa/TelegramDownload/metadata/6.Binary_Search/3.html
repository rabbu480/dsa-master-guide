12. BOUNDARY SEARCH VISUALIZATION
We are looking for FIRST occurrence of 8
Array:
1 2 4 5 7 8 8 8 8 10 13
012345678910
Step left right mid nums[mid] Action
1 0 10 5 8 ans = 5, move left (right = 4)
2 0 4 2 4 nums[mid] < 8, move right (left = 3)
3 3 4 3 5 nums[mid] < 8, move right (left = 4)
4 4 4 4 7 nums[mid] < 8, move right (left = 5)
5 5 4 - - left > right, stop
✔ Answer = 5 (First index of 8)
💡
Key Idea:
When nums[mid] == target, don't return immediately.
Store the answer and keep searching in the left half.
14. BINARY SEARCH ON 2D MATRIX (ROW-WISE SORTED)
Example Matrix:
1 3 5 7
10 11 16 20
23 30 34 50
60 65 70 80
Search = 34
Approach:
  1. Treat matrix as 1D array.
  2. Index mapping:
    row = mid / m;
    col = mid % m;
  3. Apply normal Binary Search.
Code: 
int row = matrix.length, col = matrix[0].length;
int left = 0, right = row * col - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    int r = mid / col, c = mid % col;
    if (matrix[r][c] == target) return true;
    else if (matrix[r][c] < target) left = mid + 1;
    else right = mid - 1;
}
return false;
★
Works because each row is sorted and
first element of a row is greater than last of previous row.
16. SEARCH IN INFINITE / VERY LARGE ARRAY
Problem:
Array is sorted but size is unknown or very large.

Solution:
  1. Find the range (low, high) where target can exist.
  2. Apply Binary Search in that range.
Target = 15
... 1 3 7 9 12 15 18 21 ...
01234567
↑
low = 4 Expanding Range ↑
high = 7
1. Expand range:
low = high + 1;
high = high * 2;
until arr[high] >= target
or arr[high] is out of bounds
2. Apply normal Binary Search between low and high.
✔ Time Complexity: O(log index_of_target)
13. MORE BINARY SEARCH TEMPLATES
Lower Bound (First >= target)
int left = 0, right = n;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] >= target)
        right = mid;
    else
        left = mid + 1;
}
return left;
Returns:
First index where
nums[index] >= target
If none exists, returns n

Floor (Last <= target)

while (left <= right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] <= target) {
        ans = mid;
        left = mid + 1;
    } else right = mid - 1;
}
return ans;
Returns:
Last index where
nums[index] <= target
If none exists, returns -1

15. SEARCH IN PEAK ELEMENT (BITONIC ARRAY)
Bitonic Array (First increasing then decreasing)
Array:
1 3 8 12 4 2
←───→
←───→
Search = 4
Steps:
  1. Find the peak element index.
  2. If target == peak → return true
  3. If target < peak → Binary Search in left (increasing part)
  4. If target > peak → Binary Search in right (decreasing part)
Find Peak Index
int l = 0, r = n - 1;
while (l < r) {
    int mid = l + (r - l) / 2;
    if (arr[mid] < arr[mid + 1])
        l = mid + 1;
    else
        r = mid;
}
return l;
Binary Search in Decreasing Order
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (arr[mid] == target)
        return true;
    else if (arr[mid] > target)
        l = mid + 1;
    else
        r = mid - 1;
}
