🧰 REUSABLE LINKED LIST UTILITIES

Reverse Linked List Utility:

ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

Find Middle Node (Fast & Slow):

ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
💡 AHA MOMENT #1: THE DUMMY NODE SENTINEL PATTERN (FOR BEGINNERS)
Why do beginners get NullPointerException or write endless if (head == null) checks? Because the head node can change or be deleted! Creating a ListNode dummy = new ListNode(-1); dummy.next = head; anchors the list. Now perform all insertions/deletions on dummy.next safely, and return dummy.next as the new head!
1 JAVA REFERENCE VS ARRAY MEMORY
• Array: Contiguous memory block. $O(1)$ index lookup arr[i] via base address math.
• Linked List: Non-contiguous nodes scattered on Java Heap. Nodes link via reference pointers (next). $O(N)$ sequential traversal, but $O(1)$ node insertion/deletion once pointer is positioned!
2 WHY THIS VARIABLE EXISTS: `ListNode temp`
💡 ListNode temp = curr.next;
Why it exists: Re-assigning curr.next = prev severs the forward arrow! Without saving temp first, nodes 3..N become completely unreachable, causing Java's Garbage Collector to erase the rest of your list!

EXERCISE: Given list 1 ➔ 2 ➔ 3 ➔ 4. Draw the position of prev, curr, and nextTemp after exactly ONE iteration of reversing:
[Your Drawing Space: prev = ____, curr = ____, nextTemp = ____, List: 1 ◄── 2 ➔ 3 ➔ 4]
🎨 VISUALIZING THE DUMMY NODE SENTINEL ANCHOR
WITH DUMMY NODE ANCHOR: [dummy: -1] ──next──► [Head: 10] ──next──► [Node: 20] ──next──► [Node: 30] ──next──► null ▲ │ tail = dummy (Perform all appends to tail.next safely! Return dummy.next at the end!)

1 FINDING MIDDLE NODE MECHANICS
public ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;       // 1 step
        fast = fast.next.next;  // 2 steps
    }
    return slow; // Points to middle!
}
2 CYCLE START MATHEMATICAL PROOF
Let $L$ = distance from Head to Entrance, $k$ = distance from Entrance to Meeting Point.
Distance(fast) = 2 * Distance(slow)
L + nC + k = 2(L + k) ➔ L = nC - k

}

1. LEETCODE 206 — REVERSE LINKED LIST
🟢 Easy ★★★★★ 3-Pointer Reverse AmazonMetaGoogle
📌 FLOWCHART: prev=null, curr=head ➔ Save temp=curr.next ➔ curr.next=prev ➔ Advance prev & curr
Problem: Given head of singly linked list, reverse list and return new head.
Example: 1 ➔ 2 ➔ 3 ➔ 4 ➔ 5 → Output: 5 ➔ 4 ➔ 3 ➔ 2 ➔ 1.
💡 ALTERNATIVE SOLUTIONS:
1. Stack: Push all nodes to Stack, pop to rebuild ($O(N)$ Space).
2. Recursive: Reverses links on unwinding ($O(N)$ Call Stack).
3. Iterative 3-Pointer: $O(N)$ Time & $O(1)$ Space — OPTIMAL CHOICE! 
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next; // Step 1: Save forward chain
        curr.next = prev;              // Step 2: Reverse link pointer
        prev = curr;                   // Step 3: Shift prev forward
        curr = nextTemp;               // Step 4: Shift curr forward
    }
    return prev; // Step 5: New reversed head!
}
2. LEETCODE 21 — MERGE TWO SORTED LISTS
🟢 Easy ★★★★★ Dummy Node Merge AmazonMicrosoft
Problem: Merge two sorted linked lists into one sorted list.
Example: l1 = 1 ➔ 2 ➔ 4, l2 = 1 ➔ 3 ➔ 4 → 1 ➔ 1 ➔ 2 ➔ 3 ➔ 4 ➔ 4. 
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(-1), tail = dummy;
    while (list1 != null && list2 != null) {
        if (list1.val <= list2.val) { tail.next = list1; list1 = list1.next; }
        else { tail.next = list2; list2 = list2.next; }
        tail = tail.next;
    }
    tail.next = (list1 != null) ? list1 : list2;
    return dummy.next;
}
3. LEETCODE 141 — LINKED LIST CYCLE
🟢 Easy ★★★★★ Fast & Slow Pointer AmazonMeta
Problem: Determine if linked list has a cycle (`fast == slow`). 
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true; // Cycle detected!
    }
    return false;
}

4. LEETCODE 876 — MIDDLE OF THE LINKED LIST
🟢 Easy ★★★★☆ Fast & Slow Google
Problem: Return middle node of linked list. If two middle nodes, return second middle. 
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow; // Points to middle node!
}
5. LEETCODE 234 — PALINDROME LINKED LIST
🟢 Easy ★★★★★ Mid + Reverse MetaAmazon
Problem: Check if linked list values form a palindrome in $O(N)$ time and $O(1)$ space.
💡 ALTERNATIVE SOLUTIONS COMPARISON:
1. Array Copy: Copy to ArrayList, use 2-pointer ($O(N)$ Space).
2. Stack: Push 1st half, pop & compare ($O(N)$ Space).
3. Find Mid + Reverse 2nd Half: $O(N)$ Time & $O(1)$ Space — OPTIMAL! 
public boolean isPalindrome(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next; fast = fast.next.next;
    }
    ListNode secondHalf = reverse(slow), p1 = head, p2 = secondHalf;
    while (p2 != null) {
        if (p1.val != p2.val) return false;
        p1 = p1.next; p2 = p2.next;
    }
    return true;
}
private ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next; curr.next = prev;
        prev = curr; curr = nextTemp;
    }
    return prev;
}
6. LEETCODE 19 — REMOVE NTH NODE FROM END OF LIST
🟡 Medium ★★★★★ Fast/Slow Gap + Dummy MetaAmazon
Problem: Remove $N$-th node from end of list in one pass. 
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0), fast = dummy, slow = dummy;
    dummy.next = head;
    for (int i = 0; i <= n; i++) fast = fast.next; // Create N gap
    while (fast != null) {
        fast = fast.next; slow = slow.next;
    }
    slow.next = slow.next.next; // Bypass N-th node!
    return dummy.next;
}
💡 AHA MOMENT (LC 19): Creating a gap of $N+1$ steps between `fast` and `slow` positions `slow` directly before the target node to delete!

7. LEETCODE 143 — REORDER LIST
🟡 Medium ★★★★★ Find Mid + Reverse + Interleave MetaAmazon
📌 FLOWCHART: Find Mid ➔ Reverse 2nd Half ➔ Interleave L1 & L2 nodes alternatingly!
Problem: Reorder list to $L_0 \rightarrow L_n \rightarrow L_1 \rightarrow L_{n-1} \dots$
Example: 1 ➔ 2 ➔ 3 ➔ 4 → 1 ➔ 4 ➔ 2 ➔ 3. 
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    // Step 1: Find Middle
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next; fast = fast.next.next;
    }
    // Step 2: Reverse Second Half
    ListNode prev = null, curr = slow.next;
    slow.next = null; // Split lists
    while (curr != null) {
        ListNode temp = curr.next; curr.next = prev;
        prev = curr; curr = temp;
    }
    // Step 3: Interleave Lists
    ListNode first = head, second = prev;
    while (second != null) {
        ListNode t1 = first.next, t2 = second.next;
        first.next = second; second.next = t1;
        first = t1; second = t2;
    }
}
8. LEETCODE 2 — ADD TWO NUMBERS
🟡 Medium ★★★★★ Dummy + Carry Digit AmazonGoogle
Problem: Two non-empty linked lists representing two non-negative integers in reverse order. Add the two numbers and return sum list.
Example: (2 ➔ 4 ➔ 3) + (5 ➔ 6 ➔ 4) → 7 ➔ 0 ➔ 8 (342 + 465 = 807). 
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), curr = dummy;
    int carry = 0;
    while (l1 != null || l2 != null || carry != 0) {
        int v1 = (l1 != null) ? l1.val : 0;
        int v2 = (l2 != null) ? l2.val : 0;
        int sum = v1 + v2 + carry;
        carry = sum / 10;
        curr.next = new ListNode(sum % 10);
        curr = curr.next;
        if (l1 != null) l1 = l1.next;
        if (l2 != null) l2 = l2.next;
    }
    return dummy.next;
}
💡 AHA MOMENT (LC 143): Reorder list combines 3 core sub-patterns: Fast/Slow Mid + 3-Pointer Reverse + Two-Pointer Interleaving!

9. LEETCODE 138 — COPY LIST WITH RANDOM POINTER
🟡 Medium ★★★★★ 3-Pass Interleaving AmazonMetaGoogle
Problem: Deep copy linked list where each node contains an additional `random` pointer in $O(N)$ time and $O(1)$ extra space! 
public Node copyRandomList(Node head) {
    if (head == null) return null;
    // Pass 1: Interleave clone nodes (A ➔ A' ➔ B ➔ B')
    Node curr = head;
    while (curr != null) {
        Node clone = new Node(curr.val);
        clone.next = curr.next; curr.next = clone;
        curr = clone.next;
    }
    // Pass 2: Assign random pointers
    curr = head;
    while (curr != null) {
        if (curr.random != null) curr.next.random = curr.random.next;
        curr = curr.next.next;
    }
    // Pass 3: Separate cloned list from original
    curr = head; Node dummy = new Node(0), copyCurr = dummy;
    while (curr != null) {
        copyCurr.next = curr.next; copyCurr = copyCurr.next;
        curr.next = curr.next.next; curr = curr.next;
    }
    return dummy.next;
}
10. LEETCODE 148 — SORT LIST (MERGE SORT ON LINKED LIST)
🟡 Medium ★★★★★ Divide & Conquer Merge MetaGoogle
Problem: Sort a linked list in $O(N \log N)$ time and $O(\log N)$ space complexity. 
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    // Step 1: Split list in half
    ListNode prev = null, slow = head, fast = head;
    while (fast != null && fast.next != null) {
        prev = slow; slow = slow.next; fast = fast.next.next;
    }
    prev.next = null; // Cut link
    // Step 2: Recursively sort halves & merge
    ListNode l1 = sortList(head), l2 = sortList(slow);
    return merge(l1, l2);
}
private ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
        else { tail.next = l2; l2 = l2.next; }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
🧠 MEMORY BOX: 3-pass interleaving (`A -> A' -> B -> B'`) achieves $O(1)$ space deep copying without needing a HashMap!

11. LEETCODE 23 — MERGE K SORTED LISTS
🔴 Hard ★★★★★ Min-Heap / PriorityQueue AmazonMetaGoogle
Problem: Merge $K$ sorted linked lists into one sorted linked list in $O(N \log K)$ time! 
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>((a,b) -> a.val - b.val);
    for (ListNode node : lists) {
        if (node != null) minHeap.add(node);
    }
    ListNode dummy = new ListNode(0), tail = dummy;
    while (!minHeap.isEmpty()) {
        ListNode smallest = minHeap.poll();
        tail.next = smallest;
        tail = tail.next;
        if (smallest.next != null) minHeap.add(smallest.next);
    }
    return dummy.next;
}
12. LEETCODE 25 — REVERSE NODES IN K-GROUP
🔴 Hard ★★★★★ Group Reversal + Pointer Stitching AmazonMicrosoft
Problem: Reverse nodes of list $k$ at a time and return modified list. 
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode curr = head; int count = 0;
    while (curr != null && count != k) { // Find k-th node
        curr = curr.next; count++;
    }
    if (count == k) {
        ListNode reversedHead = reverseKGroup(curr, k); // Recurse rest
        while (count-- > 0) { // Reverse current k group
            ListNode temp = head.next; head.next = reversedHead;
            reversedHead = head; head = temp;
        }
        head = reversedHead;
    }
    return head;
}

⭐ THE 4 GOLDEN LAWS OF LINKED LISTS
1. Dummy Node Anchor: Use ListNode dummy = new ListNode(-1); dummy.next = head; whenever head node can change!
2. Fast & Slow Speed Rule: Move slow = slow.next (1x) and fast = fast.next.next (2x) for mid-finding & cycle detection.
3. 3-Pointer Reverse Window: Save forward chain first (temp = curr.next), reverse arrow (curr.next = prev), then shift window!
4. Null Safety Check: Always check while (fast != null && fast.next != null) before jumping 2 steps!
⛔ WHEN LINKED LIST FAILS (DO NOT USE!)
• Random Index Access: Getting element at index $i$ takes $O(N)$ sequential steps ➔ Use Array / ArrayList!
• CPU Cache Locality: Non-contiguous heap nodes cause high CPU cache misses ➔ Arrays outperform Linked Lists for iteration speed!
