🚀 THE UNIVERSAL FAANG DP THINKING PARADIGM — SB ➔ RBR ➔ MTS
🟦 SB — State & Brainstorm

S (State): What variables uniquely identify `dp[i]` or `dp[i][j]`?
B (Brainstorm): "If I'm at this state, what choices do I have?" (Take/Skip, Climb 1/2 steps, Rob/Skip).

🟨 RBR — Recurrence, Base, Result

R (Recurrence): `dp[i] = max(take, skip)`.
B (Base Case): Recursion stop point (`dp[0] = 0`).
R (Result): Target location (`dp[N]`, `dp[M][N]`).

🟩 MTS — Memo, Tabulate, Space

M (Memoization): Top-down recursion cache.
T (Tabulation): Bottom-up iterative table.
S (Space Opt): Compress 1D/2D table into `prev1, prev2` variables!

Golden Rule: Brute Force \rightarrow Recursion \rightarrow SB \rightarrow RBR \rightarrow Memoization \rightarrow Tabulation \rightarrow Space Optimization O(1).
📚 THE 2 MANDATORY DP CONDITIONS

1. Overlapping Subproblems: Exact same state `fib(3)` computed multiple times in recursion tree.

2. Optimal Substructure: Optimal solution of size N built from optimal solutions of smaller subproblems!

⚡ CLUES THAT SCREAM DYNAMIC PROGRAMMING

1. "Max / Min ways to reach target" \rightarrow 1D / Knapsack DP

2. "Longest common subsequence / Edit distance" \rightarrow 2D String DP

3. "Can partition array into 2 equal sum subsets" \rightarrow 0/1 Knapsack DP

public int solveTopDown(int n) {
  Integer[] memo = new Integer[n + 1];

private int helper(int n, Integer[] memo) {
  if (n <= 1) return n;
  if (memo[n] != null) return memo[n]; // Memoization Cache Hit!
  memo[n] = helper(n - 1, memo) + helper(n - 2, memo);
  return memo[n];
}

    prev2 = prev1;
    prev1 = curr;
  }
  return prev1;
}

PATTERN 1
CLIMBING STAIRS (1D Fibonacci Transition)
e.g. Climbing Stairs (LC 70), Min Cost Climbing Stairs (LC 746)
Recurrence Formula
`dp[i] = dp[i-1] + dp[i-2]`. Space compressed to O(1) variables `prev1` and `prev2`.
Template — LC 70
public int climbStairs(int n) {
  if (n <= 2) return n;
  int prev2 = 1, prev1 = 2;
  for (int i = 3; i <= n; i++) {
    int curr = prev1 + prev2;
    prev2 = prev1;
    prev1 = curr;
  }
  return prev1;
}

HOUSE ROBBER II (Circular Array Split)

Circular Robber Trick

Template — LC 213
public int rob(int[] nums) {
  if (nums.length == 1) return nums[0];
  return Math.max(robRange(nums, 0, nums.length - 2), robRange(nums, 1, nums.length - 1));
}
private int robRange(int[] nums, int start, int end) {
  int prev2 = 0, prev1 = 0;
  for (int i = start; i <= end; i++) {
    int curr = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1; prev1 = curr;
  }
  return prev1;
}

UNBOUNDED KNAPSACK · COIN CHANGE I & II
PATTERN 5
COIN CHANGE I (Fewest Coins to Make Amount)
e.g. Coin Change (LC 322)
Unbounded Forward Loop
Infinite reuse of coins! Loop `a = coin..amount` forward: `dp[a] = Math.min(dp[a], 1 + dp[a - coin])`.
Template — LC 322
public int coinChange(int[] coins, int amount) {
  int[] dp = new int[amount + 1];
  Arrays.fill(dp, amount + 1);
  dp[0] = 0;
  for (int a = 1; a <= amount; a++) {
    for (int coin : coins) {
      if (a >= coin) dp[a] = Math.min(dp[a], 1 + dp[a - coin]);
    }
  }
  return dp[amount] > amount ? -1 : dp[amount];
}
PATTERN 6
COIN CHANGE II (Total Combination Ways)
e.g. Coin Change II (LC 518)
Outer Loop = Coins (Prevents Duplicates)
Outer loop over `coins`, inner loop over `amount` ensures combinations (not permutations) are counted!
Template — LC 518
public int change(int amount, int[] coins) {
  int[] dp = new int[amount + 1];
  dp[0] = 1;
  for (int coin : coins) {
    for (int a = coin; a <= amount; a++) {
      dp[a] += dp[a - coin];
    }
  }
  return dp[amount];
}

0/1 KNAPSACK · PARTITION EQUAL SUBSET SUM
PATTERN 7
PARTITION EQUAL SUBSET SUM (0/1 Knapsack Reverse Loop)
e.g. Partition Equal Subset Sum (LC 416)
Reverse Loop Single Use Trick
For single-use elements, inner loop MUST run backwards from `target` down to `num` to prevent using same element twice in 1D array!
Template — LC 416
public boolean canPartition(int[] nums) {
  int sum = 0; for (int n : nums) sum += n;
  if (sum % 2 != 0) return false;
  int target = sum / 2;
  boolean[] dp = new boolean[target + 1];
  dp[0] = true;
  for (int num : nums) {
    for (int j = target; j >= num; j--) { // Reverse loop for 0/1!
      dp[j] = dp[j] || dp[j - num];
    }
  }
  return dp[target];
}

PATTERN 8
LONGEST INCREASING SUBSEQUENCE (Binary Search Tails Array)
e.g. Longest Increasing Subsequence (LC 300)
Patience Sorting O(N log N)
Maintain array `tails[]` of smallest tail of all increasing subsequences of length i+1. Use binary search (`Arrays.binarySearch`) to replace or append!
Template — LC 300
public int lengthOfLIS(int[] nums) {
  int[] tails = new int[nums.length];
  int len = 0;
  for (int num : nums) {
    int i = Arrays.binarySearch(tails, 0, len, num);
    if (i < 0) i = -(i + 1);
    tails[i] = num;
    if (i == len) len++;
  }
  return len;
}

LCS · EDIT DISTANCE · 2D MATRIX
PATTERN 9
LONGEST COMMON SUBSEQUENCE (2D Matrix Match)
e.g. Longest Common Subsequence (LC 1143)
Matching vs Non-Matching Transition
If `text1[i-1] == text2[j-1]`: `dp[i][j] = 1 + dp[i-1][j-1]`. Else `dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1])`.
Template — LC 1143
public int longestCommonSubsequence(String text1, String text2) {
  int m = text1.length(), n = text2.length();
  int[][] dp = new int[m + 1][n + 1];
  for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
      if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
        dp[i][j] = 1 + dp[i - 1][j - 1];
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }
  return dp[m][n];
}
PATTERN 10
EDIT DISTANCE (Insert, Delete, Replace Operations)
e.g. Edit Distance (LC 72)
3 Edit Transitions
`dp[i][j] = 1 + Min(Insert dp[i][j-1], Delete dp[i-1][j], Replace dp[i-1][j-1])`.
Template — LC 72
public int minDistance(String word1, String word2) {
  int m = word1.length(), n = word2.length();
  int[][] dp = new int[m + 1][n + 1];
  for (int i = 0; i <= m; i++) dp[i][0] = i;
  for (int j = 0; j <= n; j++) dp[0][j] = j;
  for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
      if (word1.charAt(i - 1) == word2.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1];
      else dp[i][j] = 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
    }
  }
  return dp[m][n];
}

📐 MATHEMATICAL PROOF — O(N LOG N) LIS PATIENCE SORT

Claim: `tails[i]` stores the smallest tail of all increasing subsequences of length i+1.

Proof: `tails[]` is strictly increasing! For each number `x`, binary search finds the first element `tails[i] >= x`. Replacing `tails[i]` with `x` maintains the invariant with a smaller tail, creating more capacity for future elements \rightarrow O(N \log N) Time!

💼 GOLDEN RULES — NEVER FORGET
Rule 1 — Fill Array with Safe Infinity
In min-cost DP (e.g. Coin Change), initialize `dp[]` with `amount + 1` (NOT `Integer.MAX_VALUE` to avoid overflow during `1 + dp[a - coin]`)!
Rule 2 — Reverse Inner Loop for 0/1 Knapsack
When elements can only be used ONCE, inner loop MUST run backwards (`for (int j = target; j >= num; j--)`)!
