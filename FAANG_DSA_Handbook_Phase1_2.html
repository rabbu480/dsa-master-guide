FAANG DSA Master Handbook — Phases 1 & 2

Strictly optimized for 30-second pattern recognition and flawless Java execution. No fluff. No college theory. Just what you need to pass.

1. The 30-Second Pattern Decision Tree

  • Sorted Array + Target Sum/Pair? → Two Pointers
  • Contiguous Subarray/Substring + Min/Max/Longest? → Sliding Window
  • Top K / Kth Smallest / Kth Largest? → Heap / PriorityQueue
  • LIFO / "Next Greater Element" / Nested parsing? → Stack
  • Sorted Array + O(log N) requirement? → Binary Search
  • Connected Components / Shortest Path (Unweighted)? → BFS / DFS (Graphs)
  • Tree Traversal / Level Order? → BFS (Queue) / DFS (Recursion)

2. Arrays & Hashing

Recognition: Frequency counting, finding duplicates, O(1) lookups needed.

Template (Frequency Map):

Map<Integer, Integer> count = new HashMap<>();
for (int num : nums) {
    count.put(num, count.getOrDefault(num, 0) + 1);
}

Common Mistakes: Using `HashMap` when an `int[26]` array works for lowercase English letters (Array is much faster). Modifying collection while iterating.

3. Two Pointers

Recognition: Sorted arrays, palindromes, container with most water.

Template (Opposite Ends):

int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return true;
    if (sum < target) left++;
    else right--;
}

Common Mistakes: `while (left <= right)` vs `while (left < right)`. Not handling duplicates correctly in 3Sum.

4. Sliding Window

Recognition: "Longest/Shortest substring/subarray", "contiguous".

Template (Dynamic Window):

int left = 0, maxLen = 0;
for (int right = 0; right < nums.length; right++) {
    // 1. Add nums[right] to state
    while (/* condition violated */) {
        // 2. Remove nums[left] from state
        left++;
    }
    // 3. Update maxLen / minLen
}

5. Binary Search

Recognition: Sorted array, O(log N) time required, finding boundaries.

Template (Search Space / Boundary):

int left = 0, right = nums.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2; // Prevent overflow
    if (nums[mid] == target) return mid;
    if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
}

Common Mistakes: Calculating `mid = (left + right)/2` (causes integer overflow). Infinite loops when `left < right` without shifting `mid` properly.

6. Trees

Recognition: Hierarchical data, LCA, path sums, BST properties.

Template (DFS / Recursive):

public int dfs(TreeNode node) {
    if (node == null) return 0;
    int left = dfs(node.left);
    int right = dfs(node.right);
    return Math.max(left, right) + 1; // Example: Max Depth
}

7. Graphs

Recognition: Grids (matrices), connected components, "shortest path" (BFS), topological sort (dependencies).

Template (BFS Shortest Path):

Queue<Integer> q = new LinkedList<>();
Set<Integer> visited = new HashSet<>();
q.offer(startNode); visited.add(startNode);
int steps = 0;

while (!q.isEmpty()) {

8. Heap / Priority Queue

Recognition: "Top K", "Kth Largest/Smallest", Median of data stream.

Template (Min-Heap for Top K Largest):

PriorityQueue<Integer> pq = new PriorityQueue<>(); // Min-Heap
for (int num : nums) {
    pq.offer(num);
    if (pq.size() > k) {
        pq.poll(); // Evict the smallest, keeping top K largest
    }
}
