# Visual Layout Specification: BFS Pattern Problems (Level Order Focused)

## 1. Global Structure
- **Layout Type:** Grid-based multi-section poster/cheatsheet layout.
- **Orientation:** Portrait.
- **Background:** White or very light gray.
- **Margins/Padding:** Uniform outer margins, distinct internal padding for grouped elements.
- **Section Dividers:** Sections are primarily delineated by solid dark blue header bars spanning the width of their respective containers.

## 2. Header Section (Top)
- **Title Block:** 
  - A prominent dark blue square with a white number on the left.
  - Large, bold uppercase title text taking up the center space.
  - Subtitle centered below the main title, with horizontal flanking lines.
- **Legend Bar:**
  - A single horizontal row spanning the full width.
  - Contains four evenly spaced items, each consisting of a colored icon followed by short text describing the icon's meaning.

## 3. Body Sections
The body is divided into four distinct horizontal bands (rows), some spanning the full width and others split into columns.

### Row 1: Full-Width Section (Section 1)
- **Header:** Full-width dark blue bar with left-aligned white text.
- **Grid Layout:** 4-column structure.
  - **Column 1 (Left, approx 20%):** Contains a title, a binary tree node diagram (circles and connecting lines), and an outlined box for output data.
  - **Column 2 (Middle-Left, approx 20%):** Stacked vertical layout of three distinct insight blocks (each featuring a legend icon and text).
  - **Column 3 (Middle-Right, approx 45%):** A large, dedicated block for code with syntax-like formatting.
  - **Column 4 (Right, approx 15%):** Vertical stack containing complexity metrics with an icon.

### Row 2: Two-Column Split (Sections 2 & 3)
- **Layout:** Divided evenly into two equal-width blocks (Left and Right), separated by a gutter.
- **Both Blocks Structure:**
  - **Header:** Dark blue header bar with left-aligned white text.
  - **Internal Columns:** Each split block internally contains a 3-column layout.
    - *Sub-Column A (approx 30%):* Tree diagram and output box.
    - *Sub-Column B (approx 25%):* Stacked insight blocks (icons and text).
    - *Sub-Column C (approx 45%):* Code block.

### Row 3: Two-Column Split (Sections 4 & 5)
- **Layout:** Divided evenly into two equal-width blocks, similar to Row 2.
- **Left Block (Section 4):**
  - **Header:** Dark blue bar with left-aligned white text.
  - **Content:** Two sub-columns. The left sub-column contains a code block. The right sub-column is an enclosed box with a light background containing a vertical checklist (checkbox icons).
- **Right Block (Section 5):**
  - **Header:** Dark blue bar with left-aligned white text.
  - **Content:** A tabular structure with 5 columns (Step, Queue state, Level, Action, Visual Flow). The "Visual Flow" column incorporates tiny tree level diagrams matching the steps.

### Row 4: Three-Column Footer Block
- **Layout:** Three distinct rectangular containers spanning the full width, evenly distributed.
- **Container 1 (Left):** 
  - Sub-header title.
  - Vertical list of items featuring green checkmark icons.
- **Container 2 (Center):**
  - Sub-header title.
  - A structured comparison table with colored header rows and alternating row structures.
- **Container 3 (Right):**
  - Sub-header title.
  - Vertical list of items featuring yellow star icons.

## 4. Bottom Footer Bar
- **Layout:** A single horizontal bar spanning the entire bottom.
- **Content:** Begins with a trophy icon and bold label, followed by a sequence of short text blocks connected by horizontal right-pointing arrows.

## 5. Visual Components & Styling
- **Color Palette:**
  - **Primary:** Dark Blue (Headers, title numbers).
  - **Text:** Black / Dark Gray for primary text. Code blocks use standard mono coloring (blacks, blues, greens).
  - **Accents:** Green (checkboxes), Yellow (lightbulbs, stars, trophy), Blue (gears, math symbols).
- **Typography:**
  - Sans-serif font family used globally.
  - Heavily relies on font weight (bolding) to establish hierarchy.
  - Code blocks use a monospaced font.
- **Graphical Elements:**
  - **Tree Diagrams:** Minimalist style using circular nodes with numeric labels and straight line connectors.
  - **Icons:** Flat, vectorized icons (Lightbulb, Gear, Sigma, Clock, Checkmark, Star, Trophy) used consistently as bullet points or identifiers.
  - **Tables:** Clean lines, no heavy cell borders, relying on spacing and light background fills for the header row.
  - **Containers:** Outlined boxes with rounded corners are used to group specific secondary information (e.g., Output blocks, Key Points blocks).
