1. LOWEST COMMON ANCESTOR
IN BINARY TREE (LC 236)
Example
graph TD 3((3)) --> 5((5)) 3 --> 1((1)) 5 --> 6((6)) 5 --> 2((2)) 2 --> 7((7)) 2 --> 4((4)) 1 --> 0((0)) 1 --> 8((8)) style 3 fill:#bbf7d0,stroke:#22c55e,stroke-width:2px style 5 fill:#bbf7d0,stroke:#22c55e,stroke-width:2px style 1 fill:#bbf7d0,stroke:#22c55e,stroke-width:2px
p = 5, q = 1   ➔   LCA = 3
💡 AHA
Children report back.
If both left and right return non-null ➔
current node is LCA.
⚙️ Pattern
Postorder (Left ➔ Right ➔ Root)
∑ Idea / Formula
If root == null or root == p or root == q ➔ return root
left = recurse(left), right = recurse(right)
If left != null and right != null ➔ return root
Else return left if not null else right
Complexity Time: O(n) Space: O(h)
4. PATH SUM (LC 112 / 113)
Example (Sum = 22)
graph TD 5((5)) --> 4a((4)) 5 --> 8((8)) 4a --> 11((11)) 11 --> 7((7)) 11 --> 2((2)) 8 --> 13((13)) 8 --> 4b((4)) 4b --> 1((1)) style 5 fill:#fef3c7,stroke:#d97706,stroke-width:2px style 4a fill:#fef3c7,stroke:#d97706,stroke-width:2px style 11 fill:#fef3c7,stroke:#d97706,stroke-width:2px style 2 fill:#fef3c7,stroke:#d97706,stroke-width:2px
💡 AHA
Need root to leaf path.
Keep subtracting from target.
If leaf and target == 0 ➔ valid path.
⚙️ Pattern
DFS (Preorder)
∑ Idea / Formula
target -= node.val
If leaf and target == 0 ➔ true
Else check left and right
Complexity Time: O(n) Space: O(h)
2. CONSTRUCT BINARY TREE
FROM TRAVERSALS (LC 105)
Example
Inorder  :  [9, 3, 15, 20, 7]
Preorder :  [3, 9, 20, 15, 7]
graph TD 3((3)) --> 9((9)) 3 --> 20((20)) 20 --> 15((15)) 20 --> 7((7))
💡 AHA
Preorder ➔ Root comes first.
Inorder ➔ Left and Right parts.
Build tree using indices.
⚙️ Pattern
Recursive (Divide & Conquer)
∑ Idea / Formula
  1. First element in preorder = Root
  2. Find root in inorder ➔ split left & right
  3. Recur for left part and right part
Complexity Time: O(n) Space: O(n)
5. BUILD TREE FROM INORDER
AND POSTORDER (LC 106)
Example
Inorder  :  [9, 3, 15, 20, 7]
Postorder :  [9, 15, 7, 20, 3]
graph TD 3((3)) --> 9((9)) 3 --> 20((20)) 20 --> 15((15)) 20 --> 7((7))
💡 AHA
Postorder ➔ Root comes last.
Inorder ➔ Left and Right parts.
⚙️ Pattern
Recursive (Divide & Conquer)
∑ Idea / Formula
  1. Last element in postorder = Root
  2. Find root in inorder ➔ split left & right
  3. Recur for left part and right part
Complexity Time: O(n) Space: O(n)
3. SERIALIZE AND DESERIALIZE
BINARY TREE (LC 297)
Example (Serialize)
graph TD 1((1)) --> 2((2)) 1 --> 3((3)) 3 --> 4((4)) 3 --> 5((5))
Serialized:
[1,2,4,null,null,5,3,null,6]
(Level Order with nulls)
💡 AHA
Store structure + values.
Use null marker for missing nodes.
⚙️ Pattern
BFS (Level Order) or Preorder
∑ Idea / Formula
Serialize ➔ Traverse and add values (add nulls)
Deserialize ➔ Rebuild tree from values
Complexity Time: O(n) Space: O(n)
6. BURNING BINARY TREE (LC 2385)
Example
graph TD 1((1)) --> 2((2)) 1 --> 3((3)) 2 --> 4((4)) 2 --> 5((5)) 5 --> 7((7)) 3 --> 6((6)) style 5 fill:#fee2e2,stroke:#dc2626,stroke-width:2px,color:#dc2626
Start Node = 5
Time to burn
all nodes = 4
💡 AHA
Fire spreads in all 4 directions.
Convert tree to graph (undirected).
Do BFS from start node.
⚙️ Pattern
Graph + BFS
∑ Idea / Formula
  1. Convert tree to undirected graph
  2. BFS from start node
  3. Count levels (time)
Complexity Time: O(n) Space: O(n)
Common Mental Models
👥 Need parent first Preorder
🔄 Need sorted order Inorder
🌲 Need children first Postorder
🏢 Need level by level BFS
🛤️ Path / Root to Leaf DFS (Backtrack)
🎯 Multiple directions Graph + BFS
Tree Building Index Rules
Preorder + Inorder
Preorder
Root | Left | Right
Inorder
Left | Root | Right
➔ Use root from preorder
Inorder + Postorder
Inorder
Left | Root | Right
Postorder
Left | Right | Root
➔ Use root from postorder
