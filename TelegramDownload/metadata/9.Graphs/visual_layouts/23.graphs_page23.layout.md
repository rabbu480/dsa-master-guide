# Visual Layout Specification: Graph Pattern Guide Cheat Sheet

## 1. Overall Document Structure
- **Type**: Single-page cheat sheet, vertically oriented (A4 format).
- **Grid System**: 
  - The document primarily relies on a multi-row block structure.
  - Top sections and bottom sections use varied horizontal splits (2-column and 3-column splits).
  - The central core of the document is a rigid 3x2 grid containing detailed algorithm blocks.
- **Color Palette**:
  - Primary Theme: Deep Blue (#000080 roughly) used for headers, main titles, and structural borders.
  - Secondary Accents: Green, Orange, Purple used to color-code specific algorithm sections.
  - Background: White.
  - Text: Black or dark gray for body text.
- **Typography**: Sans-serif, clear legible fonts. Use of bolding for emphasis, headings, and keywords. Monospace font used for code snippets.

### 2.3 Main Grid: Algorithm Blocks
- **Layout**: A 3x2 grid of rectangular cards (3 columns, 2 rows).
- **Card Structure (Consistent across all 6 cards)**:
  - **Title Area**: 
    - Colored square with a white number (1 to 6). Colors: Dark Blue (1, 6), Green (2, 5), Orange (3), Purple (4).

  - **Body Content (2-Column Split)**:
    - **Left ("PROCESS (STEPS)")**: Includes a small running figure icon. Contains numbered steps, where numbers are in small filled squares matching the block's theme color.
    - **Right ("CODE TEMPLATE (Java)")**: Includes a code snippet icon. Contains monospace code blocks.

    - **"AHA"**: Lightbulb icon. Core conceptual takeaway.

    - **"Watch Out"**: Warning triangle icon. Common pitfalls.
  - **Metrics Footer**: 
    - Bottom row of the card detailing "Time:" and "Space:" complexities.
