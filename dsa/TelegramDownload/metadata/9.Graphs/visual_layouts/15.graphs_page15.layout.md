# Visual Layout Specification

## Overall Structure
* **Orientation:** Portrait
* **Grid System:** The page is structured into multiple horizontal sections, primarily utilizing a 3-column grid for the main content area, with some top/bottom sections spanning different widths.
* **Background Color:** White.
* **Borders/Dividers:** Thin light gray borders wrap individual cards and panels.

## Header Section
* **Top Banner:** 
  * Features a dark blue badge with white text ("PAGE 11") in the top left corner.
  * Centered next to it is a book icon followed by a large, bold, blue title "GRAPH PATTERN GUIDE".
* **Sub-title:** Centered text reading "PAGE 11 - UNION FIND PROBLEM GUIDE (APPLY TEMPLATES)". Below this is a smaller, italicized, center-aligned subtitle.

## Top Panels (Sub-header area)
* **Layout:** Split into two unequal columns.
* **Left Panel ("HOW TO USE THIS PAGE"):** Roughly 1/3 of the page width.
  * **Header:** Dark blue rectangular banner with white, centered text.
  * **Content:** A left-aligned numbered list with circled numbers. A target graphic is positioned on the right side of the list.
* **Right Panel ("TEMPLATE LEGEND (From Page 10)"):** Roughly 2/3 of the page width.
  * **Header:** Dark blue rectangular banner with white, centered text.
  * **Content:** A horizontal flex-like layout containing five legend items. Each item consists of a colored square box with a white letter (B, C, D, I, P) and an adjacent text label.

## Main Grid Structure (Problems 1-6)
* **Layout:** A 3x2 grid of distinct problem cards (3 columns, 2 rows).
* **Card Design (Consistent across all 6 cards):**
  * **Header:** A dark blue rectangle containing a white number on the left, the problem title in white, and a colored square indicator on the far right (matching the legend).
  * **Base Template Row:** Small, center-aligned text indicating the base template.
  * **Problem Description & Changed Lines:** Left-aligned text.
  * **Code Snippet:** Monospace font with blue syntax highlighting.
  * **Inline Table:** A 3-column layout (Caller, Return, Key Idea) separated by thin vertical borders. Text is center-aligned.
  * **AHA Moment:** A light bulb icon followed by bold text.
  * **Bottom Meta Info:** A 2-column inline layout for "Complexity" and "Interview Tip", with left-aligned small text.

## Bottom Grid Structure (Panels 7-9)
* **Layout:** A 3-column grid.
* **Panel 7 ("CHANGED LINES SUMMARY"):** Leftmost column.
  * **Header:** Dark blue banner, white text.
  * **Content:** A 3-column table with tiny text headers (Problem, Base Template, What Changes).
* **Panel 8 ("UNION FIND TEMPLATE RECAP"):** Middle column.
  * **Header:** Green banner, white text.
  * **Content:** Two code blocks in monospace font with blue syntax, describing different union-find methods.
* **Panel 9 ("RETURN TYPE GUIDE"):** Rightmost column.
  * **Header:** Dark blue banner, white text.
  * **Content:** A 3-column table (Return Type, Use When, Example Problems).

## Bottom-most Grid Structure (Panels 10-12)
* **Layout:** A 3-column grid.
* **Panel 10 ("INTERVIEW CHECKLIST"):** Leftmost column.
  * **Header:** Dark blue banner, white text.
  * **Content:** A vertical list of items, each prefixed with a checked checkbox icon.
* **Panel 11 ("INTERVIEW THINKING FLOW"):** Middle column.
  * **Header:** Dark blue banner, white text.
  * **Content:** A flowchart diagram using rectangular boxes with text and small arrows connecting them downwards.
* **Panel 12 ("PAGE 12 PREVIEW"):** Rightmost column.
  * **Header:** Light blue banner, white text.
  * **Content:** Text followed by a horizontal row of five icons with small labels below each.

## Footer Section
* **Process Flow Diagram:** Located at the very bottom. A horizontal sequence of small icons with descriptive text underneath. Nodes are connected by thin horizontal right-pointing arrows.

## Typography and Colors
* **Headers/Titles:** Bold, all-caps, sans-serif font.
* **Body Text:** Standard sans-serif font.
* **Code Blocks:** Monospace font, distinct blue color scheme.
* **Primary Color:** Dark blue (#000080 or similar) is used heavily for main headers, section banners, and primary text.
* **Secondary Colors:** Green, orange, teal, and pink are used strategically in legend badges and corresponding card indicators to visually link concepts.
