# Visual Layout Specification: Heap Hidden Triggers (Page 4)

## 1. Overall Grid Structure
*   **Page Layout**: The document is structured as a two-column grid with a full-width header and a full-width footer. The layout is dense, utilizing bounding boxes, tables, and stylized lists to organize information visually.
*   **Color Palette**:
    *   **Primary accents**: Dark blue (used for all section headers and main title), Red (used for subtitles and warning elements).
    *   **Backgrounds & Borders**: Light purple, light yellow, light red, and light green are used as background fills and border colors for contextual callout boxes.
    *   **Typography**: Primarily sans-serif; black text for general content, white text for section headers.

## 2. Header Section (Full Width)
*   **Left Side**: Large bold dark blue main title, followed by a red subtitle directly below it.
*   **Right Side**:
    *   A pill-shaped, dark blue badge with white text acting as a page number indicator, aligned to the top right.
    *   A light purple rectangular callout box with a thin purple border and purple text positioned slightly below the page indicator.

## 3. Left Column (approx. 55-60% width)
Contains Sections 1, 3, and 5 stacked vertically.
*   **Section 1 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text spanning the column width.
    *   **Content (Table)**: A two-column table with a light gray outline and horizontal row dividers.
        *   **Left Column**: Each cell contains a distinct, colorful illustrative icon followed by left-aligned text.
        *   **Right Column**: Left-aligned text.
        *   **Headers**: Centered text headers with a faint background.
*   **Section 3 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text.
    *   **Content (Table)**: A three-column table with horizontal borders separating rows, aligning different data types vertically.
*   **Section 5 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text.
    *   **Content (Boxed Layout)**: A light purple bounded box containing a flowchart-like structure.
        *   **Left sub-section**: A vertical list with custom bullet points (numbered solid purple circles).
        *   **Right sub-section**: A right-facing arrow pointing from the list to a light green box with a green border and bold text.

## 4. Right Column (approx. 40-45% width)
Contains Section 2, a "Pro Tip" box, Section 4, and Section 6 stacked vertically.
*   **Section 2 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text.
    *   **Content (List with dividers)**: A list of items separated by light gray horizontal lines. Each item features:
        *   A unique thematic icon on the far left.
        *   A bold title and description in the middle.
        *   Right-aligned text indicating a specific category.
*   **Pro Tip Block**:
    *   **Container**: A light yellow rounded rectangular box with a thin colored border.
    *   **Content**: A lightbulb icon next to the bolded title, followed by left-aligned text.
*   **Section 4 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text.
    *   **Content (Warning Box)**: A light red box with a solid red border. Features a vertical list where each item is preceded by a bold red "X" icon.
*   **Section 6 Block**:
    *   **Header**: Dark blue rectangular block with white, bold text.
    *   **Content (Success/Remember Box)**: A light green box with a solid green border.
        *   Features a vertical list where each item is preceded by a green square checkmark icon.
        *   A large yellow lightbulb illustration is absolutely positioned on the right edge inside the box.

## 5. Footer Section (Full Width)
*   A horizontal layout at the bottom composed of three distinct visual elements.
*   **Left element**: A rectangular box containing a yellow star icon and bold text.
*   **Center element**: Centered text, wrapping slightly, occupying the primary middle space.
*   **Right element**: A rectangular box with a light purple border containing centered text.
