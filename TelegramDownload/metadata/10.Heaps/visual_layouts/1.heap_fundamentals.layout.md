# Visual Layout Specification: Heap Fundamentals

## 1. Overall Structure
- **Page Layout**: A two-column grid layout with full-width header and footer sections.
- **Background Color**: White.
- **Grid System**: 
  - **Header**: 1 row, spanning the full width (2 columns).
  - **Main Body**: 2 distinct vertical columns. The left column contains sections 1 to 5. The right column contains sections 6 to 9.
  - **Footer**: 1 row, spanning the full width, with content aligned to the right.

## 2. Header Section
- **Location**: Top of the page, spanning the entire width.
- **Layout**: Left-aligned main title and subtitle; right-aligned page badge and sub-heading.
- **Visual Elements**:
  - **Main Title**: Large, bold, dark blue typography.
  - **Subtitle**: Medium, blue typography placed next to the main title.
  - **Page Badge**: Dark blue rounded rectangle with white text ("PAGE 1") in the top right corner.
  - **Sub-heading**: Small, bold, right-aligned typography beneath the page badge.
  - **Divider**: A full-width horizontal blue line separates the header from the main content.

## 3. Left Column (Sections 1-5)
- **Width**: Approximately 50% of the page width.
- **Section Headers Style (1-5)**: Dark blue rectangular background block with white, bold text. Left-aligned and numbered.
- **Section 1**: 
  - Standard bulleted list.
- **Section 2**:
  - Split into two parallel sub-columns (Min Heap on left, Max Heap on right).
  - **Left Sub-column (Min Heap)**: Green header badge, green-bordered bounding box containing a binary tree diagram with green circular nodes, followed by green text.
  - **Right Sub-column (Max Heap)**: Red header badge, red-bordered bounding box containing a binary tree diagram with red circular nodes, followed by red text.
- **Section 3**:
  - Text description at the top.
  - Two binary tree diagrams placed side-by-side below the text.
  - **Left Diagram**: Accompanied by a green square checkmark icon indicating a valid state.
  - **Right Diagram**: Accompanied by a red square cross icon indicating an invalid state.
- **Section 4**:
  - **Left**: A binary tree diagram with numbered nodes.
  - **Right**: A light blue bordered box detailing "Index Relationships".
  - **Bottom**: A 1D array visualization showing horizontal mappings of "Index" and "Value" using distinct square cells with blue borders.
- **Section 5**:
  - **Table**: 4 columns and 7 rows. The header row features a light blue background. Cell borders are visible.
  - **Alert Box 1**: A full-width (within the column) rectangular block with a light yellow background.
  - **Alert Box 2**: A full-width rectangular block with a light blue background, accompanied by a golden bulb icon.

## 4. Right Column (Sections 6-9)
- **Width**: Approximately 50% of the page width.
- **Section Headers Style (6-8)**: Dark blue typography, bold, numbered, with no background color block.
- **Section Header Style (9)**: Red typography, bold, numbered, with no background color block.
- **Section 6**:
  - Divided into sub-sections with distinct typography colors (e.g., green, purple, red).
  - **Code Blocks**: Enclosed in light blue bordered rectangles with a light gray background and monospaced font.
  - **Table**: 2 columns and 6 rows. The header row features a light blue background.
- **Section 7**:
  - A formatted two-column alignment list, where terms on the left are separated by a colon from their definitions on the right.
- **Section 8**:
  - A list structure utilizing green checkmark icons in place of standard bullet points.
- **Section 9**:
  - A list structure utilizing red square cross icons in place of standard bullet points.

## 5. Footer Section
- **Location**: Bottom of the page, spanning the entire width.
- **Visual Elements**:
  - **Divider**: A subtle horizontal line separates the footer from the main content above.
  - **Content**: A right-aligned text block indicating the "Next Page", accompanied by a blue right-pointing arrow icon.
