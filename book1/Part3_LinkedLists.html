3.2 Fast / Slow Pointer (Floyd's Cycle Detection)

Mental Model: Move slow 1 step and fast 2 steps. If a cycle exists, they must meet inside the loop.

public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) { // Phase 1: Meeting point found
            ListNode entry = head;
            while (entry != slow) { // Phase 2: Find cycle start
                entry = entry.next;
                slow = slow.next;
            }
            return entry;
        }
    }
    return null;
}
3.3 Reverse Linked List (Iterative)
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
