# Visual Layout Specification

## Overall Structure
- The document is a cheat sheet titled "BINARY SEARCH", organized in a two-column layout grid.
- **Top Header**: Spans the full width at the top, featuring a large title with a magnifying glass icon and a prominent subtitle block centered below it.
- **Top Right (Absolute)**: A floating block with a dashed blue border containing a "Goal" section.
- **Main Content**: Divided into two primary columns (Left Column and Right Column).
- **Footer**: A full-width section at the bottom containing a concluding message on the left and a page indicator on the right.

## Column 1 (Left Column)
- **Section 1**: A block with a solid blue header tab ("1. WHEN TO USE BINARY SEARCH?") intersecting the top border of a larger box. The main body of this section is outlined in light blue and contains vertically aligned bullet points (marked with green checkmark icons).
- **Section 2**: 
  - A blue header tab ("2. CLASSIC BINARY SEARCH TEMPLATE").
  - The content is a dark theme code block with syntax-highlighted text.
  - Immediately below the code block is a smaller, light blue callout box featuring a yellow lightbulb icon.
- **Section 3**: 
  - A blue header tab ("3. BINARY SEARCH DECISION TREE").
  - The body is outlined in blue and contains a complex flowchart/decision tree.
  - The flowchart uses rectangular nodes with different border colors (purple, green, red, orange) connected by directional arrows labeled "YES" (green) and "NO" (red).

## Column 2 (Right Column)
- **Section 'AHA MOMENT'**: 
  - A green header tab.
  - The main body is outlined with a light green background. 
  - It contains a visual representation of a 1D array partitioned into blocks containing red 'F's and green 'T's, with an upward-pointing arrow indicating the transition point.
- **Section 'INTERVIEW TIP'**: 
  - An orange/yellow header tab with a star icon.
  - The main body is outlined with a light yellow/orange background and contains bulleted text.
- **Section 'COMMON MISTAKES'**: 
  - A red header tab with an 'X' icon.
  - The main body is outlined with a light red/pink background and contains bulleted text.
- **Section 4**: 
  - A blue header tab ("4. BINARY SEARCH ON SORTED ARRAY").
  - The body is outlined in blue. It displays a step-by-step visual trace using three distinct array state diagrams ("Step 1", "Step 2", "Step 3").
  - Target elements and calculated mid-points are highlighted in yellow. Textual explanations accompany each array block on the right.
- **Section 5**: 
  - A purple header tab ("5. COMPLEXITY ANALYSIS").
  - The content is split into two side-by-side elements:
    - Left side: A 2-column, 4-row data table with a solid purple header row and alternating white/light-purple data rows.
    - Right side: A light grey box styled as a "Remember" sticky note pinned with a purple pushpin, containing text.

## Color Palette
- **Primary Headers**: Dark blue for main title and most numbered section tabs.
- **Icons & Highlights**: 
  - Green (checkmarks, "YES" paths, "T" in arrays).
  - Red (mistake icons, "NO" paths, "F" in arrays).
  - Yellow (lightbulbs, target highlights in arrays, star icon).
  - Purple (Complexity Analysis headers and pushpin).
- **Code Block**: Dark grey/black background with colored text for syntax highlighting (keywords, comments in green).

## Alignment & Typography
- The layout relies heavily on top-aligned left/right columns.
- Header tabs use absolute positioning relative to their container boxes (often overlapping the top border of the box).
- Content within blocks is predominantly left-aligned, except for titles and array elements which are center-aligned.
