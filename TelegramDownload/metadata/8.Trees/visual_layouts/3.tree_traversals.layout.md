# Visual Layout Specification: Tree Traversals

## 1. Overall Structure
The document is a single-page technical reference or cheatsheet detailing "Tree Traversals". It uses a multi-section, block-based layout with a consistent color-coding scheme to differentiate between different types of traversals. The layout is structured sequentially, moving from general concepts to specific traversals, and concluding with comparison and application guidelines.

## 2. Header Section
- **Location**: Top of the page.
- **Layout**: Two-column split.
- **Left Column**:
  - A prominent, large dark-blue square containing the section number "2" in white.
  - Large, bold uppercase title text in dark blue to the right of the number block.
  - A smaller subtitle centered below the main title.
- **Right Column (Quick View)**:
  - A rectangular box with a thin gray border.
  - Features a dark blue header tab on the top edge with white text.
  - Inside the box, a 2-column layout:
    - Left: A small, hierarchical tree diagram.
    - Right: A text legend explaining the diagram's components.

## 3. Section 2.1: Depth First Search (DFS) Traversals
- **Header**: A full-width, dark blue horizontal bar containing white uppercase text.
- **Body**: Consists of three vertically stacked sub-blocks (Preorder, Inorder, Postorder).
- **Sub-block Layout (Consistent across all three)**:
  - A 3-column grid structure.
  - **Column 1 (Visual Representation, ~35% width)**:
    - A colored circle with a number (1, 2, or 3) indicating the sequence.
    - A title indicating the traversal type and its node-visit sequence logic.
    - A visual tree diagram below the title.
  - **Column 2 (Sequences and Insights, ~30% width)**:
    - Two vertically stacked components.
    - Top: An "ORDER OF VISIT" header (solid colored background, white text) followed by a numerical sequence below it.
    - Bottom: An "AHA MOMENT" header (solid colored background, white text) followed by brief explanatory text.
  - **Column 3 (Applications, ~35% width)**:
    - A prominent, light-colored rectangular box spanning the height of the row.
    - The box has a rounded border and a very light background tint matching the section's theme color.
    - Contains a header with an icon and a bulleted list of use cases.
- **Color Coding**:
  - Sub-block 1 (Preorder): Green theme.
  - Sub-block 2 (Inorder): Blue theme.
  - Sub-block 3 (Postorder): Purple theme.

## 4. Section 2.2: Breadth First Search (BFS) Traversal
- **Header**: A full-width, dark blue horizontal bar containing white uppercase text.

- **Column 2 (Sequences and Insights, ~30% width)**:

## 7. Global Design Elements
- **Typography**: Clean, sans-serif fonts used throughout. Bold weights used for headers, numbers, and key terms.
- **Visuals**: Simple, node-and-edge graph diagrams used consistently to represent trees.
- **Color Palette**: Dark blue is used as the primary structural color (headers, titles). A secondary palette of distinct colors (Green, Blue, Purple, Orange) is systematically used to categorize and distinguish different algorithms.
- **Icons**: Minimalistic outline and flat icons are used in headers, tables, and lists to provide visual cues.
