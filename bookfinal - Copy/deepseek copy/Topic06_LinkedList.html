💡 WHY LINKED LISTS?

Arrays require contiguous memory blocks. Linked Lists store nodes anywhere in Heap memory, linked via next pointers for O(1) insertion/deletion without shifting!

💡 THE DUMMY NODE AHA
Always use a Dummy Head Sentinel Node (`ListNode dummy = new ListNode(0)`) to eliminate edge cases when modifying or removing the real head node!
1 CORE NODE STRUCTURE
public class ListNode {
    int val;
    ListNode next;

    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
2 VISUALIZING POINTER REVERSAL
3-Pointer Window (prev, curr, next):
prev = null,  curr = [1] -> [2] -> [3] -> null

Step 1: next = curr.next ([2])
Step 2: curr.next = prev (null <- [1])
Step 3: prev = curr ([1]), curr = next ([2])

Final: [3] -> [2] -> [1] -> null
📚 COMPLEXITY REASONING
OperationTimeSpace
Prepend / Append (with tail)O(1)O(1)
Search / Index AccessO(N)O(1)
In-place ReversalO(N)O(1)

⚡ CLUES THAT SCREAM LINKED LIST

1. "Modify list in-place" → 3-Pointer Reversal or Fast/Slow

2. "Find cycle / entry point" → Floyd's Tortoise & Hare

3. "Remove Nth node from end" → 2 Pointers offset by N

4. "Merge K sorted lists" → Min-Heap PriorityQueue

⚡ 5-STEP LINKED LIST THINKING FRAMEWORK
  1. Can we use a dummy node? If head might change, use dummy sentinel.
  2. What's the traversal pattern? Single pointer? Fast/slow? Two pointers?
  3. Are we modifying pointers? Save `next` before overwriting!
  4. Need middle or cycle detection? Floyd's Fast & Slow.
  5. Check edge cases: Empty list, single node, two nodes.

PATTERN 1 — 3-POINTER REVERSAL LC 206 · EASY
When to Use: Reverse full or subsegments in O(N) time and O(1) space.
Input: [1,2,3,4,5]
Output: [5,4,3,2,1]
💡 AHA
Always save `curr.next` before overwriting! The 3 pointers are `prev`, `curr`, and `nextTemp`. 
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;

    while (curr != null) {
        ListNode nextTemp = curr.next; // Save next node
        curr.next = prev;              // Reverse link
        prev = curr;                   // Move prev forward
        curr = nextTemp;               // Move curr forward
    }
    return prev; // New head
}
PATTERN 1B — RECURSIVE REVERSE LC 206 · EASY
When to Use: When interviewer asks "Can you solve recursively?"
💡 AHA
Base case: null or single node. Recursively reverse the rest, then attach current node at the end. 
public ListNode reverseListRecursive(ListNode head) {
    // Base case: empty list or single node
    if (head == null || head.next == null) {
        return head;
    }

    // Recursively reverse the rest of the list
    ListNode newHead = reverseListRecursive(head.next);

    // Attach current node at the end of reversed list
    head.next.next = head;
    head.next = null;

    return newHead;
}
PATTERN 2 — DUMMY SENTINEL MERGE LC 21 · EASY
When to Use: Merging two sorted lists without modifying input.
Input: [1,2,4], [1,3,4]
Output: [1,1,2,3,4,4]
💡 AHA
Dummy node eliminates edge cases. Attach smaller node, then attach remaining list. 
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;

    while (list1 != null && list2 != null) {
        if (list1.val <= list2.val) {
            curr.next = list1;
            list1 = list1.next;
        } else {
            curr.next = list2;
            list2 = list2.next;
        }
        curr = curr.next;
    }

    // Attach remaining nodes
    curr.next = (list1 != null) ? list1 : list2;

    return dummy.next;
}
PATTERN 3 — FLOYD'S CYCLE DETECTION LC 141 · EASY
When to Use: Detect if a cycle exists in a linked list.
Input: [3,2,0,-4], pos=1 (cycle)
Output: true
💡 AHA — Why Fast & Slow Works
slow = 1 step, fast = 2 steps. Distance difference increases by 1 each iteration. If cycle length = C, after C steps fast laps slow → collision guaranteed! 
public boolean hasCycle(ListNode head) {
    if (head == null || head.next == null) return false;

    ListNode slow = head;
    ListNode fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;          // Move 1 step
        fast = fast.next.next;     // Move 2 steps

        if (slow == fast) return true; // Cycle detected!
    }
    return false; // No cycle
}

PATTERN 4 — MID SPLIT + REVERSE LC 234 · EASY
When to Use: Check if linked list is a palindrome in O(N) time and O(1) space.
Input: [1,2,2,1]
Output: true
💡 AHA
Find middle with fast/slow → reverse second half → compare both halves! 
public boolean isPalindrome(ListNode head) {
    // Step 1: Find middle with fast & slow
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // Step 2: Reverse second half
    ListNode prev = null, curr = slow;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }

    // Step 3: Compare first half with reversed second half
    ListNode first = head, second = prev;
    while (second != null) {
        if (first.val != second.val) return false;
        first = first.next;
        second = second.next;
    }
    return true;
}
PATTERN 5 — OFFSET POINTERS LC 19 · MEDIUM
When to Use: Remove Nth node from end in one pass.
Input: [1,2,3,4,5], n=2
Output: [1,2,3,5]
💡 AHA
Advance `fast` by N+1 from dummy. Then move both until `fast == null`. `slow.next` is the target! 
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    ListNode fast = dummy, slow = dummy;

    // Advance fast by n+1 steps
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }

    // Move both pointers until fast reaches end
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }

    // Remove the nth node from end
    slow.next = slow.next.next;

    return dummy.next;
}
⚠️ Assumes n is valid (1 ≤ n ≤ list length). LeetCode guarantees this.
PATTERN 6 — INTERLEAVING LC 143 · MEDIUM
When to Use: Reorder list as L0 → Ln → L1 → Ln-1 → ...
Input: [1,2,3,4,5]
Output: [1,5,2,4,3]
💡 AHA
Find mid → reverse second half → interleave first and reversed second. 
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;

    // Step 1: Find middle
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // Step 2: Reverse second half
    ListNode prev = null, curr = slow.next;
    slow.next = null; // Split list
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }

    // Step 3: Interleave
    ListNode first = head, second = prev;
    while (second != null) {
        ListNode tmp1 = first.next;
        ListNode tmp2 = second.next;

        first.next = second;
        second.next = tmp1;

        first = tmp1;
        second = tmp2;
    }
}

PATTERN 7 — DUMMY + CARRY LC 2 · MEDIUM
When to Use: Add two numbers represented as linked lists.
Input: [2,4,3], [5,6,4] (342 + 465)
Output: [7,0,8] (807)
💡 AHA
Sum = val1 + val2 + carry. Digit = sum % 10. Carry = sum / 10. Dummy node for result. 
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;
    int carry = 0;

    while (l1 != null || l2 != null || carry != 0) {
        int val1 = (l1 != null) ? l1.val : 0;
        int val2 = (l2 != null) ? l2.val : 0;
        int sum = val1 + val2 + carry;

        carry = sum / 10;
        curr.next = new ListNode(sum % 10);
        curr = curr.next;

        if (l1 != null) l1 = l1.next;
        if (l2 != null) l2 = l2.next;
    }
    return dummy.next;
}
PATTERN 8 — HASHMAP CLONE LC 138 · MEDIUM
When to Use: Clone a linked list with random pointers.
Input: [[7,null],[13,0],[11,4],[10,2],[1,0]]
Output: Copy of the list
💡 AHA
Pass 1: create copies in HashMap. Pass 2: assign next and random pointers from original to copies. 
public Node copyRandomList(Node head) {
    if (head == null) return null;

    // Pass 1: Map original -> copy
    Map<Node, Node> map = new HashMap<>();
    Node curr = head;
    while (curr != null) {
        map.put(curr, new Node(curr.val));
        curr = curr.next;
    }

    // Pass 2: Assign next and random pointers
    curr = head;
    while (curr != null) {
        Node copy = map.get(curr);
        copy.next = map.get(curr.next);
        copy.random = map.get(curr.random);
        curr = curr.next;
    }

    return map.get(head);
}
PATTERN 8B — RANDOM POINTER O(1) SPACE LC 138 · MEDIUM
When to Use: Follow-up: "Can you do it in O(1) space?"
💡 AHA
Interweave original and copied nodes: A → A' → B → B'. Then assign random pointers, then separate. 
public Node copyRandomListO1(Node head) {
    if (head == null) return null;

    // Pass 1: Create copy nodes interleaved
    Node curr = head;
    while (curr != null) {
        Node copy = new Node(curr.val);
        copy.next = curr.next;
        curr.next = copy;
        curr = copy.next;
    }

    // Pass 2: Assign random pointers
    curr = head;
    while (curr != null) {
        if (curr.random != null) {
            curr.next.random = curr.random.next;
        }
        curr = curr.next.next;
    }

    // Pass 3: Separate original and copy lists
    Node dummy = new Node(0);
    Node copyCurr = dummy;
    curr = head;
    while (curr != null) {
        copyCurr.next = curr.next;
        copyCurr = copyCurr.next;
        curr.next = curr.next.next;
        curr = curr.next;
    }

    return dummy.next;
}

⭐ LC 142 · Cycle Entry MEDIUM
Input: [3,2,0,-4], pos=1
Output: node at pos=1
Pattern: Floyd's + Reset
💡 AHA — Why Reset Works
Let L = distance from head to cycle entry, C = cycle length. When slow & fast meet, slow has traveled L + K steps. Reset slow to head. Moving both one step, they meet at entry after L steps because L = C - K (mod C). 
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;

    // Phase 1: Detect cycle
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) break;
    }

    if (fast == null || fast.next == null) return null;

    // Phase 2: Find cycle entry
    slow = head;
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;
}
⭐ LC 23 · Merge K Lists HARD
Input: [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Pattern: Min-Heap PQ
💡 AHA
Two approaches: (1) Min-Heap O(N log K) or (2) Divide & Conquer O(N log K) with O(log K) stack. Both are accepted! 
// Approach 1: Min-Heap (PriorityQueue)
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;

    PriorityQueue<ListNode> pq = new PriorityQueue<>(
        (a, b) -> a.val - b.val
    );

    for (ListNode node : lists) {
        if (node != null) pq.offer(node);
    }

    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;

    while (!pq.isEmpty()) {
        ListNode min = pq.poll();
        curr.next = min;
        curr = curr.next;

        if (min.next != null) pq.offer(min.next);
    }
    return dummy.next;
}

// Approach 2: Divide & Conquer (merge two at a time)
public ListNode mergeKListsDC(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return mergeK(lists, 0, lists.length - 1);
}

private ListNode mergeK(ListNode[] lists, int l, int r) {
    if (l == r) return lists[l];
    int mid = l + (r - l) / 2;
    ListNode left = mergeK(lists, l, mid);
    ListNode right = mergeK(lists, mid + 1, r);
    return mergeTwoLists(left, right);
}
⭐ LC 148 · Merge Sort List MEDIUM
Input: [4,2,1,3]
Output: [1,2,3,4]
Pattern: Merge Sort
💡 AHA
Find mid → sort left → sort right → merge. Ties together everything: fast/slow, merge, recursion! 
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;

    // Step 1: Find middle
    ListNode slow = head, fast = head, prev = null;
    while (fast != null && fast.next != null) {
        prev = slow;
        slow = slow.next;
        fast = fast.next.next;
    }
    prev.next = null; // Split

    // Step 2: Sort each half
    ListNode left = sortList(head);
    ListNode right = sortList(slow);

    // Step 3: Merge sorted halves
    return mergeTwoLists(left, right);
}
⭐ LC 160 · Intersection EASY
Input: intersectVal=8, listA=[4,1,8,4,5], listB=[5,6,1,8,4,5]
Output: node with val=8
Pattern: Two Pointers
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    if (headA == null || headB == null) return null;

    ListNode a = headA, b = headB;

    // When a reaches end, jump to headB. When b reaches end, jump to headA.
    while (a != b) {
        a = (a == null) ? headB : a.next;
        b = (b == null) ? headA : b.next;
    }
    return a;
}

⭐ LC 92 · Reverse Between MEDIUM
Input: [1,2,3,4,5], left=2, right=4
Output: [1,4,3,2,5]
Pattern: Dummy + Find + Reverse + Reconnect
💡 AHA — The Most Common Medium-Level Linked List Problem
Combines 3 patterns: Dummy Node, Find Position, and Subsegment Reversal. The key is carefully reconnecting the reversed part back to the rest of the list. 
public ListNode reverseBetween(ListNode head, int left, int right) {
    if (head == null || left == right) return head;

    // Step 1: Dummy node to handle left = 1 case
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;

    // Step 2: Move prev to node before left
    for (int i = 1; i < left; i++) {
        prev = prev.next;
    }

    // Step 3: Reverse subsegment from left to right
    ListNode curr = prev.next;
    ListNode next = null;

    for (int i = 0; i < right - left; i++) {
        next = curr.next;
        curr.next = next.next;
        next.next = prev.next;
        prev.next = next;
    }

    return dummy.next;
}
⭐ LC 86 · Partition List MEDIUM
Input: [1,4,3,2,5,2], x=3
Output: [1,2,2,4,3,5]
Pattern: Two Lists + Dummy
💡 AHA
Build two separate lists: small (< x) and large (>= x). Then combine them. Dummy nodes for both lists eliminate edge cases. 
public ListNode partition(ListNode head, int x) {
    // Two dummy heads for small and large lists
    ListNode smallHead = new ListNode(0);
    ListNode largeHead = new ListNode(0);
    ListNode small = smallHead, large = largeHead;

    ListNode curr = head;
    while (curr != null) {
        if (curr.val < x) {
            small.next = curr;
            small = small.next;
        } else {
            large.next = curr;
            large = large.next;
        }
        curr = curr.next;
    }

    // Terminate large list
    large.next = null;

    // Connect small list to large list
    small.next = largeHead.next;

    return smallHead.next;
}
⭐ LC 24 · Swap Pairs MEDIUM

public ListNode swapPairs(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        ListNode first = prev.next;
        ListNode second = first.next;

        // Swap
        first.next = second.next;
        second.next = first;
        prev.next = second;

        // Move prev two steps
        prev = first;
    }

    return dummy.next;
}
⭐ LC 203 · Remove Elements EASY
Input: [1,2,6,3,4,5,6], val=6
Output: [1,2,3,4,5]
Pattern: Dummy Node
public ListNode removeElements(ListNode head, int val) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode curr = dummy;

    while (curr.next != null) {
        if (curr.next.val == val) {
            curr.next = curr.next.next;
        } else {
            curr = curr.next;
        }
    }
    return dummy.next;
}
⭐ LC 328 · Odd Even MEDIUM
Input: [1,2,3,4,5]
Output: [1,3,5,2,4]
Pattern: Two Pointers
public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) return head;

    ListNode odd = head, even = head.next;
    ListNode evenHead = even;

    while (even != null && even.next != null) {
        odd.next = even.next;
        odd = odd.next;
        even.next = odd.next;
        even = even.next;
    }
    odd.next = evenHead;
    return head;
}
