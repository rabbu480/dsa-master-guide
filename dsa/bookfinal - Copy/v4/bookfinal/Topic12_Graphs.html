💡 WHY DO GRAPHS EXIST?

Arrays and Trees represent linear or hierarchical data. But real-world data is a network of connections (social friends, web links, maps, dependencies).

Graphs model entities (Vertices) and relationships (Edges) with zero restrictions on cycles or connectivity.

💡 THE VISITED LAW
A Tree is an acyclic graph. In Graphs, cycles exist! Traversal MUST track visited[] or visited[][] to prevent infinite recursion loop!
1 GRAPH TERMINOLOGY
  • Vertex (V): Node / entity in network
  • Edge (E): Connection / link between nodes
  • Degree: Count of edges attached to node
  • In-Degree / Out-Degree: Incoming vs outgoing edges
  • Path / Cycle: Sequence of nodes / closed loop

TYPE 1
GRID GRAPH TRAVERSALS (2D Matrix DFS & BFS)
e.g. Number of Islands (LC 200), Max Area of Island (LC 695)
Grid DFS Template
void dfs(char[][] grid, int r, int c) {
  if (r < 0 || r >= grid.length || 
      c < 0 || c >= grid[0].length || 
      grid[r][c] == '0') return;
  grid[r][c] = '0'; // mark visited in-place
  for (int[] d : DIRS)
    dfs(grid, r + d[0], c + d[1]);
}
Grid BFS Template
void bfs(char[][] grid, int sr, int sc) {
  Queue<int[]> q = new LinkedList<>();
  q.offer(new int[]{sr, sc}); grid[sr][sc] = '0';
  while (!q.isEmpty()) {
    int[] curr = q.poll();
    for (int[] d : DIRS) {
      int nr = curr[0] + d[0], nc = curr[1] + d[1];
      if (nr >= 0 && nr < grid.length && 
          nc >= 0 && nc < grid[0].length && 
          grid[nr][nc] == '1') {
        grid[nr][nc] = '0'; // mark when enqueuing!
        q.offer(new int[]{nr, nc});
      }
    }
  }
}
Key Rule
Mark grid[nr][nc] = '0' BEFORE adding to queue to avoid TLE/duplicate enqueueing!
Time: O(R × C)
Space: O(R × C) worst case stack/queue
TYPE 2
TREE GRAPH TRAVERSALS (Acyclic Graph DFS & BFS)
e.g. Tree Diameter, Graph Valid Tree, Reconstruct Tree
Parent-Track DFS (No visited[] array needed!)
void dfs(int u, int p, List<Integer>[] adj) {
  for (int v : adj[u]) {
    if (v != p) { // Skip immediate parent to avoid backtrack!
      dfs(v, u, adj);
    }
  }
}
Tree BFS Level Order
Queue<Integer> q = new LinkedList<>();
q.offer(root);
while (!q.isEmpty()) {
  int size = q.size();
  for (int i = 0; i < size; i++) {
    int u = q.poll();
    for (int v : adj[u]) q.offer(v);
  }
}
AHA Insight
In a tree (acyclic graph), checking v != parent replaces full visited[] tracking!

void dfs(int u, List<Integer>[] adj, boolean[] vis) {
  vis[u] = true;

void bfs(int src, List<Integer>[] adj, boolean[] vis) {
  Queue<Integer> q = new LinkedList<>();
  q.offer(src); vis[src] = true;
  while (!q.isEmpty()) {
    int u = q.poll();
    for (int v : adj[u]) {
      if (!vis[v]) {
        vis[v] = true;
        q.offer(v);
      }
    }
  }
}

OBJECT / CUSTOM NODE GRAPH TRAVERSALS (Clone Graph)
e.g. Clone Graph (LC 133)
Clone Graph DFS with Map Visited
class Node { public int val; public List<Node> neighbors; }

Map<Node, Node> map = new HashMap<>();

Node cloneGraph(Node node) {
  if (node == null) return null;
  if (map.containsKey(node)) return map.get(node);
  
  Node copy = new Node(node.val, new ArrayList<>());
  map.put(node, copy);
  
  for (Node neighbor : node.neighbors) {
    copy.neighbors.add(cloneGraph(neighbor));
  }
  return copy;
}
Clone Graph BFS Template
Node cloneGraphBFS(Node node) {
  if (node == null) return null;
  Map<Node, Node> map = new HashMap<>();
  Queue<Node> q = new LinkedList<>();
  
  q.offer(node);
  map.put(node, new Node(node.val, new ArrayList<>()));
  
  while (!q.isEmpty()) {
    Node u = q.poll();
    for (Node v : u.neighbors) {
      if (!map.containsKey(v)) {
        map.put(v, new Node(v.val, new ArrayList<>()));
        q.offer(v);
      }
      map.get(u).neighbors.add(map.get(v));
    }
  }
  return map.get(node);
}

PAGE 5
MULTI-SOURCE BFS · TOPOLOGICAL SORT · KAHN'S BFS
ADVANCED 1
MULTI-SOURCE BFS (Parallel Propagation)
e.g. Rotting Oranges (LC 994), 01 Matrix (LC 542), Walls and Gates
Multi-Source Concept
  • Enqueue ALL starting sources at t=0
  • Process layer-by-layer (minute-by-minute)
  • Computes minimum distance to ANY source
💡 AHA
Instead of running BFS from each source separately (slow O(k·V)), add all sources to queue initially and run ONE BFS (fast O(V+E))!
Template — Rotting Oranges (LC 994)
int orangesRotting(int[][] grid) {
  Queue<int[]> q = new LinkedList<>();
  int fresh = 0, time = 0;
  for (int r = 0; r < grid.length; r++)
    for (int c = 0; c < grid[0].length; c++)
      if (grid[r][c] == 2) q.offer(new int[]{r, c});
      else if (grid[r][c] == 1) fresh++;
  
  while (!q.isEmpty() && fresh > 0) {
    time++; int size = q.size();
    for (int i = 0; i < size; i++) {
      int[] curr = q.poll();
      for (int[] d : DIRS) {
        int nr = curr[0]+d[0], nc = curr[1]+d[1];
        if (nr>=0 && nr<grid.length && nc>=0 && nc<grid[0].length && grid[nr][nc]==1) {
          grid[nr][nc] = 2; fresh--; q.offer(new int[]{nr, nc});
        }
      }
    }
  }
  return fresh == 0 ? time : -1;
}
ADVANCED 2
TOPOLOGICAL SORT (Kahn's In-Degree BFS & Cycle Detection)
e.g. Course Schedule I & II (LC 207, 210), Alien Dictionary
Kahn's Algorithm Steps
  1. Calculate indegree[] for all nodes
  2. Push nodes with indegree == 0 to Queue
  3. Poll node, decrement neighbor indegrees
  4. If neighbor indegree reaches 0 → enqueue
  5. If processed count < V → Cycle exists!
Template — Course Schedule II (LC 210)
int[] findOrder(int n, int[][] prereqs) {
  List<Integer>[] adj = new ArrayList[n]; int[] in = new int[n];
  for (int i=0; i<n; i++) adj[i] = new ArrayList<>();
  for (int[] p : prereqs) { adj[p[1]].add(p[0]); in[p[0]]++; }
  
  Queue<Integer> q = new LinkedList<>();
  for (int i=0; i<n; i++) if (in[i] == 0) q.offer(i);
  
  int[] res = new int[n]; int idx = 0;
  while (!q.isEmpty()) {
    int u = q.poll(); res[idx++] = u;
    for (int v : adj[u]) if (--in[v] == 0) q.offer(v);
  }
  return idx == n ? res : new int[0]; // Cycle if idx != n
}

DSU
DISJOINT SET UNION (Union-Find with Path Compression & Rank)
e.g. Redundant Connection (LC 684), Number of Provinces (LC 547)
DSU Operations
• Find(x): Find root + Path Compression
• Union(x, y): Merge sets by Rank
• Time: O(α(N)) ≈ O(1) amortized
Template — DSU Class
class DSU {
  int[] parent, rank;
  DSU(int n) {
    parent = new int[n]; rank = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;
  }
  int find(int i) {
    if (parent[i] == i) return i;
    return parent[i] = find(parent[i]); // Path compression
  }
  boolean union(int i, int j) {
    int rootI = find(i), rootJ = find(j);
    if (rootI != rootJ) {
      if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
      else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
      else { parent[rootJ] = rootI; rank[rootI]++; }
      return true;
    }
    return false; // Already in same set -> Cycle detected!
  }
}
DIJKSTRA
DIJKSTRA'S SHORTEST PATH (Non-Negative Weighted Graph)
e.g. Network Delay Time (LC 743), Path with Min Effort
Dijkstra Concept
Min Heap stores [cost, node].
Always expand nearest unvisited node.
Time: O((V + E) log V)
Space: O(V + E)
Template — Network Delay Time (LC 743)
int networkDelayTime(int[][] times, int n, int k) {
  List<int[]>[] adj = new ArrayList[n+1];
  for (int i=1; i<=n; i++) adj[i] = new ArrayList<>();
  for (int[] t : times) adj[t[0]].add(new int[]{t[1], t[2]});
  
  PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
  int[] dist = new int[n+1]; Arrays.fill(dist, Integer.MAX_VALUE);
  pq.offer(new int[]{0, k}); dist[k] = 0;
  
  while (!pq.isEmpty()) {
    int[] cur = pq.poll(); int d = cur[0], u = cur[1];
    if (d > dist[u]) continue;
    for (int[] nei : adj[u]) {
      int v = nei[0], w = nei[1];
      if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; pq.offer(new int[]{dist[v], v}); }
    }
  }
  int max = 0; for (int i=1; i<=n; i++) { if (dist[i]==Integer.MAX_VALUE) return -1; max = Math.max(max, dist[i]); }
  return max;
}
MST
KRUSKAL'S MINIMUM SPANNING TREE (Sort Edges + DSU)
e.g. Min Cost to Connect All Points (LC 1584)
Kruskal MST Template
int minCostConnectPoints(int[][] pts) {
  int n = pts.length; List<int[]> edges = new ArrayList<>();
  for (int i=0; i<n; i++)
    for (int j=i+1; j<n; j++)
      edges.add(new int[]{Math.abs(pts[i][0]-pts[j][0]) + Math.abs(pts[i][1]-pts[j][1]), i, j});
  
  edges.sort((a,b)->a[0]-b[0]); // Sort edges by weight!
  DSU dsu = new DSU(n); int cost = 0, count = 0;
  for (int[] e : edges) {
    if (dsu.union(e[1], e[2])) { cost += e[0]; if (++count == n - 1) break; }
  }
  return cost;
}

💼 INTERVIEW TRADE-OFFS & FOLLOW-UPS
Interviewer AsksYour Answer
Why BFS for shortest path, not DFS?BFS explores level-by-level, ensuring first arrival at target is shortest. DFS can explore deep long paths first.
Why not Dijkstra for negative weights?Dijkstra assumes distances are non-decreasing. Use Bellman-Ford for negative weights.
Matrix vs Adj List memory?Adj List is O(V+E) (optimal for sparse). Matrix is O(V²) (wasteful for sparse).

LC 207 · Course Schedule I MEDIUM
Pattern: Topological Cycle Detect
Key Insight: Kahn's BFS. Processed count == n.
Kahn's BFS
boolean canFinish(int n, int[][] prereqs) {
  List<Integer>[] adj = new ArrayList[n]; int[] in = new int[n];
  for (int i=0; i<n; i++) adj[i] = new ArrayList<>();
  for (int[] p : prereqs) { adj[p[1]].add(p[0]); in[p[0]]++; }
  Queue<Integer> q = new LinkedList<>();
  for (int i=0; i<n; i++) if (in[i] == 0) q.offer(i);
  int count = 0;
  while (!q.isEmpty()) {
    int u = q.poll(); count++;
    for (int v : adj[u]) if (--in[v] == 0) q.offer(v);
  }
  return count == n;
}

Key Insight: Min Heap by distance. Max dist of all nodes.
Dijkstra PQ
int networkDelayTime(int[][] times, int n, int k) {
  List<int[]>[] adj = new ArrayList[n+1];
  for (int i=1; i<=n; i++) adj[i] = new ArrayList<>();
  for (int[] t : times) adj[t[0]].add(new int[]{t[1], t[2]});
  PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
  int[] dist = new int[n+1]; Arrays.fill(dist, Integer.MAX_VALUE);
  pq.offer(new int[]{0, k}); dist[k] = 0;
  while (!pq.isEmpty()) {
    int[] cur = pq.poll(); int d = cur[0], u = cur[1];
    if (d > dist[u]) continue;
    for (int[] nei : adj[u]) {
      if (dist[u] + nei[1] < dist[nei[0]]) {
        dist[nei[0]] = dist[u] + nei[1]; pq.offer(new int[]{dist[nei[0]], nei[0]});
      }
    }
  }
  int max = 0; for (int i=1; i<=n; i++) { if (dist[i]==Integer.MAX_VALUE) return -1; max = Math.max(max, dist[i]); }
  return max;
}

📐 MATHEMATICAL COMPLEXITY DERIVATIONS

Why DFS/BFS is O(V + E):
Every node is enqueued/visited at most once (O(V)). Every edge is traversed at most once in directed (twice in undirected) (O(E)). Total = O(V + E).

Why Dijkstra is O((V + E) log V):
Min-heap holds at most E edges. Each edge relaxation does a pq.offer() of O(log V). Total = O(E log V + V log V).
