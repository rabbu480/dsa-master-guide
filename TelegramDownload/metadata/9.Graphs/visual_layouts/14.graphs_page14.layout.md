# Visual Layout Specification

## Overall Page Structure
- **Header Section:** Top of the page, spanning full width. Contains a page number tag on the left, a large main title, a subtitle, and a tagline.
- **Main Grid:** A multi-column layout divided into multiple numbered sections (1 to 12).
- **Background:** White page background with distinct borders separating sections.

## Sections Layout
- **Section 1 (Top Left):** Single column block.
- **Section 2 (Top Middle):** Tabular layout. Below it is a TIP block with a blue background.
- **Section 3 (Top Middle to Right):** Spans vertically. Contains code blocks with light gray backgrounds and syntax highlighting.
- **AHA MOMENTS (Top Right):** Side panel, single column list with icons.
- **Section 4 (Left below Sec 1):** Two sub-blocks with icons on the left and text on the right.
- **COMMON MISTAKES (Right below AHA):** Side panel, single column list with icons.
- **Section 5 (Middle Left):** Table on the left and a diagram of trees/graphs on the right.
- **Section 6 (Middle Right):** Large table spanning multiple columns. Includes a TIP block below.
- **Section 7 (Bottom Left):** Split into two columns: a checklist on the left and a flowchart on the right.
- **Section 8 (Bottom Right):** Table on the left and text blocks on the right.
- **Section 9 (Bottom Left, below Sec 7):** Table with multiple columns.
- **Section 10 (Bottom Right, below Sec 8):** Two-column list with icons.
- **Section 11 (Bottom Left, below Sec 9):** Horizontal flowchart with icons and arrows.
- **Section 12 (Bottom Right, below Sec 10):** Contains a row of icons with labels below them, inside a bordered box.

## Color Palette
- **Primary:** Dark Blue (used for main titles, section headers, page number tags).
- **Secondary:** Light Blue/Teal (used for some borders or specific icons).
- **Backgrounds:** White for main content, Light Gray for code blocks and table headers.
- **Accents:** Red/Maroon for error/mistake icons (crosses), Green for success icons (checkmarks).

## Typography and Alignment
- **Headers:** Bold, all caps, white text on dark blue background.
- **Body Text:** Sans-serif, mostly left-aligned.
- **Code:** Monospaced font, left-aligned.
- **Tables:** Centered or left-aligned depending on the column. Headings are bold.

## Visual Elements
- **Icons:** Used extensively in lists (lightbulbs, checkmarks, crosses, gears).
- **Diagrams:** Tree structures with circular nodes and arrows in Section 5.
- **Flowcharts:** Rectangular boxes with arrows connecting them in Sections 7 and 11.
- **Dividers:** Thin gray lines separating table rows and sections.
