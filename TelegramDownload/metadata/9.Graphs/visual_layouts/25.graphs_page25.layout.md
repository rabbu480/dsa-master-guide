# Visual Layout Specification: Graph Algorithm Cheat Sheet

## Overall Structure
The document is a cheat sheet structured into three main sections: a Header, a 2-column Main Grid containing 6 individual algorithm blocks, and a Footer section containing a quick recall guide.

## 1. Header Section
- **Page Indicator (Left):** A dark blue block containing white text indicating the page number.
- **Main Title (Center):** Prominent dark blue text with an accompanying open book icon. Below the main title is a subtitle specifying the content themes.
- **Badge (Right):** A light green rectangular badge with a border containing text.

## 2. Main Grid Layout
The core content is organized in a 2-column, 3-row grid. Each cell in this grid represents a distinct algorithm block.
- **Row 1:** Block 1 (Left), Block 2 (Right)
- **Row 2:** Block 3 (Left), Block 4 (Right)
- **Row 3:** Block 5 (Left), Block 6 (Right)

## 3. Algorithm Block Structure
Each of the 6 algorithm blocks follows a strict internal template:

### 3.1 Block Header
- A colored rectangular banner spanning the full width of the block.
- Left-aligned number enclosed in a white square (or colored square with white text).
- White text for the algorithm name and a brief description.
- **Color Coding by Block:**
  - Block 1 (DFS): Dark Blue
  - Block 2 (BFS): Teal / Dark Green
  - Block 3 (Topological Sort): Purple
  - Block 4 (Dijkstra): Orange
  - Block 5 (Union Find): Crimson / Red
  - Block 6 (Grid DFS/BFS): Blue

### 3.2 Block Body (2-Column Split)
Immediately below the block header, the space is divided into a roughly 30/70 split:
- **Left Column (PROCESS/STEPS):** Contains a step-by-step numbered list. The numbers are stylized inside colored circles or squares matching the block's header color.
- **Right Column (JAVA TEMPLATE):** Contains a code block. The code is formatted in a monospaced font with syntax highlighting and is enclosed within a subtle border.

### 3.3 Block Footer (4-Column Attributes Grid)
At the bottom of each algorithm block is a 4-column grid detailing specific attributes. Each column has a header with an icon and colored text, followed by bullet points or text:
- **Column 1:** AHA (Lightbulb Icon)
- **Column 2:** USE WHEN (Target/Crosshair Icon)
- **Column 3:** WATCH OUT (Warning Triangle Icon)
- **Column 4:** COMPLEXITY (Clock/Timer Icon)

## 4. Footer Section
- **Legend:** A single line of text providing definitions for variables (V, E, alpha) positioned above the quick recall guide.
- **Quick Recall Banner:** A full-width dark blue banner with white text titled "QUICK RECALL - ALGORITHM SELECTION GUIDE".
- **Selection Guide Grid:** Below the banner is a row divided into multiple columns, showing mappings from problem types to specific algorithms with arrows.
- **Golden Rule Box (Right):** A distinct yellow/gold highlighted rectangular box on the far right containing a trophy icon and the text "GOLDEN RULE" with accompanying advice.
