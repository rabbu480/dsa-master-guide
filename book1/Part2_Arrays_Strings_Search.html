2.1B Prefix Sum Pattern

Mental Model: Precompute running totals so range sum [L..R] can be answered in O(1) time via prefix[R+1] - prefix[L].

public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1); // Seed base case: sum 0 occurs once
    int sum = 0, count = 0;
    
    for (int num : nums) {
        sum += num;
        if (map.containsKey(sum - k)) {
            count += map.get(sum - k);
        }
        map.put(sum, map.getOrDefault(sum, 0) + 1);
    }
    return count;
}
💡 AHA MOMENT: When array contains negative numbers, Sliding Window fails! Use Prefix Sum + HashMap instead.

Part 2: Section 2.2
2.2C KMP Pattern Matching O(N + M)

Mental Model: Never re-examine characters that have already been matched. Build LPS[] (Longest Prefix Suffix) array to skip redundant comparisons.

public int strStr(String haystack, String needle) {
    if (needle.isEmpty()) return 0;
    int[] lps = buildLPS(needle);
    int i = 0, j = 0;
    
    while (i < haystack.length()) {
        if (haystack.charAt(i) == needle.charAt(j)) {
            i++; j++;
        }
        if (j == needle.length()) return i - j; // Found match!
        else if (i < haystack.length() && haystack.charAt(i) != needle.charAt(j)) {
            if (j != 0) j = lps[j - 1];
            else i++;
        }
    }
    return -1;
}

Two Pointers Core Template (Refer to A.11)
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxWater = 0;
    
    while (left < right) {
        int w = right - left;
        int h = Math.min(height[left], height[right]);
        maxWater = Math.max(maxWater, w * h);
        
        // Greedily move the pointer pointing to the shorter line
        if (height[left] < height[right]) left++;
        else right--;
    }
    return maxWater;
}

Part 2: Section 2.5
Variable Window Template (Refer to A.12)
public int minWindow(String s, String t) {
    int[] target = new int[128];
    for (char c : t.toCharArray()) target[c]++;
    
    int left = 0, count = t.length(), minLen = Integer.MAX_VALUE, start = 0;
    for (int right = 0; right < s.length(); right++) {
        if (target[s.charAt(right)]-- > 0) count--;
        
        while (count == 0) { // Valid window -> shrink
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }
            if (++target[s.charAt(left++)] > 0) count++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}

public int minEatingSpeed(int[] piles, int h) {
    int lo = 1, hi = 1_000_000_000, ans = hi;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (canEatAll(piles, h, mid)) {
            ans = mid;
            hi = mid - 1; // Try smaller speed
        } else {
            lo = mid + 1; // Speed too slow
        }
    }
    return ans;
}
