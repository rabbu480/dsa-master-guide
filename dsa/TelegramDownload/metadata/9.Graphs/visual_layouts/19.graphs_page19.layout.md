# Visual Layout Specification

## Overall Page Structure
- **Orientation**: Portrait
- **Grid System**: 3-column primary grid structure, with top-level sections spanning multiple columns.
- **Color Palette**: 
  - Dark blue backgrounds for primary headers and section titles.
  - Light blue, green, orange, pink, purple, and teal for template badges (A-F).
  - White background for code blocks and content areas.

## 1. Header Section
- **Top Bar**:
  - Left-aligned badge: "PAGE 13" (White text on dark blue rounded rectangle).
  - Center-aligned title: "GRAPH PATTERN GUIDE" (Dark blue uppercase, accompanied by a book icon).
- **Sub-header**:
  - Center-aligned text: "PAGE 13 — DIJKSTRA PROBLEM GUIDE (APPLY TEMPLATES)".
  - Center-aligned italicized quote below: *"Same algorithm. Different problems. Only the changing parts."*

## 2. Top Reference Section (Row 1)
- **Layout**: 2 columns (approx 1:2 ratio).
- **Left Column ("HOW TO USE THIS PAGE")**:
  - Dark blue header bar.
  - Numbered list (1-6) of instructions.
  - Target/dart graphic icon aligned to the right.
- **Right Column ("TEMPLATE LEGEND (From Page 12)")**:
  - Dark blue header bar.
  - 2-row by 3-column subgrid of template items.
  - Each item consists of a colored square badge (A through F) paired with a problem name.
  - **Badge Colors**: A (Blue), B (Green), C (Purple), D (Orange), E (Pink), F (Teal).

## 3. Main Content Cards (Rows 2 & 3)
- **Layout**: 3 columns, 2 rows of identical card structures.
- **Cards (1-6)**:
  - **Card Header**: Dark blue banner containing a number on the left, the problem title in the center, and a colored letter badge (matching the legend) on the right.
  - **Body Content**:
    - "Base Template" text (blue text).
    - "Problem" description paragraph.
    - "Changed Lines (from Template)" section, containing a monospaced code snippet block.
  - **Summary Table**:
    - A 3-column borderless layout within the card: "Caller", "Return", "Key Idea".
  - **AHA Moment**:
    - Lightbulb icon followed by bold text "AHA:" and a summarizing sentence.
  - **Footer Section**:
    - Split into two columns: "Complexity" (Time/Space) and "Interview Tip".

## 4. Summary & Guides (Row 4)
- **Layout**: 3 columns (Blocks 7, 8, 9).
- **Block 7 ("CHANGED LINES SUMMARY")**:
  - Dark blue header.
  - Contains a 4-column table (#, Problem, Template, Main Changes) with letter badges.
- **Block 8 ("Dijkstra Template Recap (From Page 12)")**:
  - Dark green header.
  - Contains a numbered list defining the core algorithm steps and logic.
- **Block 9 ("RETURN TYPE GUIDE")**:
  - Dark purple header.
  - Contains a 3-column table (Return Type, Use When, Example Problems) outlining when to use which return type.

## 5. Checklists & Flowcharts (Row 5)
- **Layout**: 3 columns (Blocks 10, 11, 12).
- **Block 10 ("INTERVIEW CHECKLIST")**:
  - Dark blue header.
  - Checklist of 6 items with green checkmarks.
  - Right-aligned "Interview Tip" callout box with a star icon.
- **Block 11 ("INTERVIEW THINKING FLOW")**:
  - Dark blue header.
  - Contains a multi-node flowchart diagram with decision points (YES/NO paths) for choosing the right approach (e.g., Dijkstra vs Bellman-Ford).
- **Block 12 ("PAGE 14 PREVIEW")**:
  - Dark blue header.
  - Preview text and a horizontal arrangement of small illustrative icons indicating the next page's features.

## 6. Footer Process Flow
- **Layout**: Full-width footer strip spanning the bottom of the page.
- **Content**:
  - A linear sequence of steps connected by horizontal arrows.
  - **Sequence**: Problem (?) -> Input (list icon) -> Representation (grid icon) -> Choose Pattern (tree icon) -> Helper Structure (blocks icon) -> Apply Changes (pencil icon) -> Dry Run (play icon) -> Optimize (clock/space icon).
  - Each step is accompanied by an icon and descriptive text below it.
