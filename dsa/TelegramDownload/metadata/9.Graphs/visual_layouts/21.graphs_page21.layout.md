# Visual Layout Specification: Graph Pattern Guide (Page 17)

## 1. Overall Page Structure
- **Theme**: Dark blue primary accent color, with multi-colored functional highlights for categories.
- **Background**: White.
- **Grid System**: The page uses a flexible multi-column grid that shifts between 1, 2, 3, and 4 columns depending on the section, separated by horizontal white space.

## 2. Header Section
- **Top Left Badge**: Solid dark blue rectangle with white text indicating the page number.
- **Main Title**: Centered, large bold dark blue typography.
- **Subtitle**: Centered, slightly smaller blue text, flanked by horizontal lines extending outward.
- **Quote**: Centered italic text positioned just beneath the subtitle.

## 3. Row 1: Instructions & Roadmap
- **Layout**: Two-column split (approx. 25% left / 75% right).
- **Left Column ("How to Use This Page")**:
  - Dark blue header bar with white text, left-aligned.
  - Numbered list utilizing circled numbers.
  - Target/bullseye icon illustration positioned at the bottom right of the text block.
- **Right Column ("Graph Pattern Roadmap")**:
  - Dark blue header bar spanning the full width of the column.
  - **Internal Grid**: 6 equal-width vertical sub-columns for the roadmap steps.
  - Each step features a colored square containing a white number, followed by a bold title, and a bulleted list below.
  - **Step Colors**: 1 (Teal), 2 (Green), 3 (Orange), 4 (Purple), 5 (Red), 6 (Blue).
  - Centered instructional text/tip at the bottom.

## 4. Row 2: Pattern Summary Table
- **Layout**: Full width (100%).
- **Header**: Dark blue spanning header bar.
- **Table Structure**: 6 vertical columns.
- **Table Styling**:
  - Column headers have a light blue/gray background.
  - Row labels in Column 1 are preceded by a colored square badge containing the row number (1-12) with white text.
  - Light gray grid lines separate rows and columns.
  - Text is left-aligned in the first few columns and center-aligned in the complexity columns.

## 5. Row 3: Practice & Revision Plans
- **Layout**: Three-column split (approx. 50% / 25% / 25%).
- **Left Column ("Spaced Practice Plan")**:
  - Dark blue header bar.
  - 5-column table format with rows divided by weeks.
  - Light yellow tip box at the bottom featuring a lightbulb icon.
- **Middle Column ("Revision Schedule")**:
  - Dark blue header bar.
  - Two-column vertical list layout aligning days and corresponding actions.
  - Dates use colored circular bullets (teal, red, blue, purple).
- **Right Column ("Error Log")**:
  - Dark blue header bar.
  - Bulleted list structure.
  - Clipboard icon illustration floated to the right.
  - Blockquote styling with blue text at the bottom.

## 6. Row 4: Interview Strategies
- **Layout**: Three-column split (approx. 50% / 25% / 25%).
- **Left Column ("Interview Strategy Roadmap")**:
  - Dark blue header bar.
  - Horizontal flowchart consisting of 5 steps.
  - Each step contains a circular outlined icon, a bold label, and a short bulleted list.
  - Steps are visually connected by right-pointing arrows.
- **Middle Column ("Key Mindset Reminders")**:
  - Dark blue header bar.
  - Vertical checklist with blue square checkmark icons.
  - Horizontal linear text flow at the bottom connected by arrows.
- **Right Column ("Complexity Reminders")**:
  - Dark blue header bar.
  - Two-column data list aligning algorithm names (bolded) on the left with their time/space complexities on the right.
  - Light yellow tip box at the bottom with a lightbulb icon.

## 7. Row 5: Quick Tips & Pitfalls
- **Layout**: Four equal-width columns (25% each).
- **Styling**: All columns share the standard dark blue header bar style.
- **Column 1 ("Common Pitfalls")**: Uses red "X" icons in circles for the list. A light yellow warning box (triangle icon) sits at the bottom.
- **Column 2 ("Quick Check Before Submit")**: Uses blue checkmark boxes for the list. A light gray tip box (stopwatch icon) sits at the bottom.
- **Column 3 ("Interview Tips")**: Uses blue star icons for the list. A light gray note box (chat bubble icon) sits at the bottom.
- **Column 4 ("Next Page Preview")**: Text description followed by a blue rising bar chart and arrow icon illustration on the bottom right.

## 8. Bottom Section: The Success Formula
- **Layout**: Full width (100%).
- **Title**: Centered, bold blue text.
- **Flowchart Diagram**:
  - 10 distinct steps flowing horizontally from left to right.
  - Each step consists of a circular dark blue line-art icon.
  - Two lines of text labels below each icon: a bold main label and a parenthetical sub-label.
  - Elements are connected by simple right-pointing arrows.
- **Footer Text**: Centered, green text with a subtle highlight spanning the bottom of the page.

## 9. Typography, Colors, and Alignment
- **Headings**: Sans-serif, bold, uppercase, white text on dark blue backgrounds.
- **Body Text**: Sans-serif, legible font size, left-aligned in most lists and tables, center-aligned in flowchart diagrams.
- **Alignment**: Strict adherence to column bounding boxes with generous white space padding separating the vertical rows and horizontal columns.
