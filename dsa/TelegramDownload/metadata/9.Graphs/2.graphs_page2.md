# GRAPH PATTERN GUIDE
**PAGE 3 - GRAPH HELPER STRUCTURES & INTERVIEW TOOLKIT**
*"Before choosing an algorithm, choose the helper structures that power it."*

## 1 PLAIN ENGLISH
* Almost every graph problem uses helper structures.
* Choosing the right helper structure is often more important than choosing the algorithm.
* Build first. Choose helper structures. Then solve.

## 2 THE GRAPH TOOLBOX (Helper Structures You'll Use in Almost Every Problem)

| Structure | Purpose (One-line) | Used In (Typical Problems) | Java Type | Initialization (Example) | Validation / What to Check |
| --- | --- | --- | --- | --- | --- |
| ⭐ `visited[]` | Track visited nodes | DFS, BFS, Cycle Detect, Components | `boolean[]` | `boolean[] visited = new boolean[n];` | Print visited nodes (true indices) |
| ⭐ `dist[]` | Store shortest distance from source | Shortest Path, Dijkstra, Multi-Source BFS | `int[]` | `int[] dist = new int[n]; Arrays.fill(dist, INF);` | Print distances (`Arrays.toString`) |
| `parent[]` | Store parent / predecessor of each node | Path Reconstruction, Union Find, Trees | `int[]` | `int[] parent = new int[n]; for (int i=0;i<n;i++) parent[i] = i;` | Print parent array |
| `rank[]` | Rank / size for Union Find (Optimized Merge) | Union Find (Disjoint Set) | `int[]` | `int[] rank = new int[n]; (default 0)` | Print rank array |
| `indegree[]` | Count incoming edges | Topological Sort (Kahn's Algo) | `int[]` | `int[] indegree = new int[n];` | Print indegree array |
| `dirs[][]` | Directions for grid movement | Grid DFS/BFS, Islands, Flood Fill | `int[][]` | `int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};` | Print dirs to verify movement |
| ⭐ `Queue` | Process nodes in FIFO order | BFS, Level Order, Kahn's Algo | `Queue<Integer>` | `Queue<Integer> q = new LinkedList<>();` | Print queue content |
| ⭐ `PriorityQueue` | Process best candidate first | Dijkstra, Prim's, Minimum Effort | `PriorityQueue<int[]>` | `PriorityQueue<int[]> pq = new PriorityQueue<>();` | Print pq content |
| `HashMap` | Mapping / Lookup (Visited, Clone, etc.) | Clone Graph, Store Mappings, Count | `HashMap<K,V>` | `HashMap<K,V> map = new HashMap<>();` | Print map entries |
| ⭐ `List<List<Integer>>` | Adjacency List for Unweighted Graph | Most Graph Problems (95%) | `List<List<Integer>>` | `List<List<Integer>> g = new ArrayList<>();` | Print neighbors for each node |
| `List<List<int[]>>` | Adjacency List for Weighted Graph | Weighted Graphs, Dijkstra, MST | `List<List<int[]>>` | `List<List<int[]>> g = new ArrayList<>();` | Print (neighbor,weight) for each node |

**⭐ Most Frequently Used in Interviews | Adjacency List + visited[] + Queue + PriorityQueue = Your Core Toolkit**

## 3 WHEN DO I NEED WHAT?
* Need to avoid revisiting nodes? → `visited[]`
* Need shortest distance? → `dist[]`
* Need smallest distance first? → `PriorityQueue`
* Need BFS (level by level)? → `Queue`
* Need to merge / union groups? → `parent[]`, `rank[]`
* Need dependency count? → `indegree[]`
* Need grid movement? → `dirs[][]`
* Need clone / mapping / lookup? → `HashMap`

## 4 INITIALIZATION CHEAT SHEET

| Structure | Java Initialization |
| --- | --- |
| `visited[]` | `boolean[] visited = new boolean[n];` |
| `dist[]` | `int[] dist = new int[n]; Arrays.fill(dist, INF);` |
| `parent[]` | `int[] parent = new int[n]; for (int i = 0; i < n; i++) parent[i] = i;` |
| `rank[]` | `int[] rank = new int[n]; // default 0` |
| `indegree[]` | `int[] indegree = new int[n];` |
| `Queue` | `Queue<Integer> q = new LinkedList<>();` |
| `PriorityQueue` | `PriorityQueue<int[]> pq = new PriorityQueue<>();` |
| `HashMap` | `HashMap<K, V> map = new HashMap<>();` |
| `dirs[][]` | `int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};` |

## 5 PRINT & VALIDATE (Always Do This!)

| Structure | How to Print | Expected Output |
| --- | --- | --- |
| `visited[]` | `Arrays.toString(visited)` | `[true, false, true, ...]` |
| `dist[]` | `Arrays.toString(dist)` | `[0, 2, 5, INF, ...]` |
| `parent[]` | `Arrays.toString(parent)` | `[0, 0, 1, 2, ...]` |
| `rank[]` | `Arrays.toString(rank)` | `[0, 1, 0, 1, ...]` |
| `indegree[]` | `Arrays.toString(indegree)` | `[0, 1, 2, 0, ...]` |
| Adjacency List | `for (i) print i -> neighbors` | `0 -> [1,2]`<br>`1 -> [0,2,3]` |
| Weighted Graph | `for (i) print i -> (nbr,w)` | `0 -> (1,4) (2,7)`<br>`1 -> (0,4) ...` |
| `PriorityQueue` | `System.out.println(pq)` | `[(2,5), (1,8), ...]` |
| `Queue` | `System.out.println(q)` | `[1, 2, 3, ...]` |
| `HashMap` | `System.out.println(map)` | `{key1=val1, ...}` |

⚠️ **Never debug DFS/BFS until helper structures look correct.**

## 6 VISUAL MEMORY MAP (How Everything Connects)

Problem -> Input -> Representation -> **Helper Structure** (Choose What You Need) -> Pattern (DFS / BFS / etc.) -> Tiny Logic Change (Per Problem)

**Helper Structures:**
`visited[]`, `dist[]`, `parent[]`, `rank[]`, `indegree[]`, `Queue`, `PriorityQueue`, `dirs[][]`, `HashMap`

## 7 AHA MOMENTS
* Algorithms usually share helper structures.
* Most DFS problems differ only by return type.
* Most BFS problems differ only by queue logic.
* Grid problems always reuse dirs[].
* Weighted graphs almost always need dist[].
* PriorityQueue usually means "best candidate first".
* Union Find is impossible without parent[].
* Topological Sort begins with indegree[].

## 8 COMMON INTERVIEW MISTAKES
- [ ] Forgot visited[].
- [ ] Forgot Arrays.fill(dist, INF).
- [ ] Mixed node and distance in structures.
- [ ] Forgot parent[i] = i.
- [ ] Forgot reverse edge in undirected graph.
- [ ] Used Queue instead of PriorityQueue.
- [ ] Forgot dirs[].
- [ ] Didn't print structures while debugging.
