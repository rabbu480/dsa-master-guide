# Visual Layout Specification: Heap Patterns

## Overall Structure
- **Document Type**: Cheat sheet / reference guide.
- **Orientation**: Portrait.
- **Grid System**: Multi-section layout with a primary 5-column grid for the main content areas.
- **Visual Theme**: Technical, structured, block-based with a color palette consisting primarily of dark blue, light blue, light purple, light green, and white.

## Sections

### 1. Header
- **Layout**: Full-width container spanning the top.
- **Elements**: 
  - Main title on the left.
  - Subtitle on the left below the main title.
  - Page number badge aligned to the far right with a dark blue background and white text.

### 2. Legend / Key Box
- **Layout**: Full-width container, centrally aligned content.
- **Visuals**: Enclosed within a thin, rounded rectangular border (dark blue). Elements are separated by horizontal spacing and arrow symbols.

### 3. Main Content Blocks (Pattern 1 to Pattern 4)
The core of the document consists of four stacked horizontal blocks, each detailing a specific pattern. Each block is structured with a header and a 5-column data grid.

#### Pattern Header
- **Layout**: Full width horizontal bar.
- **Visuals**: 
  - Left side: A dark blue tag with white text indicating the pattern number.
  - Right side: A very light blue/white bar with dark blue text indicating the pattern title and an example in parentheses.

#### Pattern Data Grid (Columns)
Each pattern block has a 5-column layout beneath the header. The columns are separated by thin vertical lines.

- **Column 1 (When to Use?)**
  - Header text centered in green.
  - Left-aligned bulleted list.

- **Column 2 (Heap to Use)**
  - Header text centered in red.
  - Contains visual diagrams, specifically tree graph representations of heaps with circular nodes connected by lines.
  - Some patterns include multiple tree diagrams or linked list representations.

- **Column 3 (Idea / AHA)**
  - Header text centered in purple.
  - Contains a centered purple lightbulb icon.
  - Text enclosed in a light purple rectangular box with rounded corners.

- **Column 4 (Template (Java))**
  - Header text centered in blue.
  - Contains a code block with monospaced font and syntax highlighting (green for comments, blue/purple for keywords, black for standard text).

- **Column 5 (Complexity & Examples)**
  - Divided vertically into two sub-sections.
  - Top sub-section: "Complexity" header in green, followed by a bulleted list.
  - Bottom sub-section: "Examples" header within a light green rectangular box with rounded corners, followed by a bulleted list.

### 4. Footer
- **Layout**: Divided into two main columns taking up the bottom section of the page.
- **Elements**:
  - **Left Column (AHA Summary)**: Uses a star icon for the title. Bullet points use green square checkmark icons.
  - **Right Column (Pattern Recognition Triggers)**: Uses a red icon for the title. Bullet point consists of inline text separated by slashes.
- **Visuals**: Separated from the main content by a thin horizontal line.
