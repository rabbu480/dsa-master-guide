# Visual Layout Specification: Arrays & Hashing Cheat Sheet

## Overall Structure
- **Orientation**: Portrait
- **Theme**: Dark header, white background body, highly segmented grid using colorful headers to delineate sections.
- **Grid System**: The main body relies on a 3-column layout, with occasional spanning across the full width.

## Sections Breakdown

### 1. Header Banner
- **Span**: Full width at the top.
- **Background Color**: Dark Blue (`#1e293b` approx).
- **Layout**: 
  - Main title in large, bold, white, and yellow uppercase text.
  - Subtitle badge on the right (rounded rectangle, light blue background with white text).
  - A sub-header row containing three items distributed horizontally, each with a small icon (Star, Target, Lightning bolt) and text.

### 2. Main Content Grid - Row 1 (3 Columns)
- **Column 1 (Left)**
  - **Header Color**: Green
  - **Visual Representation**: Vertical sequential list (Steps 1 to 7).
  - **Styling**: Each step features a circular numbered icon, bold title, descriptive text, and a vertical downward arrow connecting to the next step.
- **Column 2 (Middle)**
  - **Header Color**: Blue
  - **Visual Representation**: 3-column data table.
  - **Styling**: Rows are separated by light gray borders. The first column contains small illustrative icons next to the text.
- **Column 3 (Right)**
  - **Header Color**: Orange
  - **Visual Representation**: 4-column data table.
  - **Styling**: Standard grid-lined table rows.

### 3. Main Content Grid - Row 2 (Full Width Span)
- **Span**: Full width (spans across all 3 columns).
- **Header Color**: Purple
- **Visual Representation**: Container split internally into 5 equal-width vertical columns separated by thin vertical lines.
- **Styling**: 
  - Each internal column has a light purple sub-header.
  - Content includes formatted code blocks, numbered lists, and text.
  - Some columns contain a highlighted tip at the bottom, marked by a yellow lightbulb icon.

### 4. Main Content Grid - Row 3 (3 Columns)
- **Column 1 (Left)**
  - **Header Color**: Green
  - **Visual Representation**: 2-column data table (key-value pairs).
  - **Styling**: Zebra-striped rows or simple bordered rows.
- **Column 2 (Middle)**
  - **Header Color**: Teal
  - **Visual Representation**: 4-column list/table.
  - **Styling**: Each column has a bold title with a list of methods beneath it.
- **Column 3 (Right)**
  - **Header Color**: Orange
  - **Visual Representation**: 2-column mapping list.
  - **Styling**: Uses horizontal arrows (`→`) to indicate relationships between left and right column items.

### 5. Main Content Grid - Row 4 (3 Columns)
- **Column 1 (Left)**
  - **Header Color**: Blue
  - **Visual Representation**: Split-pane explanatory block.
  - **Styling**: Text divided into left (Sequential) and right (Nested) examples, followed by a summary equation at the bottom.
- **Column 2 (Middle)**
  - **Header Color**: Red
  - **Visual Representation**: Unordered bulleted list.
  - **Styling**: Uses red circled 'X' icons for each bullet point.
- **Column 3 (Right)**
  - **Header Color**: Purple
  - **Visual Representation**: Unordered bulleted list followed by a summary callout.
  - **Styling**: Uses green circled checkmark icons for each bullet point. The bottom contains a centered "Golden Line" text block.

### 6. Footer Banner
- **Span**: Full width at the bottom.
- **Background Color**: Light Yellow / Gold (`#fef08a` approx).
- **Layout**: Horizontal flex container.
  - Left side: "MEMORY MANTRAS" text with a star icon.
  - Middle: Five pairs of vertically stacked text items (Question on top, Answer in green on bottom).
  - Right side: A golden trophy icon followed by concluding motivational text.
