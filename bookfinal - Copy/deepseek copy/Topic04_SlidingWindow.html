💡 WHY SLIDING WINDOW?

Computing subarray sums or frequencies naively takes O(N²) or O(N³) time. Sliding Window re-uses computation from overlapping adjacent windows to achieve O(N) time.

💡 THE AHA MOMENT
When moving from window `[left..right]` to `[left+1..right+1]`, do NOT recompute from scratch! Subtract `nums[left]` and add `nums[right+1]` in O(1)!
1 3 CORE VARIANTS
  • Fixed Window Size K: Window size K is fixed. Expand `right`, contract `left` when `right - left + 1 > K`.
  • Dynamic Window Longest: Expand `right` to include elements. Shrink `left` ONLY when constraint is violated.
  • Dynamic Window Shortest: Expand `right` until constraint is satisfied. Shrink `left` greedily to minimize size.
2 VISUALIZING WINDOW SLIDING
Fixed Window K=3:
Window 1: [ 2,  1,  5 ], 1,  3,  2   Sum = 8
              Subtract 2, Add 1 ➔
Window 2:   2, [ 1,  5,  1 ], 3,  2   Sum = 7
              Subtract 1, Add 3 ➔
Window 3:   2,  1, [ 5,  1,  3 ], 2   Sum = 9 (Max!)

⚡ CLUES THAT SCREAM SLIDING WINDOW

1. "Contiguous subarray / substring" + "Max / Min / Target"

2. "Longest substring with at most K distinct"

3. "Find all anagrams in string" → Fixed Window Frequency Match

4. "Subarrays with exactly K distinct" → `atMost(K) - atMost(K-1)`

🔧 FAST FREQUENCY ARRAY
// Fast ASCII Frequency Tracker (Replaces HashMap!)
int[] freq = new int[128]; // Fits all ASCII characters

// Add character at right pointer
freq[s.charAt(right)]++;

// Remove character at left pointer
freq[s.charAt(left)]--;
💡 Avoids HashMap auto-boxing overhead. Executes 5x faster in FAANG benchmarks!
🔧 AT MOST K → EXACTLY K TRICK
// Mathematical Identity:
// exactly(K) = atMost(K) - atMost(K - 1)

public int numSubarraysWithK(int[] nums, int k) {
    return atMost(nums, k) - atMost(nums, k - 1);
}
💡 Converts complex "Exactly K" into two simple "At Most K" passes!

⚡ 5-STEP SLIDING WINDOW THINKING FRAMEWORK
  1. Is the window size fixed or dynamic? Fixed → simple add/remove. Dynamic → expand right, shrink left conditionally.
  2. What's the window condition? Sum threshold? Distinct chars? Frequency match?
  3. When to shrink left? Fixed: when `right - left + 1 > K`. Dynamic: when condition is violated (longest) or while condition holds (shortest).
  4. How to track state? Frequency array for strings. HashMap for generic.
  5. What's the answer? Max length? Min length? Count of valid windows?

PATTERN 1 — FIXED WINDOW SIZE K LC 643 · EASY
When to Use: Subarray length K is fixed in problem description.
Input: [1,12,-5,-6,50,3], k=4
Output: 12.75
💡 AHA
Build first window of size K, then slide: subtract `nums[i-K]`, add `nums[i]`. 
public double findMaxAverage(int[] nums, int k) {
    // Build first window
    double sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    double max = sum;

    // Slide window: add right, remove left
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        max = Math.max(max, sum);
    }

    return max / k;
}
PATTERN 2 — DYNAMIC LONGEST LC 3 · MEDIUM
When to Use: Find maximum length subarray/substring satisfying a condition.
Input: "abcabcbb"
Output: 3 ("abc")
💡 AHA
Expand right, shrink left ONLY when condition is violated (`freq[c] > 1`). This gives the longest valid window. 
public int lengthOfLongestSubstring(String s) {
    int[] freq = new int[128]; // ASCII frequency
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        freq[c]++;

        // Shrink until valid (all characters unique)
        while (freq[c] > 1) {
            freq[s.charAt(left)]--;
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
PATTERN 3 — CHARACTER REPLACEMENT LC 424 · MEDIUM
When to Use: Longest substring where at most K characters can be replaced.
Input: s="AABABBA", k=1
Output: 4
💡 AHA
Valid window if `(windowLength - maxFreq) <= K`. If invalid, shrink left by 1. 
public int characterReplacement(String s, int k) {
    int[] freq = new int[26];
    int left = 0, maxCount = 0, maxLen = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        maxCount = Math.max(maxCount, ++freq[c - 'A']);

        // If window invalid, shrink left
        if (right - left + 1 - maxCount > k) {
            freq[s.charAt(left) - 'A']--;
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

PATTERN 4 — FIXED FREQUENCY MATCH LC 567 · MEDIUM
When to Use: Finding subsegment that is an anagram/permutation of target.
Input: s1="ab", s2="eidbaooo"
Output: true
💡 AHA
Window length is fixed at `s1.length()`. Slide and compare frequency arrays. 
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;

    int[] target = new int[26];
    int[] window = new int[26];

    // Build initial window
    for (int i = 0; i < s1.length(); i++) {
        target[s1.charAt(i) - 'a']++;
        window[s2.charAt(i) - 'a']++;
    }

    if (Arrays.equals(target, window)) return true;

    // Slide window
    for (int i = s1.length(); i < s2.length(); i++) {
        window[s2.charAt(i) - 'a']++;
        window[s2.charAt(i - s1.length()) - 'a']--;
        if (Arrays.equals(target, window)) return true;
    }
    return false;
}

When to Use: Max length with at most K distinct elements.
Input: [1,2,1]
Output: 3
💡 AHA
This is just "at most 2 distinct" — shrink left while `map.size() > 2`. 
public int totalFruit(int[] fruits) {
    Map<Integer, Integer> count = new HashMap<>();
    int left = 0, maxLen = 0;

    for (int right = 0; right < fruits.length; right++) {
        count.put(fruits[right], count.getOrDefault(fruits[right], 0) + 1);

        while (count.size() > 2) {
            count.put(fruits[left], count.get(fruits[left]) - 1);
            if (count.get(fruits[left]) == 0) count.remove(fruits[left]);
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (s.length() < p.length()) return res;

    int[] target = new int[26];
    int[] window = new int[26];

    for (int i = 0; i < p.length(); i++) {
        target[p.charAt(i) - 'a']++;
        window[s.charAt(i) - 'a']++;
    }

    if (Arrays.equals(target, window)) res.add(0);

    for (int i = p.length(); i < s.length(); i++) {
        window[s.charAt(i) - 'a']++;
        window[s.charAt(i - p.length()) - 'a']--;
        if (Arrays.equals(target, window)) res.add(i - p.length() + 1);
    }
    return res;
}

PATTERN 7 — DYNAMIC SHORTEST LC 76 · HARD
When to Use: Find the shortest substring containing all target characters.
Input: s="ADOBECODEBANC", t="ABC"
Output: "BANC"
💡 AHA
Expand until all chars found. Then shrink left greedily while still valid to minimize length! 
public String minWindow(String s, String t) {
    int[] count = new int[128];
    for (char c : t.toCharArray()) count[c]++;

    int left = 0, minLen = Integer.MAX_VALUE, start = 0;
    int matched = t.length(); // Total chars needed

    for (int right = 0; right < s.length(); right++) {
        // Expand right: if char needed, decrement matched
        if (count[s.charAt(right)]-- > 0) matched--;

        // Window valid: shrink left greedily
        while (matched == 0) {
            if (right - left + 1 < minLen) {
                minLen = right - left + 1;
                start = left;
            }

            // Remove left char
            if (++count[s.charAt(left)] > 0) matched++;
            left++;
        }
    }

    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
PATTERN 8 — EXACTLY K DISTINCT LC 992 · HARD
When to Use: Count subarrays with exactly K distinct elements.
Input: [1,2,1,2,3], k=2
Output: 7
💡 AHA
`exactly(K) = atMost(K) - atMost(K-1)`. AtMost is easier to compute! 
public int subarraysWithKDistinct(int[] nums, int k) {
    return atMost(nums, k) - atMost(nums, k - 1);
}

private int atMost(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    int left = 0, res = 0;

    for (int right = 0; right < nums.length; right++) {
        count.put(nums[right], count.getOrDefault(nums[right], 0) + 1);

        while (count.size() > k) {
            count.put(nums[left], count.get(nums[left]) - 1);
            if (count.get(nums[left]) == 0) count.remove(nums[left]);
            left++;
        }

        // All subarrays ending at right with at most k distinct
        res += right - left + 1;
    }
    return res;
}

⭐ LC 209 · Minimum Size Subarray Sum MEDIUM
Input: target=7, nums=[2,3,1,2,4,3]
Output: 2 ([4,3])
Pattern: Dynamic Shortest
💡 AHA
Expand right until sum >= target. Then shrink left while sum >= target to minimize length! 
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;

    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];

        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left];
            left++;
        }
    }

    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}

💼 GOLDEN RULES
Rule 1 — Expand Right, Shrink Left
Always expand `right` to include next element first. Shrink `left` ONLY when window condition breaks (longest) or while window remains valid (shortest).
Rule 2 — Use int[128] for ASCII Frequencies
For strings, use `int[128]` or `int[256]` instead of HashMap for faster performance.
Rule 3 — Exactly K = AtMost(K) - AtMost(K-1)
This mathematical identity converts a hard problem into two easy ones. Always consider this when asked for "exactly K".
