DFS
(Depth First Search)		 Explore all nodes, components, cycles, topo sort, paths Go deep first, then backtrack.
  1. Mark node visited
  2. Recur for all unvisited neighbors
  3. Backtrack
 
void dfs(int node, List<List<Integer>> g, boolean[] vis) {
  vis[node] = true;
  for (int nei : g.get(node)) {
    if (!vis[nei]) dfs(nei, g, vis);
  }
}
 O(V + E) O(V)
(Recursion Stack)
BFS
(Breadth First Search)		 Shortest path (unweighted), level order, nearest First visit = shortest path.
  1. Push start in queue, mark visited
  2. While queue not empty:
    • Pop front
    • Push unvisited neighbors
 
Queue<Integer> q = new LinkedList<>();
q.offer(start); vis[start] = true;
while (!q.isEmpty()) {
  int node = q.poll();
  for (int nei : g.get(node)) {
    if (!vis[nei]) { vis[nei] = true; q.offer(nei); }
  }
}
 O(V + E) O(V)
(Queue)
Topological Sort
(Kahn's BFS)		 DAG ordering, course schedule, dependencies Process node after all prerequisites are satisfied.
  1. Compute indegree of all nodes
  2. Push all nodes with indegree 0
  3. Pop, add to order, reduce indegree
  4. If processed < V ➔ cycle exists
 
Queue<Integer> q = new LinkedList<>();
int[] indeg = new int[n]; // compute indegree
for(int i=0; i<n; i++) if(indeg[i]==0) q.offer(i);
List<Integer> order = new ArrayList<>();
while(!q.isEmpty()) { 
  int node = q.poll(); order.add(node);
  for(int nei: g.get(node)) if(--indeg[nei]==0) q.offer(nei); 
}
 O(V + E) O(V)
Dijkstra
(Min Heap)		 Shortest path in weighted graph (positive weights) Relax edges. First time pop from heap = shortest distance.
  1. Init dist[] = INF, dist[src] = 0
  2. Push (0, src) in min-heap
  3. Pop min, skip if outdated
  4. Relax neighbors
  5. Repeat
 
PriorityQueue<int[]> pq = new ...((a,b)->a[0]-b[0]);
int[] dist = new int[n]; Arrays.fill(dist, INF); dist[src]=0;
pq.offer(new int[]{0, src});
while(!pq.isEmpty()) { 
  int[] cur = pq.poll(); int d = cur[0], node = cur[1];
  if(d > dist[node]) continue;
  for(int[] nei: g.get(node)) { 
    int w = nei[1], next = nei[0];
    if(dist[node] + w < dist[next]) { 
      dist[next] = dist[node] + w; pq.offer(new int[]{dist[next], next}); 
    } 
  } 
}
 O((V+E) log V) O(V+E)
Union Find
(DSU)		 Connectivity, merge components, dynamic graph Build groups instead of traversing.
  1. Make each node its own parent
  2. Find with path compression
  3. Union by rank/size
  4. Find to check connectivity
 
int find(int x){ if(parent[x]!=x) parent[x]=find(parent[x]); return parent[x]; }
void union(int x, int y){ 
  x=find(x); y=find(y); if(x==y) return;
  if(rank[x]<rank[y]) parent[x]=y; else if(rank[x]>rank[y]) parent[y]=x;
  else { parent[y]=x; rank[x]++; } 
}
 O(α(V))
per op		 O(V)

9 COMMON PITFALLS (DON'T LOSE MARKS!)
  • ❌ Not marking visited ➔ infinite loops
  • ❌ Wrong data structure (Stack vs Queue vs PQ)
  • ❌ Index out of bounds in grid problems
  • ❌ Forgetting to handle disconnected components
  • ❌ Ignoring edge direction
  • ❌ Topological sort on cyclic graph
  • ❌ Not checking if all nodes processed (cycle)
  • ❌ Dijkstra with negative weights
  • ❌ Union Find without path compression / rank
  • ❌ Modifying list while iterating
10 AHA MOMENTS (MEMORIZE THESE!)
💡 DFS ➔ Go deep, then backtrack.
💡 BFS ➔ First visit = shortest path (unweighted).
💡 Topo Sort ➔ Process only after all prerequisites done.
💡 Dijkstra ➔ Relax edges, pick next closest.
💡 DSU ➔ Build groups, don't traverse.
💡 Grid ➔ Direction + Bounds + Visit = Safe traversal.
💡 Disconnected ➔ Run algorithm from every unvisited node.
💡 Cycle in Topo ➔ If result size < V.
💡 Why PQ in Dijkstra? ➔ Always take min distance.
