DFS — Template & Why
PAGE 5/30
🌊 DFS RECURSIVE
// PSEUDO: Explore all nodes reachable from u
// Mark visited, then recurse on unvisited neighbors
void dfs(int u, List<Integer>[] adj, boolean[] vis) {
  vis[u] = true;                       // 1. mark visited
  for (int v : adj[u]) {               // 2. for each neighbor
    if (!vis[v]) {                     // 3. if not visited
      dfs(v, adj, vis);                // 4. recurse
    }
  }
}
✅ PURPOSE: Explore all nodes in a graph or grid. Used for connectivity, path existence, and component labeling.
🤔 WHY DFS? Simple, intuitive, and optimal when you need to visit every node in a component. Uses recursion (or explicit stack) and is the foundation for backtracking.
⚠️ WHY NOT BFS? Both work for connectivity. DFS uses less memory for deep graphs (O(H) vs O(W)). BFS is better for shortest path in unweighted graphs.
🚫 WHEN NOT TO USE DFS: When you need the shortest path in an unweighted graph (use BFS) or when recursion depth may overflow (use iterative DFS).
💡 AHA PROGRESSION
1. Visit node → mark visited
2. Count components → wrap in loop
3. Return size → area of component
4. Parent array → reconstruct path
5. Cycle (undirected) → parent check
6. Cycle (directed) → DFS colors
7. Topological sort → post-order
8. Tarjan SCC → disc, low, stack
🔍 DRY RUN — DFS on Tree (1→2, 1→3, 2→4)
StepCall StackVisitedAction
1dfs(1){1}Visit 1, neighbors: 2,3
2dfs(1)→dfs(2){1,2}Visit 2, neighbor: 4
3dfs(1)→dfs(2)→dfs(4){1,2,4}Visit 4, no neighbors → return
4dfs(1)→dfs(2){1,2,4}Back to 2, no more neighbors → return
5dfs(1){1,2,4}Back to 1, next neighbor: 3
6dfs(1)→dfs(3){1,2,4,3}Visit 3, no neighbors → return
7dfs(1){1,2,4,3}All done
🚨 DFS — COMMON MISTAKES
❌ Forgot visited✅ vis[u]=true at start
❌ Wrong base case✅ if (u==null) return
❌ Stack overflow✅ Use iterative DFS

BFS — Template & Why
PAGE 6/30
📦 BFS STANDARD
// PSEUDO: Process nodes level by level using a queue
// Mark visited when enqueuing to avoid duplicates
void bfs(int src, List<Integer>[] adj, boolean[] vis) {
  Queue<Integer> q = new LinkedList<>();
  q.offer(src);
  vis[src] = true;                     // 1. mark on enqueue
  while (!q.isEmpty()) {
    int u = q.poll();                  // 2. process current
    for (int v : adj[u]) {
      if (!vis[v]) {
        vis[v] = true;                 // 3. mark before enqueue
        q.offer(v);                      // 4. enqueue
      }
    }
  }
}
✅ PURPOSE: Process nodes level by level. Used for shortest path in unweighted graphs, level-order traversal, and multi-source propagation.
🤔 WHY BFS? Guarantees shortest path in unweighted graphs because the first visit is the shortest. Also handles multi-source efficiently.
⚠️ WHY NOT DFS? DFS does NOT guarantee shortest path — it may explore a long path first. BFS is optimal for unweighted shortest path.
🚫 WHEN NOT TO USE BFS: When the graph is weighted (use Dijkstra) or when you need to explore all possibilities (use DFS/backtracking).
💡 AHA PROGRESSION
1. Queue → process in FIFO order
2. Level order → freeze size per level
3. Shortest path (unweighted) → first visit is shortest
4. Multi-source BFS → enqueue all sources initially
5. 0‑1 BFS → deque with 0-front / 1-back
6. Bidirectional BFS → two frontiers meet
🔍 DRY RUN — BFS on Tree (1→2, 1→3, 2→4)
StepQueueVisitedAction
1[1]{1}Enqueue 1
2pop 1 → [2,3]{1,2,3}Process 1, enqueue 2,3
3pop 2 → [3,4]{1,2,3,4}Process 2, enqueue 4
4pop 3 → [4]{1,2,3,4}Process 3, no new
5pop 4 → []{1,2,3,4}Process 4, done
🚨 BFS — COMMON MISTAKES
❌ Mark visited after dequeue✅ Mark BEFORE enqueue
❌ Forget level size✅ int size = q.size()
❌ Duplicate enqueue✅ Check vis before offer

DSU — Disjoint Set Union
PAGE 7/30
🔗 DSU TEMPLATE
// PSEUDO: Dynamic connectivity with path compression + union by rank
class DSU {
  int[] parent, rank;
  DSU(int n) {
    parent = new int[n];
    rank = new int[n];
    for (int i=0; i<n; i++) parent[i] = i; // each node is own parent
  }
  int find(int x) {
    // Path compression: point directly to root
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
  }
  boolean union(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return false; // cycle detected!
    // Union by rank: attach smaller under larger
    if (rank[ra] < rank[rb]) parent[ra] = rb;
    else if (rank[ra] > rank[rb]) parent[rb] = ra;
    else { parent[rb] = ra; rank[ra]++; }
    return true;
  }
}
✅ PURPOSE: Maintain disjoint sets with near‑O(1) union and find operations. Used for dynamic connectivity, cycle detection, and Kruskal's MST.
🤔 WHY DSU? Optimal for incremental edge processing. Union returns false if adding an edge creates a cycle — perfect for cycle detection.
⚠️ WHY NOT DFS/BFS? DFS/BFS would require re‑traversal after every edge addition. DSU processes edges incrementally in O(α(N)).
🚫 WHEN NOT TO USE DSU: When you need to reconstruct paths or need detailed component information (use DFS/BFS with parent tracking).
💡 AHA PROGRESSION
1. Parent array → each node points to itself
2. Find with path compression → O(α(N))
3. Union by rank → keeps trees shallow
4. Union returns false → cycle detected
5. Used in Kruskal for MST
🚨 DSU — COMMON MISTAKES
❌ No path compression✅ parent[x] = find(parent[x])
❌ Wrong union (no rank)✅ Union by rank keeps O(α(N))

Dijkstra — Shortest Path (weighted)
PAGE 8/30
⚡ DIJKSTRA TEMPLATE
// PSEUDO: Greedy shortest path for non-negative weights
int[] dijkstra(int src, List<int[]>[] adj) {
  int n = adj.length;
  int INF = Integer.MAX_VALUE / 2;
  int[] dist = new int[n];
  Arrays.fill(dist, INF);
  dist[src] = 0;
  // Min-heap of [distance, node]
  PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[0] - b[0]);
  pq.offer(new int[]{0, src});
  while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int d = cur[0], u = cur[1];
    // Skip stale entries — CRUCIAL!
    if (d > dist[u]) continue;
    for (int[] edge : adj[u]) {
      int v = edge[0], w = edge[1];
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        pq.offer(new int[]{dist[v], v});
      }
    }
  }
  return dist;
}
✅ PURPOSE: Find shortest paths from a single source in a weighted graph with non-negative edge weights. Used for network delay, navigation, and flight costs.
🤔 WHY DIJKSTRA? Greedy optimal for non-negative weights. When a node is popped from the heap, its distance is final.
⚠️ WHY NOT BFS? BFS ignores weights — it only counts edges. Dijkstra handles weighted edges. WHY NOT BELLMAN-FORD? Dijkstra is faster O((V+E)logV) vs O(VE).
🚫 WHEN NOT TO USE DIJKSTRA: When edge weights are negative (use Bellman-Ford) or when you need all-pairs (use Floyd-Warshall).
💡 AHA PROGRESSION
1. Dist array → ∞ except source
2. Min-heap → always expand closest unvisited
3. Stale entry skip → crucial for correctness
4. Relaxation → update if shorter path found
5. Returns shortest distances to all nodes
🚨 DIJKSTRA — COMMON MISTAKES
❌ Using max heap✅ Use min heap (PriorityQueue)
❌ Missing stale skip✅ if (d > dist[u]) continue

Kruskal, Kahn, Prim — Templates & Why
PAGE 9/30
📐 KRUSKAL (MST)
// Sort edges by weight, add if no cycle
int kruskal(int[][] edges, int n) {
  Arrays.sort(edges, (a,b)->a[0]-b[0]);
  DSU dsu = new DSU(n);
  int cost=0, count=0;
  for (int[] e : edges) {
    if (dsu.union(e[1], e[2])) { cost+=e[0]; if (++count==n-1) break; }
  }
  return cost;
}
✅ PURPOSE: Find MST by sorting edges and adding cheapest safe edges. Used for connecting all points with minimum cost.
🤔 WHY KRUSKAL? Simple edge‑based greedy. DSU detects cycles efficiently.
⚠️ WHY NOT PRIM? Both work. Kruskal is better for sparse graphs (E log E), Prim for dense (V² with matrix).
🚫 WHEN NOT TO USE: When graph is dense and you have adjacency matrix (Prim is better).
🎓 KAHN'S TOPO SORT
// Nodes with indegree 0 are sources
int[] topoSort(int n, List<Integer>[] adj, int[] indegree) {
  Queue<Integer> q = new LinkedList<>();
  for (int i=0; i<n; i++) if (indegree[i]==0) q.offer(i);
  int[] res = new int[n]; int idx=0;
  while (!q.isEmpty()) {
    int u=q.poll(); res[idx++]=u;
    for (int v : adj[u]) if (--indegree[v]==0) q.offer(v);
  }
  return idx==n ? res : new int[0];
}
✅ PURPOSE: Produce a linear ordering of nodes in a DAG. Used for course schedules, build systems, and dependency resolution.
🤔 WHY KAHN? O(V+E) BFS‑based. Naturally detects cycles (if processed < n → cycle).
⚠️ WHY NOT DFS TOPO? DFS topo requires post‑order reversal. Kahn's is more intuitive for cycle detection.
🌲 PRIM'S MST
// Grow tree by adding cheapest connecting edge
int prim(int n, List<int[]>[] adj) {
  boolean[] inMST = new boolean[n];
  PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
  pq.offer(new int[]{0, 0});
  int cost=0, count=0;
  while (!pq.isEmpty() && count<n) {
    int[] cur=pq.poll(); int w=cur[0], u=cur[1];
    if (inMST[u]) continue;
    inMST[u]=true; cost+=w; count++;
    for (int[] e : adj[u]) if (!inMST[e[0]]) pq.offer(new int[]{e[1], e[0]});
  }
  return cost;
}
✅ PURPOSE: MST via vertex expansion. Better for dense graphs (O(V²) with matrix).
🤔 WHY PRIM? Greedy vertex‑based. Works well with adjacency matrix for dense graphs.
💡 Kruskal = sort + DSU. Kahn = indegree + queue. Prim = PQ + visited. Choose based on graph density and input format.

🔄 BELLMAN-FORD
// Relax all edges V-1 times
int[] bellmanFord(int src, int n, int[][] edges) {
  int INF = Integer.MAX_VALUE/2;
  int[] dist = new int[n]; Arrays.fill(dist, INF); dist[src]=0;
  for (int i=0; i<n-1; i++)
    for (int[] e : edges)
      if (dist[e[0]] + e[2] < dist[e[1]]) dist[e[1]] = dist[e[0]] + e[2];
  // Check negative cycles
  for (int[] e : edges)
    if (dist[e[0]] + e[2] < dist[e[1]]) return null;
  return dist;
}
✅ PURPOSE: Shortest path with negative weights and negative cycle detection. Used for K‑stop flights, arbitrage, and currency exchange.
🤔 WHY BELLMAN-FORD? Only algorithm that handles negative weights and detects negative cycles. O(VE).
⚠️ WHY NOT DIJKSTRA? Dijkstra fails on negative weights. Use Bellman-Ford when weights can be negative.
🚫 WHEN NOT TO USE: When graph is large (V up to 10⁵) — O(VE) is too slow. Use Dijkstra for non-negative weights.
🌐 FLOYD-WARSHALL
// All-pairs shortest path via DP
int[][] floyd(int n, int[][] dist) {
  for (int k=0; k<n; k++)
    for (int i=0; i<n; i++)
      for (int j=0; j<n; j++)
        if (dist[i][k] + dist[k][j] < dist[i][j])
          dist[i][j] = dist[i][k] + dist[k][j];
  return dist;
}
✅ PURPOSE: All‑pairs shortest path in one DP pass. Used for small dense graphs, city distance matrices.
🤔 WHY FLOYD? Simple O(V³) implementation. Handles negative weights (no negative cycles).
⚠️ WHY NOT V×DIJKSTRA? Floyd is simpler and often faster for dense graphs (V ≤ 200).
🚫 WHEN NOT TO USE: When V > 500 — O(V³) becomes too slow. Use Johnson's algorithm for sparse graphs.
🧩 0-1 BFS
// Deque: push front for weight 0, back for weight 1
Deque<Integer> dq = new ArrayDeque<>();
dist[src]=0; dq.offerFirst(src);
while (!dq.isEmpty()) {
  int u = dq.pollFirst();
  for (int[] e : adj[u]) {
    int v=e[0], w=e[1];
    if (dist[u] + w < dist[v]) {
      dist[v] = dist[u] + w;
      if (w==0) dq.offerFirst(v);
      else dq.offerLast(v);
    }
  }
}
✅ PURPOSE: Shortest path in graphs with edge weights 0 or 1. Faster than Dijkstra for this special case.
🤔 WHY 0-1 BFS? O(V+E) vs Dijkstra's O((V+E)logV). Uses deque to maintain order.
🚫 WHEN NOT TO USE: When weights are not only 0 or 1 — use Dijkstra.
🔗 TARJAN SCC
// DFS with disc[], low[], stack
void tarjan(int u) {
  disc[u]=low[u]=++time; stack.push(u);
  for (int v : adj[u]) {
    if (disc[v]==0) { tarjan(v); low[u]=Math.min(low[u], low[v]); }
    else if (stack.contains(v)) low[u]=Math.min(low[u], disc[v]);
  }
  if (low[u]==disc[u]) { // root of SCC
    while (true) { int w=stack.pop(); /* add to component */ if (w==u) break; }
  }
}
✅ PURPOSE: Find strongly connected components in O(V+E). Used for cyclic dependencies, social network clusters.
🤔 WHY TARJAN? Single DFS pass. More efficient than Kosaraju for large graphs.
⚠️ WHY NOT KOSARAJU? Kosaraju requires reverse graph. Tarjan is more space‑efficient.
📐 COMPLEXITY PROOFS
DFS/BFS O(V+E): Each node visited once, each edge traversed at most twice (undirected) or once (directed).
Dijkstra O((V+E)logV): Each edge relaxed once, each heap operation O(logV).
DSU O(α(N)): Path compression + union by rank → inverse Ackermann, effectively constant.
Kruskal O(E log E): Sorting edges dominates.

Bidirectional BFS — Template & Why
PAGE 11/30
⭐ BIDIRECTIONAL BFS TEMPLATE
// PSEUDO: Two frontiers — start and target — meet in the middle
boolean bidirectionalBFS(start, target, adj) {
  Set<Integer> f1 = new HashSet<>(), f2 = new HashSet<>();
  Set<Integer> v1 = new HashSet<>(), v2 = new HashSet<>();
  f1.add(start); f2.add(target);
  v1.add(start); v2.add(target);
  int steps = 0;
  while (!f1.isEmpty() && !f2.isEmpty()) {
    if (f1.size() > f2.size()) { // expand smaller frontier
      Set<Integer> tmp = f1; f1 = f2; f2 = tmp;
      Set<Integer> tmpV = v1; v1 = v2; v2 = tmpV;
    }
    Set<Integer> next = new HashSet<>();
    for (int u : f1) {
      for (int v : adj[u]) {
        if (v2.contains(v)) return steps + 1; // found!
        if (!v1.contains(v)) { v1.add(v); next.add(v); }
      }
    }
    f1 = next; steps++;
  }
  return false;
}
✅ PURPOSE: Faster shortest path when both source and target are known. Used for word ladders, social network connections, and GPS navigation.
🤔 WHY BIDIRECTIONAL BFS? Reduces time from O(V+E) to O(2·V^d/2). Drastically faster for large graphs.
⚠️ WHY NOT STANDARD BFS? Standard BFS explores all nodes in a ball around the source. Bidirectional explores from both ends and meets in the middle.
🚫 WHEN NOT TO USE: When you don't know the target, or when the graph is very small (standard BFS is simpler).

int numIslands(char[][] grid) {
  int count=0;
  for (int r=0; r<grid.length; r++)
    for (int c=0; c<grid[0].length; c++)
      if (grid[r][c]=='1') { dfs(grid,r,c); count++; }
  return count;
}
void dfs(char[][] g, int r, int c) {
  if (r<0||r>=g.length||c<0||c>=g[0].length||g[r][c]=='0') return;
  g[r][c]='0';
  for (int[] d : DIRS) dfs(g, r+d[0], c+d[1]);
}

int area(int[][] g, int r, int c) {
  if (r<0||r>=g.length||c<0||c>=g[0].length||g[r][c]==0) return 0;
  g[r][c]=0;
  int a=1;
  for (int[] d : DIRS) a += area(g, r+d[0], c+d[1]);
  return a;
}

LC 130 · Surrounded RegionsM
In: char[][] board
Out: void
Template: Grid DFS v3
Time: O(R*C), Space: O(R*C)
Edge Cases: empty board, all 'O', all 'X'
AHA: Border-connected O's survive.
Why: Mark border O's as safe, flip rest.
void solve(char[][] board) {
  if (board.length==0) return;
  int R=board.length, C=board[0].length;
  // Mark border O's and connected as '#'
  for (int r=0; r<R; r++) {
    if (board[r][0]=='O') dfs(board,r,0);
    if (board[r][C-1]=='O') dfs(board,r,C-1);
  }
  for (int c=0; c<C; c++) {
    if (board[0][c]=='O') dfs(board,0,c);
    if (board[R-1][c]=='O') dfs(board,R-1,c);
  }
  // Flip remaining 'O' to 'X', restore '#' to 'O'
  for (int r=0; r<R; r++)
    for (int c=0; c<C; c++) {
      if (board[r][c]=='O') board[r][c]='X';
      else if (board[r][c]=='#') board[r][c]='O';
    }
}
void dfs(char[][] b, int r, int c) {
  if (r<0||r>=b.length||c<0||c>=b[0].length||b[r][c]!='O') return;
  b[r][c]='#';
  for (int[] d : DIRS) dfs(b, r+d[0], c+d[1]);
}
LC 994 · Rotting OrangesM
In: int[][] grid
Out: int min
Template: Multi-source BFS
Time: O(R*C), Space: O(R*C)
Edge Cases: no fresh, no rotten, disconnected
AHA: All sources start at t=0.
int orangesRotting(int[][] grid) {
  Queue<int[]> q = new LinkedList<>();
  int fresh=0, time=0;
  for (int r=0; r<grid.length; r++)
    for (int c=0; c<grid[0].length; c++) {
      if (grid[r][c]==2) q.offer(new int[]{r,c});
      else if (grid[r][c]==1) fresh++;
    }
  while (!q.isEmpty() && fresh>0) {
    int size=q.size(); time++;
    for (int i=0; i<size; i++) {
      int[] cur=q.poll();
      for (int[] d : DIRS) {
        int nr=cur[0]+d[0], nc=cur[1]+d[1];
        if (nr>=0 && nr<grid.length && nc>=0 && nc<grid[0].length && grid[nr][nc]==1) {
          grid[nr][nc]=2; fresh--;
          q.offer(new int[]{nr,nc});
        }
      }
    }
  }
  return fresh==0 ? time : -1;
}
LC 542 · 01 MatrixM
In: int[][] mat
Out: int[][] dist
Template: Multi-source BFS
Time: O(R*C), Space: O(R*C)
AHA: Enqueue all 0's, BFS outward.
int[][] updateMatrix(int[][] mat) {
  int R=mat.length, C=mat[0].length;
  Queue<int[]> q = new LinkedList<>();
  int[][] dist = new int[R][C];
  for (int r=0; r<R; r++)
    for (int c=0; c<C; c++) {
      if (mat[r][c]==0) { q.offer(new int[]{r,c}); dist[r][c]=0; }
      else dist[r][c] = Integer.MAX_VALUE;
    }
  while (!q.isEmpty()) {
    int[] cur=q.poll();
    for (int[] d : DIRS) {
      int nr=cur[0]+d[0], nc=cur[1]+d[1];
      if (nr>=0 && nr<R && nc>=0 && nc<C && dist[nr][nc] > dist[cur[0]][cur[1]] + 1) {
        dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
        q.offer(new int[]{nr,nc});
      }
    }
  }
  return dist;
}
LC 1971 · Path ExistsE
In: int n, int[][] edges, int s, int d
Out: boolean
Template: DFS / BFS
Time: O(V+E), Space: O(V+E)
AHA: Simple connectivity check.
boolean validPath(int n, int[][] edges, int src, int dest) {
  List<Integer>[] adj = new ArrayList[n];
  for (int i=0; i<n; i++) adj[i]=new ArrayList<>();
  for (int[] e : edges) { adj[e[0]].add(e[1]); adj[e[1]].add(e[0]); }
  boolean[] vis = new boolean[n];
  return dfs(src, dest, adj, vis);
}
boolean dfs(int u, int dest, List<Integer>[] adj, boolean[] vis) {
  if (u==dest) return true;
  vis[u]=true;
  for (int v : adj[u]) if (!vis[v] && dfs(v, dest, adj, vis)) return true;
  return false;
}

LC 743 · Network Delay TimeM
In: int[][] times, int n, int k
Out: int max
Template: Dijkstra
Time: O((V+E)logV), Space: O(V+E)
Edge Cases: unreachable node → -1
AHA: Max distance to any node is answer.
Why Dijkstra: Weighted non-negative edges → optimal.
int networkDelayTime(int[][] times, int n, int k) {
  List<int[]>[] adj = new ArrayList[n+1];
  for (int i=1; i<=n; i++) adj[i]=new ArrayList<>();
  for (int[] t : times) adj[t[0]].add(new int[]{t[1], t[2]});
  int INF = Integer.MAX_VALUE/2;
  int[] dist = new int[n+1]; Arrays.fill(dist, INF);
  dist[k]=0;
  PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->a[0]-b[0]);
  pq.offer(new int[]{0, k});
  while (!pq.isEmpty()) {
    int[] cur=pq.poll(); int d=cur[0], u=cur[1];
    if (d > dist[u]) continue;
    for (int[] e : adj[u]) {
      int v=e[0], w=e[1];
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        pq.offer(new int[]{dist[v], v});
      }
    }
  }
  int max=0;
  for (int i=1; i<=n; i++) { if (dist[i]==INF) return -1; max=Math.max(max,dist[i]); }
  return max;
}
LC 210 · Course Schedule IIM
In: int n, int[][] prereqs
Out: int[] order
Template: Kahn's BFS
Time: O(V+E), Space: O(V+E)
Edge Cases: cycle → empty array
AHA: Kahn's naturally gives order.

int[] findOrder(int n, int[][] prereqs) {
  List<Integer>[] adj = new ArrayList[n];
  int[] indegree = new int[n];
  for (int i=0; i<n; i++) adj[i]=new ArrayList<>();
  for (int[] p : prereqs) { adj[p[1]].add(p[0]); indegree[p[0]]++; }
  Queue<Integer> q = new LinkedList<>();
  for (int i=0; i<n; i++) if (indegree[i]==0) q.offer(i);
  int[] res = new int[n]; int idx=0;
  while (!q.isEmpty()) {
    int u=q.poll(); res[idx++]=u;
    for (int v : adj[u]) if (--indegree[v]==0) q.offer(v);
  }
  return idx==n ? res : new int[0];
}

int[] findRedundantConnection(int[][] edges) {
  DSU dsu = new DSU(edges.length+1);
  for (int[] e : edges) {
    if (!dsu.union(e[0], e[1])) return e;

LC 1584 · Min Cost to Connect PointsM
In: int[][] points
Out: int cost
Template: Kruskal
Time: O(N² log N), Space: O(N²)
AHA: MST = sort + DSU.
int minCostConnectPoints(int[][] points) {
  int n=points.length;
  List<int[]> edges = new ArrayList<>();
  for (int i=0; i<n; i++)
    for (int j=i+1; j<n; j++) {
      int d = Math.abs(points[i][0]-points[j][0]) +
              Math.abs(points[i][1]-points[j][1]);
      edges.add(new int[]{d, i, j});
    }
  Collections.sort(edges, (a,b)->a[0]-b[0]);
  DSU dsu = new DSU(n);
  int cost=0, count=0;
  for (int[] e : edges) {
    if (dsu.union(e[1], e[2])) {
      cost += e[0];
      if (++count == n-1) break;
    }
  }
  return cost;
}
LC 787 · Cheapest Flights Within K StopsM
In: int n, int[][] flights, int src, int dst, int k
Out: int cheapest
Template: Bellman-Ford
Time: O(K·E), Space: O(V)
AHA: Relax all edges K+1 times.
Why Bellman-Ford: Handles K‑stop constraint naturally.
int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
  int INF = Integer.MAX_VALUE/2;
  int[] dist = new int[n]; Arrays.fill(dist, INF); dist[src]=0;
  for (int i=0; i<=k; i++) {
    int[] prev = dist.clone();
    for (int[] f : flights) {
      if (prev[f[0]] + f[2] < dist[f[1]]) {
        dist[f[1]] = prev[f[0]] + f[2];
      }
    }
  }
  return dist[dst] == INF ? -1 : dist[dst];
}

LC 269 · Alien DictionaryH
In: String[] words
Out: String order

Time: O(C+E), Space: O(C+E)

String alienOrder(String[] words) {
  Map<Character,List<Character>> adj = new HashMap<>();
  Map<Character,Integer> indegree = new HashMap<>();
  for (String w : words) for (char c : w.toCharArray()) indegree.put(c,0);
  for (int i=0; i<words.length-1; i++) {
    String w1=words[i], w2=words[i+1];
    int len=Math.min(w1.length(), w2.length());
    boolean found=false;
    for (int j=0; j<len; j++) {
      char c1=w1.charAt(j), c2=w2.charAt(j);
      if (c1!=c2) {
        adj.computeIfAbsent(c1, k->new ArrayList<>()).add(c2);
        indegree.put(c2, indegree.get(c2)+1);
        found=true; break;
      }
    }
    if (!found && w1.length() > w2.length()) return "";
  }
  Queue<Character> q = new LinkedList<>();
  for (char c : indegree.keySet()) if (indegree.get(c)==0) q.offer(c);
  StringBuilder sb = new StringBuilder();
  while (!q.isEmpty()) {
    char u=q.poll(); sb.append(u);
    for (char v : adj.getOrDefault(u, new ArrayList<>())) {
      indegree.put(v, indegree.get(v)-1);
      if (indegree.get(v)==0) q.offer(v);
    }
  }
  return sb.length()==indegree.size() ? sb.toString() : "";
}
LC 1334 · Find the CityM
In: int n, int[][] edges, int distanceThreshold
Out: int city
Template: Floyd-Warshall
Time: O(V³), Space: O(V²)
AHA: All-pairs shortest path.
Why Floyd: Need all-pairs distances for small n.
int findTheCity(int n, int[][] edges, int distanceThreshold) {
  int INF = Integer.MAX_VALUE/2;
  int[][] dist = new int[n][n];
  for (int i=0; i<n; i++) { Arrays.fill(dist[i], INF); dist[i][i]=0; }
  for (int[] e : edges) { dist[e[0]][e[1]] = e[2]; dist[e[1]][e[0]] = e[2]; }
  for (int k=0; k<n; k++)
    for (int i=0; i<n; i++)
      for (int j=0; j<n; j++)
        if (dist[i][k] + dist[k][j] < dist[i][j]) dist[i][j] = dist[i][k] + dist[k][j];
  int bestCity = 0, bestCount = Integer.MAX_VALUE;
  for (int i=0; i<n; i++) {
    int count = 0;
    for (int j=0; j<n; j++) if (i!=j && dist[i][j] <= distanceThreshold) count++;
    if (count <= bestCount) { bestCount = count; bestCity = i; }
  }
  return bestCity;
}
LC 802 · Eventual Safe StatesM

Out: List safe

List<Integer> eventualSafeNodes(int[][] graph) {
  int n = graph.length;
  int[] state = new int[n]; // 0=unvisited, 1=visiting, 2=visited
  List<Integer> res = new ArrayList<>();
  for (int i=0; i<n; i++) if (isSafe(i, graph, state)) res.add(i);
  Collections.sort(res);
  return res;
}
boolean isSafe(int u, int[][] graph, int[] state) {
  if (state[u] != 0) return state[u] == 2;
  state[u] = 1;
  for (int v : graph[u]) {
    if (state[v] == 1 || !isSafe(v, graph, state)) return false;
  }
  state[u] = 2;
  return true;
}

Interview Scripts & Follow-ups
PAGE 19/30
🎤 DFS
"I'll use DFS to explore each connected component. I'll mark visited nodes to avoid cycles. For each unvisited node, I start a DFS and count it as one component. This gives us O(V+E) time."
Follow-up: Graph too large for recursion? → Use iterative DFS.
🎤 BFS
"Since the graph is unweighted, BFS guarantees the shortest path. I'll use a queue, marking nodes when I enqueue them to avoid duplicates. This gives us O(V+E)."
Follow-up: Weighted edges? → Use Dijkstra.
🎤 Dijkstra
"I'll use Dijkstra with a min-heap because all edge weights are non-negative. I skip stale entries by checking if the popped distance matches the stored one. This gives O((V+E)logV)."
Follow-up: Negative weights? → Bellman-Ford.
🎤 DSU
"I'll use DSU with path compression and union by rank. Each node starts as its own parent. When I union two nodes, if they already share a root, that edge creates a cycle."
🎤 Kahn's
"I'll use Kahn's algorithm with indegree tracking. Nodes with indegree 0 have no prerequisites. If I process all nodes, it's a DAG; otherwise there's a cycle."
🎤 Multi-source BFS
"I'll enqueue all source nodes initially and run BFS level by level. Each level represents one time step."
