# Visual Layout Specification

## Overall Grid Structure
The document follows a complex, multi-column grid layout with distinct horizontal sections. It uses a clean, highly structured, technical design aesthetic.
- **Background**: White or very light gray.
- **Borders**: Thin navy blue lines define most rectangular content blocks.
- **Card/Block Headers**: Navy blue rectangular bars with white text.
- **Primary Accent Colors**: Navy blue (#000080 or similar), pale blue highlights, with touches of green, red, and yellow for icons/markers.
- **Font Stack**: Sans-serif, structured, hierarchical (bold for headings, normal for body).

## Header Area
- **Page Badge**: Top left, solid navy blue rectangle with white text ("PAGE 4").
- **Main Title**: Centered, large bold navy blue text with a book icon. Subtitle below in a slightly smaller font, bordered by horizontal lines.

## Content Row 1 (Top)
A 3-column layout, uneven widths.
- **Box 1 (Left - MASTER IDEA)**: Narrow column. Contains centered text with bullet point-like statements and a lightbulb icon. Five stars in header.
- **Box 2 (Middle - GRAPH DFS (ADJACENCY LIST))**: Wide column. Contains a 2-column key-value table at the top, a section header ("Java Template" with a light green background), and a code block section (light gray background, monospaced colored syntax). Contains an "AHA" highlight box at the bottom.
- **Box 3 (Right - GRID DFS)**: Wide column, mirrors the structure of Box 2 with table, Java template, code block, and bottom "AHA" box.

## Content Row 2 (Middle)
A 3-column layout, mostly equal widths, maintaining the gap spacing from Row 1.
- **Box 4 (Left - NODE GRAPH DFS)**: Contains a table, a Java Template header (green), a code block, and an AHA box at the bottom.
- **Box 5 (Center - DISCONNECTED GRAPH DFS)**: Contains a table, a Java Template header, a code block, and an AHA box.
- **Box 6 (Right - BORDER DFS)**: Contains a table, a Java Template header, a code block, and an AHA box.

## Content Row 3 (Lower Middle)
A 2-column layout.
- **Box 7 (Left - RETURN TYPE GUIDE)**: Takes up about 40% of width. Contains a 3-column table with a colored header row (Return Type, Used For, Example Problems, What it Means). Alternating row colors (white/pale blue). Contains a yellow star icon at the bottom.
- **Box 8 (Right - TEMPLATE COMPARISON)**: Takes up about 60% of width. Contains a 5-column table (Template, Input, Caller, Visited, Return, Special Change). Uses small node/graph icons next to the template names.

## Content Row 4 (Bottom)
A 3-column layout.
- **Box 9 (Left - AHA MOMENTS)**: List layout with left-aligned icons (key, grid, nodes, branching, flags, edit) and corresponding text strings.
- **Box 10 (Center - COMMON INTERVIEW MISTAKES)**: List layout with left-aligned red 'X' icons indicating anti-patterns or mistakes.
- **Box 11 (Right - INTERVIEW THINKING FLOW)**: A flowchart diagram. Uses colored rounded rectangles (purple, light blue, green, orange, pink) connected by directional arrows, illustrating a decision tree.

## Footer Area
- **Box 12 (PREVIEW OF PAGE 5)**: Left aligned. Contains two columns of bullet points with green checkmarks, and a right-aligned descriptive text box with a blue border.
- **Bottom Workflow Bar**: A horizontal sequence of icons and text connected by small arrows (Problem -> Input -> Representation -> Helper Structure -> Pattern -> Tiny Logic Change -> Dry Run -> Optimize). Spans the full width of the page at the very bottom.

## Styling Details
- **Tables**: Most tables lack vertical borders, relying on spacing and horizontal rules or row backgrounds.
- **Code Blocks**: Formatted with syntax highlighting (blue keywords, green comments, black/dark gray text).
- **Icons**: Used extensively to break up text and add visual anchors (stars, lightbulbs, checkmarks, red crosses, keys, flow nodes).
