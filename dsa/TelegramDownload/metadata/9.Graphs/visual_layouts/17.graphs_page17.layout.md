# Visual Layout Specification: Graph Pattern Guide (Page 15)

## 1. Overall Layout Structure
* **Grid System**: The page utilizes a multi-level grid system. The central body consists of a 3-column grid, followed by a 4-column grid for reference tables, and a 2-column split for footer diagrams.
* **Background & Margins**: White background with thin, subtle gray dividing lines separating major sections. Uniform standard page margins.
* **Color Palette**: 
  * Primary Accents: Dark Navy Blue (Headers, numbers, borders).
  * Secondary Accents: Purple, Green, Orange, Teal, Pink (Used for categorization tags and legend items).
  * Typography: Black body text, Blue sub-headers, Monospace fonts with syntax highlighting (green/blue) for code snippets.

## 2. Header Section
* **Page Badge (Top Left)**: Solid navy blue rectangular block with white bold text ("PAGE 15").
* **Main Title (Top Center)**: Large, bold, centered text ("GRAPH PATTERN GUIDE") flanked by a book icon on the left.
* **Sub-Title (Below Main Title)**: Blue text flanked by horizontal lines ("PAGE 15 — SPECIAL GRAPH PROBLEMS GUIDE (APPLY TEMPLATES)").
* **Quote Line**: Centered italicized blue text positioned just below the sub-title.

## 3. Top Information Row (Asymmetrical Split)
* **Left Block ("HOW TO USE THIS PAGE")**:
  * Spans approximately 1/3 of the page width.
  * Header: Solid purple background with white text.
  * Content: 6-item numbered list.
  * Visual Element: A large, circular target/bullseye icon with an arrow, right-aligned next to the list.
* **Right Block ("TEMPLATE LEGEND")**:
  * Spans approximately 2/3 of the page width.
  * Header: Solid navy blue background with white text.
  * Content: A 2-row by 3-column grid of legend items.
  * Visual Elements: Each item features a solid-colored square icon containing a white letter (A: Navy, B: Green, C: Purple, D: Orange, E: Pink, F: Teal) adjacent to text descriptions.

## 4. Main Content Grid (3 Columns x 2 Rows)
Contains 6 individual "Problem Cards", labeled 1 through 6. Each card follows a strict internal visual structure:
* **Card Header**: 
  * Left: Solid navy blue square containing the card number in white.
  * Center: Bold uppercase card title.
  * Right: A small solid-colored square tag containing a letter (e.g., 'S', 'I', 'K').
* **Card Sub-header**: Centered blue text ("Base Template: ...").
* **Card Body**:
  * Standard text for "Problem" description.
  * Sub-heading for "Changed Lines".
  * Code Block: Monospaced font layout with indents and standard color highlighting for comments (green).
* **Card Meta-Table**: 
  * A 3-column minimalist table with thin gray borders (Headers: Caller, Return, Key Idea).
* **Card Callout**: 
  * A row starting with a lightbulb icon and bold "AHA:" text, indicating a key insight.
* **Card Footer**: 
  * A 2-column minimalist table (Headers: Complexity, Interview Tip).

## 5. Reference Tables Row (4 Columns)
A single row divided into 4 equal-width blocks (Cards 7, 8, 9, 10).
* **Card 7 ("CHANGED LINES SUMMARY")**: Navy blue number box + Title. Contains a 3-column table (Problem, Base Template, Key Change).
* **Card 8 ("COMPLEXITY QUICK GUIDE")**: Navy blue number box + Title. Contains a 3-column table (Pattern, Time Complexity, Space Complexity) with a highlighted green footer row.
* **Card 9 ("RETURN TYPE GUIDE")**: Navy blue number box + Title. Contains a 4-column table (Pattern, Return Type, Use When, Example Problems).
* **Card 10 ("INTERVIEW CHECKLIST")**: Navy blue number box + Title. Contains a list where each item is preceded by a blue outlined checkbox icon with a checkmark.

## 6. Footer Section (2 Columns + Full Width Bottom)
* **Card 11 ("INTERVIEW THINKING FLOW")** (Left/Center, spans ~2/3 width):
  * Navy blue number box + Title.
  * Visual Element: A horizontal flowchart consisting of 5 circular icons connected by right-facing arrows. Below each icon is a two-line text label (e.g., "Understand Problem").
  * Callout: A rounded rectangular badge labeled "TIP:" followed by bold text.
* **Card 12 ("PAGE 16 PREVIEW")** (Right, spans ~1/3 width):
  * Navy blue number box + Title.
  * Visual Element: A grid of 7 small icon boxes, each containing a line-art icon and a tiny text label (e.g., "Pattern Summary", "Key Steps"), arranged in a primary row of 6 and a floating 7th item.
* **Bottom Full-Width Banner ("CHEAT PIPELINE")**:
  * Spans the entire bottom margin of the page.
  * Header text centered.
  * Visual Element: A linear horizontal sequence diagram with 6 steps. Each step includes an icon, a bold title, and a sub-title in parentheses, connected by simple right-facing arrows.
