# Visual Layout Specification: Arrays & Hashing Patterns Cheat Sheet

## 1. Global Layout & Grid System
- **Orientation:** Landscape
- **Main Grid Structure:**
  - **Header Region:** Full width, single block.
  - **Primary Content Region:** 3x3 grid (3 columns, 3 rows) displaying 9 individual cards.
  - **Secondary Content Region:** 4 columns, 1 row (4 individual footer cards).
  - **Footer Region:** Full width, single block.
- **Spacing/Gutters:** Consistent, narrow gutters between grid items. Borders around cards are thin and light grey.

## 2. Color Palette & Typography
- **Background Colors:**
  - Page Background/Headers: Deep navy blue / black.
  - Card Backgrounds: White.
  - Code Block Backgrounds: Pale grey.
- **Text Colors:**
  - Main Headings: White.
  - Subheadings/Card Titles: Dark blue/indigo.
  - General Text: Black/Dark Grey.
  - Highlights/Code Comments/Metrics: Emerald green.
  - Accents (Footer text, icons): Yellow/Gold.
- **Typography:** Sans-serif for all UI elements and labels. Monospace for code snippets and variable names.

## 3. Component Details

### A. Main Header
- **Alignment:** Center aligned.
- **Elements:** 
  - Primary Title: Extra large, bold, uppercase, white.
  - Secondary Title: Medium, regular weight, white, with an inline yellow highlight for emphasis.

### B. Pattern Cards (Grid Items 1-8)
- **Header:** Features a bottom-bordered section containing a distinct icon (e.g., magnifying glass, chart, link), an index number, and an uppercase title in dark indigo.
- **Internal Split Layout:**
  - **Left Column (approx. 70% width):**
    - Key-Value pairs for "Use Case", "Data Structure", and "Key Idea". Labels are in teal/green, values in black.
    - Code Snippet Block: Encapsulated in a light grey bounding box, featuring syntax highlighting (green comments, red strings, blue keywords).
    - *Exception:* Card 8 uses a 3-column internal layout instead of a code block to display grid visuals and lists.
  - **Right Column (approx. 30% width):**
    - Separated by a thin vertical line.
    - Top section: "Problems" heading with a bulleted list of hyperlinks/problem titles in light blue.
    - Bottom section: "Time Complexity" and "Space Complexity" metrics vertically stacked, pushed to the bottom.

### C. Summary Card (Grid Item 9)
- **Title:** "WHEN TO USE WHAT?"
- **Header Design:** Inverted color scheme (Deep navy background, white text, yellow icon) to visually distinguish it from the pattern cards.
- **Content Layout:** Two-column table layout.
  - Left column: "Scenario" (Black text).
  - Right column: "Best Choice" (Green text).

### D. Footer Cards (4 Columns)
- **Header Design:** Similar to Card 9, utilizing deep navy backgrounds with white text and yellow/white icons.
- **Card 1 (TIPS & REMINDERS):** Unordered bulleted list.
- **Card 2 (COMMON HASHMAP METHODS):** Key-value list mapping code snippets to descriptions.
- **Card 3 (COMPLEXITY REFERENCE):** 4-column data table (Operation | HashMap/HashSet | Array | Sorting). Values are colored green.
- **Card 4 (SPACE RULE OF THUMB):** Paragraph text with inline bullet points and bolded formulas.

### E. Bottom Bar
- **Alignment:** Center aligned.
- **Design:** Deep navy background matching the top header. Contains a trophy icon and yellow text acting as a final concluding remark.
