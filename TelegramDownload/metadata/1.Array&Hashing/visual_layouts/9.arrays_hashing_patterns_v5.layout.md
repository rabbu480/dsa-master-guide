# Visual Layout Specification: Arrays & Hashing - Java Cheat Sheet (Image 2)

## 1. Document Overview
* **Orientation:** Landscape
* **Theme:** Dark theme with light content blocks (high contrast)
* **Structure:** Multi-column grid layout with distinct header, body, and footer regions.

## 2. Layout Grid & Spans
The document is divided into four main vertical regions:

### 2.1. Header Region
* **Span:** Full width (100%)
* **Alignment:** Centered
* **Components:** Main title and subtitle stacked vertically.

### 2.2. Main Body Region
* **Span:** Full width, split into two primary vertical areas.
* **Left Area (approx. 33% width):**
  * Contains a single continuous block spanning the full height of the body region.
  * Labeled "1. DATA STRUCTURES - QUICK REFERENCE".
* **Right Area (approx. 67% width):**
  * Subdivided into two horizontal tiers.
  * **Top Tier:** Split into two equal vertical columns (approx. 50% each within the right area).
    * Left Column: "2. COMMON JAVA CONVERSIONS"
    * Right Column: "3. USEFUL JAVA PATTERNS & METHODS"
  * **Bottom Tier:** Split into four equal vertical columns (approx. 25% each within the right area).
    * Column 1: "4. FREQUENCY ARRAY"
    * Column 2: "5. BUCKET / GROUPING PATTERN"
    * Column 3: "6. TOP K FREQUENT"
    * Column 4: "7. CHECKLIST - WHEN SOLVING"

### 2.3. Lower Section (Section 8)
* **Span:** Full width (100%) below the Main Body Region.
* **Components:**
  * Header spanning full width.
  * Body split into a 5-column sub-grid for syntax snippets.
  * A distinct, highlighted floating block on the far right: "MOST USED IN INTERVIEWS", integrated into the rightmost area of this section.

### 2.4. Footer Region
* **Span:** Full width (100%) at the absolute bottom edge.
* **Layout:** Single inline flex row with evenly spaced items.

## 3. Color Palette & Typography
* **Global Background:** Deep dark navy/black.
* **Block Backgrounds:** White, with thin gray or colored borders.
* **Header Backgrounds (Sections 1-6, 8):** Solid dark blue with white text.
* **Header Background (Section 7):** Solid dark red with white text.
* **Main Title:** White text with yellow accent for "JAVA CHEAT SHEET".
* **Code Formatting:**
  * Comments: Green
  * Keywords/Data Types: Dark blue/purple
  * Strings: Orange/red
  * Standard text: Black/Dark gray
* **Highlight Block ("MOST USED..."):** Dark blue background with white and yellow text, distinct from the white blocks.

## 4. Visual Elements & Alignments
* **Icons:**
  * Section 1 uses small square icons with white glyphs on colored backgrounds next to each data structure name (e.g., green hashtag, blue magnifying glass, dark blue lock, green tree, purple badge).
  * Section 7 uses green square checkmark icons for each list item.
  * The footer uses thematic emojis/icons before each phrase (Star, Lightbulb, Trophy, Target, Gear, Clock).
* **Alignment:**
  * Main titles are center-aligned.
  * Section headers are left-aligned or center-aligned.
  * Code blocks and lists are strictly left-aligned with consistent indentation.
* **Separators:** Thin horizontal and vertical lines (gutters) separate the white content blocks to maintain a rigid grid structure.
