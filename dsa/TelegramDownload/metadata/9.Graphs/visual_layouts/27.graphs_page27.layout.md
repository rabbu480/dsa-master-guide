# Visual Layout Specification

## Overall Layout Structure
- **Page Dimensions/Orientation**: Portrait orientation (standard A4 layout style, as indicated by "A4 PRINT" label).
- **Grid System**: 
  - Top header spanning full width.
  - The main body is divided into multiple main sections marked by numbered headers (1 through 10).
  - Sections 1 and 2 are in a two-column layout (left column is roughly 50% width for Section 1, right column is roughly 50% width for Section 2).
  - Sections 3 and 4 are also in a two-column layout, below 1 and 2.
  - Section 5 spans the full width of the page.
  - Section 6 spans the full width of the page.
  - Sections 7, 8, 9, 10 are arranged in a four-column layout at the bottom.
  - Footer spans full width at the very bottom.

## Header
- Contains a left-aligned badge ("PAGE 18A") with a dark blue background and white text.
- Center-aligned main title with an icon of a book. The title is dark blue, bold.
- Subtitle below main title in smaller font, dark blue.
- Right-aligned badge ("A4 PRINT DSA ONLY") with white background and thin border.

## Block Details and Colors

### Section 1: ALGORITHM DECISION TREE
- **Header**: Dark blue background with white text, left-aligned number in a white square box.
- **Content**: A complex flowchart with rectangles, diamonds, and directional arrows.
  - Start node: Light gray outline.
  - Diamonds (Decisions): Light gray outline.
  - Terminating nodes/Categories: Light green background for BFS, Topological Sort, Union Find, DFS/BFS. Light red/orange background for Dijkstra, Topological Sort (DAG with weights), and 'Use other DS'.
- **Footer**: A "Golden Rule" text with a light bulb icon, centered, blue text.

### Section 2: HIDDEN GRAPH PATTERN RECOGNITION
- **Header**: Dark green background with white text, left-aligned number in a white square box.
- **Content**: A 3-column table.
  - Columns: "PATTERN TYPE", "THINK OF", "EXAMPLES".
  - Pattern type column includes small illustrative icons (grid, graduation cap, people, plane, nodes, water drop, link, etc.).
  - Table has light gray grid lines.
- **Footer**: A "Tip" text with a star icon, dark blue text.

### Section 3: REPRESENTATION SELECTION GUIDE
- **Header**: Purple background with white text.
- **Content**: A flowchart guiding through representation choices.
  - Decision rectangles with arrows leading to light purple backgrounds (Use Adjacency Matrix, Use Adjacency List).
  - Default Choice block with light green background.

### Section 4: HELPER STRUCTURE SELECTION
- **Header**: Orange background with white text.
- **Content**: A 3-column table.
  - Columns: "IF YOU NEED TO...", "USE", "WHY?".
  - Header row text is orange.

### Section 5: ALGORITHM CHOOSER AT A GLANCE
- **Header**: Dark blue background with white text.
- **Content**: A 6-column grid, each column describing an algorithm (DFS, BFS, TOPOLOGICAL SORT, DIJKSTRA, UNION FIND, GRID DFS/BFS).
  - Each column has a bold colored title (blue, green, purple, red, green, orange respectively).
  - Includes bulleted lists for "USE WHEN".
  - Includes time and space complexity with specific icons/bold text at the bottom.

### Section 6: FAANG GRAPH SOLVING PIPELINE
- **Header**: Dark green background with white text.
- **Content**: A horizontal sequence of 7 steps with arrows in between.
  - Each step has an icon inside a rounded square, followed by a bold title and a bulleted list.
  - Icons represent stages like reading (magnifying glass), modeling (graph), choosing (list), structures (boxes), algorithm (code tags), coding (code screen), and optimizing (trophy).

### Section 7: KEY NOTATIONS
- **Header**: Purple background with white text.
- **Content**: A list of variable definitions with bold left sides.

### Section 8: COMPLEXITY SNAPSHOT
- **Header**: Orange background with white text.
- **Content**: A 3-column table detailing Algorithm, Time Complexity, and Space Complexity. Header text is orange.

### Section 9: BIGGEST INTERVIEW PITFALLS
- **Header**: Red background with white text.
- **Content**: A bulleted list with red 'X' icons instead of standard bullets.

### Section 10: REMEMBER THIS!
- **Header**: Dark green background with white text.
- **Content**: A bulleted list with light bulb icons instead of standard bullets.

## Footer
- A single centered line of bold dark blue text flanked by a star icon on the left and an arm muscle icon on the right.

## Alignments & Typography
- Headers for sections 1-10 are bold, all-caps, with a consistent boxed number prefix.
- Flowcharts use orthogonal lines with arrowheads.
- Tables are clean with minimal horizontal and vertical dividers.
- Use of color coding to group related algorithms or concepts (e.g., green for BFS/Union Find, red/orange for Dijkstra/Pitfalls).
