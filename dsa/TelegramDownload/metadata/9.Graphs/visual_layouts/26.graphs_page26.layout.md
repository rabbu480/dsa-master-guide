# Visual Layout Specification: Graph Quick Reference (Page 17B)

## 1. Overall Grid Structure & Page Layout
- **Orientation**: Portrait
- **Margins**: Narrow margins, tightly packed content to maximize information density.
- **Grid Layout**: A primary 3-column layout structure that spans the width of the page, with one full-width row near the bottom and a header/footer spanning the full width.
- **Sections**: The page is divided into 13 numbered blocks/panels plus a top header and a bottom footer.

## 5. Global Visual Elements & Styling
- **Color Palette**: Consistent thematic color coding per section type:
  - Dark Blue: Core concepts / Representations (Sections 1, 6, 8, 13, Headers)
  - Purple: Movements / Patterns (Sections 2, 10)
  - Crimson/Red: Edges / Anti-patterns (Sections 3, 7)
  - Brown/Orange: Complexities / Rules (Sections 4, 12)
  - Dark Green: Data Structures / Checklists (Sections 5, 9, 11)
- **Tables**: Use thin, light gray borders for internal cell dividers. Alternating row colors are subtle or left white to improve readability.
- **Callout Boxes**: Usually located at the bottom of a block. They use a very light pastel shade of their block's primary header color.
- **Typography**: Clean, readable sans-serif font used universally. Bold weight is applied specifically to table headers, important keywords, and block titles.
- **Borders**: All 13 block sections are contained within thin bounding box borders that match their respective header colors, visually separating them from adjacent sections in the dense grid.
