# Visual Layout Specification

## 1. Overall Structure & Grid
- **Page Layout**: Vertical portrait layout.
- **Header Section**: Full-width header spanning the top.
- **Main Body**: 3-column grid layout for the problem blocks, switching to 3-column grid for summary blocks, followed by a full-width footer.
- **Column Structure**: Three equal-width columns.

## 2. Header Elements
- **Title Block**: Top-left, large number block with a dark blue background.
- **Main Title**: Next to the number block, large dark blue text.
- **Subtitle**: Below the main title, with decorative lines on both sides.
- **Legend / Key**: Top-right corner, bordered box containing 4 small icons and their labels, arranged in a 2x2 grid.

## 3. Core Problem Cards (3x2 Grid)
There are six main problem cards, arranged in two rows of three columns. Each card follows a consistent structure:

- **Card Header**: Full-width colored block with white text.
    - Card 1: Green background.
    - Card 2: Purple background.
    - Card 3: Teal background.
    - Card 4: Orange background.
    - Card 5: Dark Green background.
    - Card 6: Red background.
- **Card Body**: White background with a light gray border.
    - **Example Section**: Contains text arrays or diagrams (trees).
    - **AHA Section**: Icon with a title, followed by text.
    - **Pattern Section**: Icon with a title, followed by text.
    - **Idea/Formula Section**: Icon with a title, followed by code snippets or steps.
    - **Complexity Section**: Bottom block with a dark background (matching the header color), followed by Time and Space complexity details.

## 4. Summary & Strategy Cards (Bottom Section)
Three cards arranged in a single row across the three columns.

- **Column 1 Card (Common Mental Models)**:
    - **Card Header**: Centered text, no colored background block.
    - **Content**: A 2-column table with icons on the left, descriptive text, and pattern names on the right. Table rows are separated by light lines.

- **Column 2 Card (Tree Building Index Rules)**:
    - **Card Header**: Centered text, purple background block.
    - **Content**: Two sections (Preorder + Inorder, Inorder + Postorder) separated by a line. Each section shows alignment of terms (Left, Right, Root) with vertical separators `|`.

- **Column 3 Card (Quick Recap)**:
    - **Card Header**: Centered text, green background block.
    - **Content**: A bulleted list with checkmark icons. A trophy icon is placed in the bottom right corner.

## 5. Footer Element
- **Final Mantra**: Full-width banner at the bottom.
- **Content**: Text "FINAL MANTRA" with a trophy icon on the left, followed by a sequence of steps connected by right-pointing arrows.

## 6. Color Palette
- **Primary Navy/Dark Blue**: Used in main titles and headers.
- **Green**: Used in Card 1 header and Recap header.
- **Purple**: Used in Card 2 header and Index Rules header.
- **Teal**: Used in Card 3 header.
- **Orange**: Used in Card 4 header.
- **Dark Green**: Used in Card 5 header.
- **Red**: Used in Card 6 header.
- **Light Gray**: Borders for cards, separation lines.
- **White**: Main background for page and cards.

## 7. Typography & Iconography
- **Headers**: Bold, uppercase sans-serif.
- **Body Text**: Sans-serif, standard weight.
- **Code/Data**: Monospace font used for array representations.
- **Icons**:
    - Lightbulb ("AHA")
    - Gear ("Pattern")
    - Sigma ("Idea/Formula")
    - Clock ("Complexity / Time")
    - Checkmark ("Recap items")
    - Trophy ("Success/Mantra")
    - Various specific icons for the "Mental Models" table (e.g., people, tree, graph, sort).
