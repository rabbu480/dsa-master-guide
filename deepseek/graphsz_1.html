💡 WHAT IS A GRAPH?

Graph = Nodes (Vertices) + Edges (Connections).

Models relationships: social networks, roads, dependencies, grids.

Real-world: You + Friends = Nodes. Friendship = Edge.
⚠️ THE VISITED LAW

Graphs may have cycles. Always track visited to avoid infinite loops.

void dfs(int u, List<Integer>[] adj, boolean[] vis) {
    if (vis[u]) return;
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) dfs(v, adj, vis);
    }
}
Time: O(V+E)  |  Space: O(V)

☕ FULL JAVA TEMPLATE
void bfs(int src, List<Integer>[] adj, boolean[] vis) {
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(src);
    vis[src] = true;
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.offer(v);
            }
        }
    }
}
Time: O(V+E)  |  Space: O(V)
💡 WHY MARK ON ENQUEUE?

Prevents duplicate enqueue and infinite loops.

❌ Duplicate enqueue
✅ Check visited before offer
❌ Forget level size
✅ int size = q.size()

8. DSU – Why & Template
PAGE 13/34
🧠 WHY DSU?

Keep track of GROUPS. union returns false if cycle.

parent[] = “boss”
rank[] = “height”
🔗 DSU TEMPLATE
class DSU {
    int[] parent, rank;
    DSU(int n) { parent=new int[n]; rank=new int[n]; for(int i=0;i<n;i++) parent[i]=i; }
    int find(int x) { if(parent[x]!=x) parent[x]=find(parent[x]); return parent[x]; }
    boolean union(int a, int b) {
        int ra=find(a), rb=find(b);
        if(ra==rb) return false;
        if(rank[ra]<rank[rb]) parent[ra]=rb;
        else if(rank[ra]>rank[rb]) parent[rb]=ra;
        else { parent[rb]=ra; rank[ra]++; }
        return true;
    }
}

Complexity: O(α(N)) ≈ O(1)

    Set<String> set = new HashSet<>(wordList);

    start.add(beginWord); end.add(endWord);

        Set<String> next = new HashSet<>();
