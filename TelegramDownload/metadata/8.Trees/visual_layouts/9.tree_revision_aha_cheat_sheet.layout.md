# Visual Layout Specification: Trees - FAANG One Page Revision

## Global Layout Structure
The document is a single-page landscape or wide-portrait cheat sheet with a structured multi-column grid layout. It uses a consistent color-coding scheme for section headers to distinguish different conceptual areas. The overall background is white, with content organized into bounded boxes.

## Typography and Styling
- **Fonts**: Sans-serif, clean and legible.
- **Section Headers**: White text on solid colored backgrounds (Dark Purple, Dark Blue, Dark Green, Dark Brown/Orange). The headers have a slightly rounded top corner.
- **Body Text**: Black and dark grey for general text, with specific highlight colors for keywords (e.g., Purple, Blue, Orange, Green).
- **Icons**: Extensive use of line-art icons adjacent to list items and table rows to provide visual cues.
