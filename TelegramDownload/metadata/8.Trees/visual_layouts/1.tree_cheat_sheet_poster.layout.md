# Visual Layout Specification: Tree Cheat Sheet Poster

## 1. Overall Document Structure
- **Type**: Cheat Sheet / Poster
- **Orientation**: Landscape
- **Grid Layout**: 4 columns by 2 rows.
- **Header/Footer**: No overarching top header; there is a single full-width footer spanning the bottom of the page.
- **Main Panels**: 8 distinct panels, each corresponding to a section, arranged in the 4x2 grid.
- **Panel Styling**: Each panel features a dark blue banner at the top containing the section title in uppercase white text. The panel content is enclosed in a thin, light gray rounded rectangular border.

## 2. Panel-by-Panel Layout Breakdown

### Row 1, Column 1: "1. TREE FOUNDATIONS"
- **Header**: Dark blue background, white text centered.
- **Section 1.1 (TREE vs BINARY TREE vs BST)**:
  - 3-column layout.
  - Each column contains a subtitle, a brief text description, and a visual tree diagram illustrating the concept.
- **Section 1.2 (TYPES OF BINARY TREES)**:
  - 4-column layout.
  - Each column contains a subtitle, a brief description, and a representative tree diagram (Full, Complete, Perfect, Balanced).
- **Section 1.3 (KEY TERMINOLOGY)**:
  - 2-column list.
  - Bulleted terms and definitions divided evenly across the left and right columns.

### Row 1, Column 2: "2. TRAVERSALS"
- **Header**: Dark blue background, white text centered.
- **Section 2.1 (DEPTH FIRST SEARCH (DFS))**:

- **Section 2.2 (BREADTH FIRST SEARCH (BFS))**:
  - Similar 2-column split: text/rules on the left, numbered tree diagram on the right.

## 3. Visual Styling & Typography
- **Fonts**: Clean, sans-serif font throughout. Variations in font weight (bolding) are heavily used to distinguish titles, keys, and important terms.
- **Color Palette**:
  - **Headers**: Dark navy blue (`#1A2B4C` approx) background with white text.
  - **Text**: Dark gray/black for primary text.
  - **Accents**: 
    - **Green**: Used for "AHA" labels, numerical badges in the recursion flow, and traversal path highlighting.
    - **Red**: Used for highlighting specific nodes (like LCA) or critical warnings.
    - **Blue**: Used for sub-headings and code syntax elements.
  - **Borders**: Light gray for panel containers and internal dividers. Light green for footer notes within panels.
- **Visual Elements**:
  - **Tree Diagrams**: Extensive use of node-and-link diagrams. Nodes are white circles with black borders and text. Links are straight black lines. Some diagrams use directional arrows.
  - **Code Blocks**: Formatted with monospace typography.
  - **Icons**: Used in the page footer (gears, checkmarks, etc.) and as badges.
