# Visual Layout Specification: Binary Search Page 2

## Overall Structure
- **Grid Layout**: 2-column primary grid, with a full-width header and a 2-column full-width footer.
- **Background**: White/Light background with distinct colored blocks for sections.
- **Theme**: Technical, organized, educational cheat sheet.

## Sections Breakdown

### 1. Header (Full Width)
- **Top Bar**: Dark blue rounded banner with a large magnifying glass icon on the left. Title in large white sans-serif text.
- **Subtitle**: Smaller blue pill-shaped banner overlapping the main title bar.
- **Goal Box**: Floating white box with a blue border on the top right, featuring a red target icon.
- **Page Indicator**: Small dark blue tab on the bottom right of the header section indicating page number.

### 2. Left Column

#### Block 6: Variants of Binary Search
- **Header**: Purple banner with white text.
- **Content**: 2-column table with purple headers ("Variant", "When to Use").
- **Table Details**: The left column contains icons representing each variant (magnifying glass, upward chart, downward chart, rotate icon, mountain icon, question mark). The right column contains text descriptions. Alternating light gray background for rows.

#### Block 8: Search in Rotated Sorted Array (Unique Elements)
- **Header**: Orange banner with white text.
- **Content**: Complex flowchart diagram.
- **Flowchart Nodes**: 
  - Starting rounded rectangle block.
  - Diamond decision block with "YES" (green line) and "NO" (red line) branches.
  - Split branches into rectangular blocks for "Left half sorted?" and "Right half is sorted".
  - Further splits into target condition blocks (light green backgrounds).
  - Terminal action blocks (green text borders).
- **Footer Callout**: Full-width red bordered box with a star icon at the bottom of the block.

#### Block 10: Visualizing Binary Search (Boundary Search)
- **Header**: Purple banner with white text.
- **Content**: Step-by-step array visualization.
- **Structure**: 
  - Text description at the top.
  - Three distinct steps (Step 1, Step 2, Step 3) shown in blue pill boxes.
  - Each step contains an array represented as contiguous square cells with indices above.
  - Target element is highlighted in yellow.
  - Pointers (l, m, r) are shown as arrows (green and red) pointing to array indices.
  - Text annotations on the right side of each array showing condition checks and variable updates.
  - Final answer box at the bottom (green border, green text).

### 3. Right Column

#### Block 7: First & Last Occurrence Templates
- **Header**: Green banner with white text.
- **Content**: 2-column internal layout.
- **Columns**:
  - Left column: "First Occurrence (Lower Bound)" with a black code block (Java syntax highlighting).
  - Right column: "Last Occurrence (Upper Bound)" with a black code block (Java syntax highlighting).
- **Footer Callout**: "PRO TIP" box spanning the width of the block, with a yellow lightbulb icon.

#### Block 9: Binary Search on Answer
- **Header**: Blue banner with white text.
- **Content**: 
  - Text section ("When to Use?") with bullet points.
  - Text section ("General Template") with a black code block (Java syntax highlighting).
  - "Examples" section at the bottom containing a 2-column bulleted list inside a light blue bordered box.

#### Block 11: Common Mistakes & How to Avoid Them
- **Header**: Red banner with white text.
- **Content**: 3-column table with red headers ("Mistake", "Why It's Wrong", "Fix").
- **Table Details**: Rows feature a red 'X' icon in the first column. Alternating light gray background for rows.

### 4. Footer (Full Width, Split into 2 Columns)

#### Left Footer Block: Remember
- **Style**: Light blue outline box.
- **Icon**: Red target icon.
- **Content**: Bold blue title with standard blue text below.

#### Right Footer Block: Interview Golden Rule
- **Style**: Light orange outline box.
- **Icon**: Yellow star icon.
- **Content**: Bold orange title with standard black text below.
