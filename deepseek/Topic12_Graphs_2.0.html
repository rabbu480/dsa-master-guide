💡 WHAT IS A GRAPH?

Graph = Nodes (Vertices) + Edges (Connections).

Models relationships: social networks, roads, dependencies, grids.

Real-world: You + Friends = Nodes. Friendship = Edge.
⚠️ THE VISITED LAW

Graphs may have cycles. Always track visited to avoid infinite loops.

☕ FULL JAVA TEMPLATE
void dfs(int u, List<Integer>[] adj, boolean[] vis) {
    // 1. STOP / invalid
    if (vis[u]) return;
    // 2. MARK
    vis[u] = true;
    // 3. PROCESS
    // ... (count, area, check, etc.)
    // 4. EXPLORE
    for (int v : adj[u]) {
        if (!vis[v]) dfs(v, adj, vis);
    }
}
Time: O(V+E)  |  Space: O(V) (recursion stack)
Iterative DFS (Stack): 
Stack<Integer> st = new Stack<>();
st.push(src);
while (!st.isEmpty()) {
    int u = st.pop();
    if (vis[u]) continue;
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) st.push(v);
}
🚨 COMMON MISTAKES
❌ Forgetting visited
✅ Always mark at start
❌ Marking too late
✅ Mark BEFORE processing
❌ Wrong parent logic in cycle
✅ Pass parent parameter
❌ Infinite recursion
✅ Check visited first
🧠 MEMORY BITE

DFS = STOP → MARK → PROCESS → EXPLORE

public boolean validPath(int n, int[][] edges, int src, int dest) {
    List<Integer>[] adj = new ArrayList[n];
    for (int i=0; i<n; i++) adj[i]=new ArrayList<>();
    for (int[] e : edges) {
        adj[e[0]].add(e[1]);
        adj[e[1]].add(e[0]); // undirected
    }
    boolean[] vis = new boolean[n];
    return dfs(src, dest, adj, vis);
}
boolean dfs(int u, int dest, List<Integer>[] adj, boolean[] vis) {
    if (u == dest) return true;
    vis[u]=true;
    for (int v : adj[u])
        if (!vis[v] && dfs(v, dest, adj, vis)) return true;
    return false;
}

int maxAreaOfIsland(int[][] grid) {
    int max=0;
    for(int r=0; r<grid.length; r++)

int dfsArea(int[][] g, int r, int c) {

☕ FULL JAVA TEMPLATE
void bfs(int src, List<Integer>[] adj, boolean[] vis) {
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(src);
    vis[src] = true; // ⭐ Mark on enqueue
    while (!q.isEmpty()) {
        int u = q.poll();
        // PROCESS u
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.offer(v);
            }
        }
    }
}
Time: O(V+E)  |  Space: O(V)
💡 WHY MARK ON ENQUEUE?

Prevents duplicate enqueue and infinite loops.

✅ Mark BEFORE enqueue
❌ Duplicate enqueue
✅ Check visited before offer
❌ Forget level size
✅ int size = q.size()
❌ Wrong multi-source init
✅ Enqueue ALL sources

4. Multi‑source BFS
PAGE 8/32
🔥 MULTI‑SOURCE BFS

When? Multiple sources start simultaneously (e.g., rotting oranges, fire spread).

Queue<Node> q = new LinkedList<>();
for (Node src : sources) { q.offer(src); visited[src]=true; }
int time = 0;
while (!q.isEmpty()) {
    int size = q.size();   // ⭐ freeze level
    for (int i=0; i<size; i++) {
        Node cur = q.poll();
        for (Node nei : cur.neighbors) {
            if (!visited[nei]) {
                visited[nei] = true;
                q.offer(nei);
            }
        }
    }
    time++; // each level = one time unit
}
💡 TIME‑EVOLUTION TABLE
t=0: [source1, source2]
t=1: [neighbors of source1 + source2]
t=2: [neighbors of neighbors]
...
Each level = one time unit.

int orangesRotting(int[][] grid) {
    // Step 1: Initialize queue with all rotten oranges
    //         Count total fresh oranges
    Queue<int[]> q = new LinkedList<>();
    int fresh = 0;
    for (int r=0; r<grid.length; r++) {
        for (int c=0; c<grid[0].length; c++) {
            if (grid[r][c] == 2) q.offer(new int[]{r,c});
            else if (grid[r][c] == 1) fresh++;
        }
    }

    int time = 0;
    int[][] DIRS = {{0,1},{0,-1},{1,0},{-1,0}};

    // Step 2: BFS level by level (each level = 1 minute)
    while (!q.isEmpty() && fresh > 0) {
        int size = q.size(); // freeze current level
        for (int i=0; i<size; i++) {
            int[] cur = q.poll();
            int r = cur[0], c = cur[1];

            // Check 4 neighbors
            for (int[] d : DIRS) {
                int nr = r + d[0];
                int nc = c + d[1];

                // If neighbor is a fresh orange, rot it
                if (nr>=0 && nr<grid.length && nc>=0 && nc<grid[0].length
                        && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2; // mark as rotten
                    fresh--;
                    q.offer(new int[]{nr, nc});
                }
            }
        }
        time++; // one minute passed
    }

    // Step 3: If fresh oranges remain, return -1
    return fresh == 0 ? time : -1;
}

int countComponents(int n, List<Integer>[] adj) {
    boolean[] vis = new boolean[n];
    int count = 0;
    for (int i=0; i<n; i++) {
        if (!vis[i]) {
            dfs(i, adj, vis); // uses standard DFS template
            count++;
        }
    }
    return count;
}

8. DSU – Why & Template
PAGE 13/32
🧠 WHY DSU?

Problem: Receive edges one by one. Need to know: “Are these nodes already connected?”

DFS/BFS approach → traverse graph repeatedly → expensive.

DSU: Keep track of GROUPS.

🎨 Visual: 
Before:
1     3
│     │
2     4

union(1,3) → After:
    1
   / \
  2   3
      │
      4
parent[] = “Who is my boss?”
rank[] = “How tall is my boss’s tree?”
🔗 DSU TEMPLATE
class DSU {
    int[] parent, rank;

    DSU(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i; // each node is its own parent
        }
    }

    // Find root with path compression
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // Union: merge two sets
    // Returns false if already connected (cycle detected)
    boolean union(int a, int b) {
        int ra = find(a);
        int rb = find(b);

        if (ra == rb) return false; // cycle!

        // Union by rank
        if (rank[ra] < rank[rb]) {
            parent[ra] = rb;
        } else if (rank[ra] > rank[rb]) {
            parent[rb] = ra;
        } else {
            parent[rb] = ra;
            rank[ra]++;
        }
        return true;
    }
}

Complexity: O(α(N)) ≈ O(1) per op.
α(N) = inverse Ackermann (≈ constant).

🚨 COMMON MISTAKES
❌ No path compression
✅ parent[x] = find(parent[x])
❌ Wrong union (no rank)
✅ Union by rank/size
❌ Forgetting to initialize parent
✅ parent[i] = i
🧠 MEMORY BITE

DSU = FIND → UNION

int[] findRedundantConnection(int[][] edges) {
    DSU dsu = new DSU(edges.length + 1);

    for (int[] e : edges) {
        // union returns false if a and b already connected
        if (!dsu.union(e[0], e[1])) {
            return e; // this edge creates a cycle

public int makeConnected(int n, int[][] connections) {
    // Need at least n-1 cables to connect n nodes
    if (connections.length < n-1) return -1;

    DSU dsu = new DSU(n);
    int extra = 0;

    // Count extra cables (connections that create cycles)
    for (int[] e : connections) {
        if (!dsu.union(e[0], e[1])) {
            extra++; // spare cable
        }
    }

    // Count number of connected components
    int comps = 0;
    for (int i = 0; i < n; i++) {
        if (dsu.find(i) == i) comps++;
    }

    // Need (comps - 1) cables to connect all components
    // We have 'extra' spare cables
    return (comps - 1 <= extra) ? comps - 1 : -1;
}

public boolean canFinish(int n, int[][] prereqs) {
    List<Integer>[] adj = new ArrayList[n];
    int[] indegree = new int[n];
    for (int i=0; i<n; i++) adj[i]=new ArrayList<>();

    // Build graph: prereq → course
    for (int[] p : prereqs) {
        adj[p[1]].add(p[0]); // p[1] must be taken before p[0]
        indegree[p[0]]++;
    }

    Queue<Integer> q = new LinkedList<>();
    for (int i=0; i<n; i++) {
        if (indegree[i] == 0) q.offer(i);
    }

    int processed = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        processed++;

        for (int v : adj[u]) {
            if (--indegree[v] == 0) {
                q.offer(v);
            }
        }
    }

    // If we processed all nodes, no cycle → can finish
    return processed == n;
}

10. Dijkstra – Concept & Template
PAGE 18/32
⚡ WHY DIJKSTRA?

BFS fails for weighted graphs — it counts edges, not weights.

Example:

0 ──1── 1
│
2
│
3

BFS would think 0 → 1 is shortest (1 edge), but if weight is 10, it's not.

Dijkstra uses a PriorityQueue to always expand the closest unvisited node.

Requires: Non‑negative edge weights.

Time: O((V+E)logV) | Space: O(V+E)

Pseudo: 
dist[src]=0
pq.add((0,src))
while pq not empty:
    pop (d,u)
    if d > dist[u]: continue
    for each edge (u,v,w):
        if dist[u]+w < dist[v]:
            dist[v]=dist[u]+w
            pq.add((dist[v],v))
☕ DIJKSTRA — FULL JAVA TEMPLATE
int[] dijkstra(int src, List<int[]>[] adj) {
    int n = adj.length;
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE/2);
    dist[src] = 0;

    // Min-heap: [distance, node]
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a,b) -> a[0] - b[0]);
    pq.offer(new int[]{0, src});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];

        // ⭐ Skip stale entries (important!)
        if (d > dist[u]) continue;

        // Relax all outgoing edges
        for (int[] e : adj[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
}
💡 STALE ENTRIES

When we update a node's distance, we may have older entries in the heap.
if (d > dist[u]) continue; ensures we process only the latest best distance.

int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    int INF = Integer.MAX_VALUE/2;
    int[] dist = new int[n];
    Arrays.fill(dist, INF);
    dist[src] = 0;

    // Relax all edges K+1 times
    for (int i = 0; i <= k; i++) {
        int[] prev = dist.clone();
        for (int[] f : flights) {
            int u = f[0], v = f[1], w = f[2];
            if (prev[u] + w < dist[v]) {
                dist[v] = prev[u] + w;
            }
        }
    }
    return dist[dst] == INF ? -1 : dist[dst];
}

🔗 KRUSKAL — FULL JAVA TEMPLATE
int kruskal(int[][] edges, int n) {
    // edges = [weight, u, v]
    Arrays.sort(edges, (a,b) -> a[0] - b[0]);

    DSU dsu = new DSU(n);
    int cost = 0;
    int count = 0;

    for (int[] e : edges) {
        int w = e[0], u = e[1], v = e[2];

        // If u and v are not connected, add this edge
        if (dsu.union(u, v)) {
            cost += w;
            count++;

            // MST has n-1 edges
            if (count == n - 1) break;
        }
    }

    return cost;
}
🌲 PRIM — FULL JAVA TEMPLATE
int prim(List<int[]>[] adj) {
    int n = adj.length;
    boolean[] inMST = new boolean[n];
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a,b)->a[0]-b[0]);
    pq.offer(new int[]{0, 0}); // weight, node
    int cost = 0;
    int count = 0;

    while (!pq.isEmpty() && count < n) {
        int[] cur = pq.poll();
        int w = cur[0], u = cur[1];
        if (inMST[u]) continue;
        inMST[u] = true;
        cost += w;
        count++;

        for (int[] e : adj[u]) {
            int v = e[0], wt = e[1];
            if (!inMST[v]) {
                pq.offer(new int[]{wt, v});
            }
        }
    }
    return cost;
}

int minCostConnectPoints(int[][] points) {
    int n = points.length;
    List<int[]> edges = new ArrayList<>();

    // Build all edges with Manhattan distance as weight
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int dist = Math.abs(points[i][0] - points[j][0])
                     + Math.abs(points[i][1] - points[j][1]);
            edges.add(new int[]{dist, i, j});
        }
    }

    Collections.sort(edges, (a,b) -> a[0] - b[0]);

    DSU dsu = new DSU(n);
    int cost = 0;
    int count = 0;

    for (int[] e : edges) {
        if (dsu.union(e[1], e[2])) {
            cost += e[0];
            if (++count == n - 1) break;
        }
    }
    return cost;
}

public Node cloneGraph(Node node) {

    Map<Node, Node> map = new HashMap<>();

private Node clone(Node node, Map<Node, Node> map) {
    if(map.containsKey(node)) return map.get(node);
    Node copy = new Node(node.val);
    map.put(node, copy);
    for(Node nei : node.neighbors) {
        copy.neighbors.add(clone(nei, map));
    }
    return copy;

Expand from both ends to meet in the middle. 
public int ladderLength(String beginWord, String endWord, List<String> wordList) {
    Set<String> set = new HashSet<>(wordList);
    if(!set.contains(endWord)) return 0;
    Set<String> start = new HashSet<>();
    Set<String> end = new HashSet<>();
    start.add(beginWord); end.add(endWord);
    int len = 1;
    while(!start.isEmpty() && !end.isEmpty()) {
        if(start.size() > end.size()) {
            Set<String> tmp = start; start = end; end = tmp;
        }
        Set<String> next = new HashSet<>();
        for(String word : start) {
            char[] arr = word.toCharArray();
            for(int i=0; i<arr.length; i++) {
                char old = arr[i];
                for(char c='a'; c<='z'; c++) {
                    arr[i] = c;
                    String nw = new String(arr);
                    if(end.contains(nw)) return len+1;
                    if(set.contains(nw)) {
                        set.remove(nw);
                        next.add(nw);
                    }
                }
                arr[i] = old;
            }
        }
        start = next;
        len++;
    }
    return 0;
}

🚨 TOP 5 INTERVIEW KILLERS
  1. Forgetting visited – infinite loops.
  2. Marking visited after dequeue – duplicate enqueue.
  3. Using DFS for shortest path – DFS doesn't guarantee shortest.
  4. Forgetting stale entries in Dijkstra – `if (d > dist[u]) continue;`
  5. Not handling disconnected components – outer loop is essential.
