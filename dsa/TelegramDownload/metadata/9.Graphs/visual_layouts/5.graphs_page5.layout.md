# Visual Layout Specification

## 1. Global Page Structure
- **Document Type**: Portrait-oriented technical reference sheet/infographic.
- **Grid System**: A modular, card-based layout primarily using a 2-column or 3-column split, defined by thin blue border containers.
- **Color Palette**:
  - **Primary Base**: White background.
  - **Headers & Accents**: Dark blue for primary titles and structural numbering blocks; light blue for card header backgrounds.
  - **Callouts & Highlights**: Light yellow/orange backgrounds for tip boxes; dark blue rounded pill shapes for "AHA" insights.
  - **Code Blocks**: Off-white/light-grey background to distinguish code from plain text.
- **Typography**: Sans-serif throughout, utilizing distinct bolding for emphasis, headers, and structural labeling.

## 2. Component Breakdowns

### 2.1 Header Section
- **Top Left**: Rectangular dark blue block containing the page number in white text.
- **Center**: Centralized main title accompanied by an open book icon. Below the main title is a subtitle enclosed in quotes.
- **Alignment**: Center-aligned typography flanked by dotted decorative lines.

## 3. Visual Representation Logic
- **Tables**: Used strictly for structured property mapping (e.g., Input, Caller, Visited, Return) and comparative matrix views. Thin grid lines demarcate cells.
- **Code Blocks**: Designated by distinct pale grey backgrounds and inset padding to emulate an IDE environment.
- **Icons**:
  - *Structural*: Represent graph concepts (nodes, matrices, directional arrows, disconnected graphs).
  - *Contextual*: Signal warnings (red cross), insights (lightbulb), and abstract process flow (gears, documents, clocks).
- **Flowcharts**: Directed arrows clearly map logical progression and decision trees, enforcing a visual hierarchy from problem state to structural representation, and finally to code.
