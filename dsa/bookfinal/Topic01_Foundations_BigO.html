🎬 THE REAL-WORLD STORY

Imagine transferring a 100 GB file across town. Wi-Fi scales linearly with file size (100 GB = 200 min) → O(N). Driving a USB drive takes fixed time regardless of size (100 GB = 30 min) → O(1).

💡 THE BIG-O AHA MOMENT
Big-O notation measures how runtime or memory scales as input size N grows to infinity, ignoring hardware speed differences!
🤔 WHY NOT MEASURE SECONDS?
  • A fast CPU runs bad code quickly on tiny inputs.
  • OS background processes alter millisecond execution timings.
  • Big-O gives a universal mathematical upper bound guaranteed on all FAANG evaluation servers!

📐 THE 3 BIG-O REDUCTION RULES

Rule 1 — Drop Constants: O(2N + 5) → O(N). We care about growth rate, not constant multipliers.

Rule 2 — Drop Non-Dominant Terms: O(N^2 + 100N + 500) → O(N^2). N^2 dominates N as N grows.

Rule 3 — Multi-Variable Rules: Array A size N, Array B size M → O(N + M) for sequential loops, O(N · M) for nested loops!

💡 AUXILIARY SPACE VS CALL STACK
  • Input Space: Memory used to store input data (e.g. array of size N).
  • Auxiliary Space: Extra memory created by your code (DS + call stack).
  • Recursion Call Stack: `factorial(3)` calls `factorial(2)` → Max stack depth 3 => O(N) Auxiliary Space!

💼 COMMON JAVA INTERVIEW BUGS & FIXES

1. Binary Search Mid Overflow:
`int mid = (left + right) / 2;` → ❌ Overflows if `left + right > 2^31 - 1`!
`int mid = left + (right - left) / 2;` → ✅ Safe formula!

2. String Immutability Loop Overhead:
`String s += "a";` in loop → ❌ Recreates string in O(N^2) total time!
`StringBuilder sb = new StringBuilder(); sb.append('a');` → ✅ O(1) amortized!

🔍 THE 4-STEP FAANG DRY RUN METHOD
  1. Pick a Small Concrete Input: Choose a simple test case e.g. `nums = [2, 7, 11]`, `target = 9`.
  2. Create a Variable State Table: Write columns for line numbers, loop counters, pointers, and key data structures.
  3. Step Line-by-Line: Execute code manually step-by-step. Do NOT skip iterations!
  4. Test Edge Cases: Test empty inputs, 1-element arrays, duplicates, and out-of-bounds bounds.
