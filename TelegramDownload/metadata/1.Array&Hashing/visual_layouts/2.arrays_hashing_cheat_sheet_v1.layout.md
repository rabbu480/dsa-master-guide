# Visual Layout Specification: Arrays & Hashing Cheat Sheet

## 1. Global Layout & Theme
*   **Orientation**: Portrait, designed to be read as a single comprehensive poster/cheat sheet.
*   **Grid System**: A 4-column base grid layout structure. Cards span either 1 column or 2 columns to form a masonry-like grid over 4 primary rows.
*   **Typography**: Clean sans-serif font used throughout, with bold weights for headers and key terms, and monospaced font for code snippets.
*   **Color Palette**: 
    *   **Background**: White or very light gray.
    *   **Header Banner**: Deep Navy Blue.
    *   **Card Headers**: Distinct solid colors indicating categories (Navy Blue, Emerald Green, Amethyst Purple, Crimson Red, Tangerine Orange, Teal).

## 2. Header Section
*   **Full Width Banner**: Navy blue background spanning the entire width at the top.
*   **Title**: Large, bold, uppercase white text. A yellow star icon sits to the left.
*   **Subtitle**: Smaller centered text below the main title, with some horizontal decorative lines.

## 3. Main Content Grid (Card-Based Layout)
The main body is composed of individual rectangular cards. Each card has a solid colored header containing a numbered title, followed by a white content area with a thin colored border matching its header.

### Row 1
*   **Card 1 (1 column, Navy Blue Header)**: 
    *   **Visual Structure**: Vertical step-by-step flowchart.
    *   **Content Alignment**: Left-aligned icons, numbered vertically from 1 to 7, each with an associated title and subtitle. Downward arrows connect each step.
*   **Card 2 (1 column, Emerald Green Header)**: 
    *   **Visual Structure**: Two-column list mapping questions to data structures.
    *   **Content Alignment**: Left column contains colored icons and text. Right column contains bold text aligned to the right or center of its sub-column.
*   **Card 3 (2 columns, Amethyst Purple Header)**: 
    *   **Visual Structure**: Tabular format with 4 columns (LC, Problem, Pattern, One-line Memory Trick).
    *   **Row Styling**: Alternating row background colors (light gray and white). Numbers in the 'LC' column are colored green, orange, or red indicating difficulty.

### Row 2
*   **Card 4 (1 column, Crimson Red Header)**: 
    *   **Visual Structure**: Stacked block layout emphasizing key insights ("Aha Moments").
    *   **Content Styling**: Uses pale red highlight blocks for headings (e.g., "Group Anagrams"), followed by code snippets and inline flow diagrams (arrows showing transformations).
*   **Card 5 (1 column, Navy Blue Header)**: 
    *   **Visual Structure**: Two-column quick reference table.
    *   **Content Alignment**: Operations on the left, Big-O complexities on the right.
*   **Card 6 (1 column, Tangerine Orange Header)**: 
    *   **Visual Structure**: Stacked text and code layout.
    *   **Content Styling**: Red bold text for operations ("ADD", "MULTIPLY") surrounded by boxed pseudo-code snippets demonstrating loop structures.
*   **Card 7 (1 column, Teal Header)**: 
    *   **Visual Structure**: Three distinct sections dividing API usage.
    *   **Content Alignment**: Left-aligned bulleted lists (using stylized arrow bullets) categorized under Teal subheaders (HashMap, HashSet, StringBuilder, Arrays).

### Row 3
*   **Card 8 (1 column, Navy Blue Header)**: 
    *   **Visual Structure**: Two-column mapping list.
    *   **Content Alignment**: Left side uses blue text with arrows indicating type conversions (e.g., String -> char[]), right side shows monospaced code.
*   **Card 9 (1 column, Amethyst Purple Header)**: 
    *   **Visual Structure**: Stacked list with purple subheadings.
    *   **Content Alignment**: Each subheading is followed by a single line of monospaced code.
*   **Card 10 (1 column, Emerald Green Header)**: 
    *   **Visual Structure**: Two-column table.
    *   **Content Alignment**: Left column shows data structure, right column shows the use case condition.
*   **Card 11 (1 column, Crimson Red Header)**: 
    *   **Visual Structure**: Bulleted list of text items.
    *   **Content Alignment**: Left-aligned text with prominent green checkmark icons serving as bullet points.

### Row 4
*   **Card 12 (1 column, Tangerine Orange Header)**: 
    *   **Visual Structure**: Bulleted list for common errors.
    *   **Content Alignment**: Left-aligned text with red cross icons serving as bullet points.
*   **Card 13 (1 column, Tangerine Orange Header)**: 
    *   **Visual Structure**: Two-column mapping of cues to actions.
    *   **Content Alignment**: Left column bolded cues mapping to right column actions.
*   **Card 14 (2 columns, Navy Blue Header)**: 
    *   **Visual Structure**: Comprehensive summary table with 4 columns (Approach, Time Complexity, Space Complexity, Example Problems).
    *   **Row Styling**: Alternating background rows for readability.

## 4. Footer Section
*   **Bottom Left**: A dark blue banner containing a sequence of highlighted steps separated by arrows (the "Golden Rule"). Flanked by a gold trophy on the left and a gold star on the right.
*   **Bottom Right**: Simple right-aligned bold text containing a motivational message, ending with a flexed bicep emoji.
