# Visual Layout Specification: Graph Pattern Guide Page 9

## Overall Structure
- **Layout Type:** Multi-column grid with horizontal rows.
- **Background Color:** White.
- **Primary Accents:** Dark Blue, Purple, Dark Green.
- **Alignment:** Center-aligned main titles, left-aligned content blocks.
- **Typography:** Sans-serif fonts, bold headers, monospaced fonts for code blocks.

## Section Breakdown

### 1. Header Section (Full Width)
- **Top Bar:** 
  - Left: "PAGE 9" inside a rounded rectangle (Blue).
  - Center: Book icon followed by "GRAPH PATTERN GUIDE" (Large, Bold, Blue).
- **Subtitle:** "PAGE 9 - TOPOLOGICAL SORT PROBLEM GUIDE (APPLY TEMPLATES)" (Blue, Medium, Bold).
- **Tagline:** "Same algorithm. Different problems. Only the changing parts." (Blue, Italic).
- **Divider:** Two thin blue horizontal lines above and below the subtitle/tagline.

### 2. Instructions & Legend Row (2 Columns)
- **Layout:** Two horizontal panels.
- **Left Panel (How to Use):**
  - **Header:** "HOW TO USE THIS PAGE" (Purple background, white text).
  - **Content:** Numbered list (1-6) with purple circled numbers.
- **Right Panel (Template Legend):**
  - **Header:** "TEMPLATE LEGEND (From Page 8)" (Dark Blue background, white text).
  - **Content:** 4 horizontal items, each with a colored square icon (K in Blue, S in Green, H in Orange, C in Purple) followed by bold text descriptions.

### 3. Problem Cards Grid (3 Columns x 2 Rows)
- **Layout:** 6 rectangular cards arranged in a 3x2 grid. Each card has a similar internal layout.
- **Card Headers:**
  - Numbered 1-6 in a colored square (Left) and a letter icon 'K' or 'S' in a colored square (Right).
  - Title text centered between icons.
  - Colors: Dark Blue for 1, 2, 4, 5, 6. Dark Green for 3.
- **Card Internal Structure:**
  - **Base Template:** Centered, bold text.
  - **Problem:** Left-aligned short sentence.
  - **Changed Lines (from Template):** Code block, syntax highlighted (green comments, blue keywords).
  - **Summary Table:** 3 columns (Caller, Return, Key Idea). No vertical borders, light horizontal dividers.
  - **AHA! Insight:** Light bulb icon + bold text statement (Left-aligned).
  - **Footer (2 Columns):** "Complexity" (Left) and "Interview Tip" (Right), with subtext below each.

### 4. Summary & Reference Blocks (4 Columns)
- **Layout:** 4 distinct blocks of varying widths.
- **Block 7 (Changed Lines Summary):**
  - **Header:** "7 CHANGED LINES SUMMARY" (Purple background, white text).
  - **Content:** 4-column table (Number, Problem, Base Template, Main Change) with alternating light row backgrounds.
- **Block 8 (Topo Sort Template Recap):**
  - **Header:** "8 TOPO SORT TEMPLATE RECAP" (Dark Green background, white text).
  - **Content:** Two sections (Kahn's BFS, DFS + Stack) with bullet points. Small visual diagrams for queues and stacks.
- **Block 9 (Return Type Guide):**
  - **Header:** "9 RETURN TYPE GUIDE" (Dark Blue background, white text).
  - **Content:** 3-column table (Return Type, Use When, Example Problems).
- **Block 10 (Interview Checklist):**
  - **Header:** "10 INTERVIEW CHECKLIST" (Dark Blue background, white text).
  - **Content:** Vertical list of checkbox items with blue checkmarks.

### 5. Flowcharts (Full Width)
- **Block 11 (Interview Thinking Flow):**
  - **Header:** "11 INTERVIEW THINKING FLOW" (Dark Blue background pill shape, white text).
  - **Content:** Horizontal flowchart with arrows connecting nodes: Question mark -> Dependencies -> Graph -> Decision Tree (Need Order?) -> Code -> Test -> Optimize. Includes icons and textual labels.
- **Block 12 (Cheat Pipeline):**
  - **Header:** "CHEAT PIPELINE (INTERVIEW SUCCESS FORMULA)" (Centered, bold text).
  - **Content:** Horizontal sequence of icons with descriptive labels below (Problem -> Input -> Representation -> Helper Structure -> Pattern -> Tiny Logic Change -> Dry Run -> Optimize), connected by right-facing arrows.
