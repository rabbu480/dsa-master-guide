# Visual Layout Specification: Graph Pattern Guide (Page 6)

## 1. Global Document Settings
- **Page Dimensions / Orientation**: Portrait.
- **Background Color**: White (`#FFFFFF`).
- **Primary Color Palette**:
  - Headers & Accents: Navy Blue.
  - Borders & Dividers: Light Blue/Grey.
  - Highlight Bars (AHA): Light Blue background with Dark Blue badge.
  - Text: Dark Grey/Black for main text, Navy Blue for titles.
- **Grid System**: 12-column underlying grid, functionally divided into a 2-column macro layout for the main content body.

## 2. Header Section (Full Spanning)
- **Alignment**: Center-aligned primarily, with a left-aligned badge.
- **Components**:
  - Top Left Badge: "PAGE 6" inside a solid blue rectangle, white text.
  - Main Title: Centered, Large bold sans-serif font (Navy Blue), flanked by decorative book icon.
  - Subtitle: Centered below the main title.
  - Quote: Centered, italicized.
- **Spanning**: 100% width.

## 3. Main Content Blocks (Cards)
All cards feature a consistent header style: Navy Blue background, white text, a numerical index enclosed in a distinct colored square block on the left, and a 5-star rating graphic on the right.

### Block 1: Master Idea
- **Grid Placement**: Top-left, spanning approximately 25% of the page width (3/12 columns).
- **Layout**: Single vertical column with a yellow lightbulb icon at the top left.
- **Visuals**: Left-aligned text snippets separated by generous vertical whitespace.

### Block 2: Graph BFS Template (Adjacency List)
- **Grid Placement**: Top-right, spanning approximately 75% of the page width (9/12 columns).
- **Layout**: 2-column internal split.
  - *Inner Left*: Key-value parameter list with small iconography.
  - *Inner Right*: Code block (Java Template) with syntax highlighting.
- **Footer**: Full-width "AHA" highlight bar (Blue badge + light blue background).

### Blocks 3 & 4: Grid BFS & Multi-Source BFS
- **Grid Placement**: Symmetrical 2-column layout (each spanning 50% / 6 columns).
- **Layout (Internal to both)**: 
  - *Inner Left (30%)*: Key-value metadata with icons.
  - *Inner Right (70%)*: Code block.
- **Footer**: Full-width "AHA" highlight bar in each card.

### Blocks 5 & 6: Level Order & Distance BFS
- **Grid Placement**: Symmetrical 2-column layout directly below Blocks 3 & 4 (each spanning 50% / 6 columns).
- **Layout (Internal to both)**: Matches Blocks 3 & 4 precisely (Metadata left, Code right, AHA bar bottom).

### Blocks 7 & 8: Tables and Guides
- **Grid Placement**: Symmetrical 2-column layout (each spanning 50% / 6 columns).
- **Layout (Block 7)**: Contains a 6-column tabular layout comparing attributes.
- **Layout (Block 8)**: Contains a 4-column tabular layout mapping return types.
- **Visuals**: Both tables use subtle light-gray alternating row backgrounds or simple grid lines. A centered concluding tip with a star icon rests below each table.

### Blocks 9, 10, 11, 12: Footer Cards
- **Grid Placement**: 4-column layout (each spanning roughly 25% / 3 columns).
- **Layout Variations**:
  - *Block 9 (AHA Moments)*: Vertical list with check/lightbulb icons.
  - *Block 10 (Mistakes)*: Vertical list with red cross/warning icons.
  - *Block 11 (Thinking Flow)*: Vertical flowchart diagram with connected nodes.
  - *Block 12 (Preview)*: Icon grid showing future concepts.

## 4. Bottom Footer (Workflow Ribbon)
- **Grid Placement**: Full width (100% span) at the very bottom edge.
- **Layout**: Horizontal flowchart containing 8 steps.
- **Visuals**: Each step consists of a top-aligned icon and a bottom-aligned text label, connected by horizontal right-pointing arrows.

## 5. Typography and Formatting Elements
- **Code Blocks**: Fixed-width (monospace) font, standard keyword syntax highlighting (blue, purple, green).
- **Icons**: Outlined vector style used consistently for metadata keys and workflow steps.
- **Borders**: Each content block is encased in a thin, rounded light-blue border to distinctly separate logical zones.
