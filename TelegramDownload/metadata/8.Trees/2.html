1.1 TREE vs BINARY TREE vs BINARY SEARCH TREE (BST)

TREE

  • A hierarchical structure.
  • Each node can have 0 or more children.
  • No ordering between child nodes.
graph TD style A stroke:#16a34a,fill:white style B stroke:#16a34a,fill:white style C stroke:#16a34a,fill:white style D stroke:#16a34a,fill:white A((1)) --> B((2)) A --> C((3)) A --> D((4))

BINARY TREE

  • Each node has at most 2 children: Left and Right.
  • No ordering between left and right subtree.
graph TD style A stroke:#7e22ce,fill:white style B stroke:#7e22ce,fill:white style C stroke:#7e22ce,fill:white style D stroke:#7e22ce,fill:white style E stroke:#7e22ce,fill:white style F stroke:#7e22ce,fill:white A((1)) --> B((2)) A --> C((3)) B --> D((4)) B --> E((5)) C --> F((6))

BINARY SEARCH TREE (BST)

  • Binary Tree + Left < Root < Right for every node.
  • Inorder traversal gives sorted order.
graph TD style A stroke:#ea580c,fill:white style B stroke:#ea580c,fill:white style C stroke:#ea580c,fill:white style D stroke:#ea580c,fill:white style E stroke:#ea580c,fill:white style F stroke:#ea580c,fill:white A((8)) --> B((3)) A --> C((10)) B --> D((1)) B --> E((6)) C --> F((14))
1.2 TYPES OF BINARY TREES

FULL BINARY TREE

Every node has 0 or 2 children.

graph TD style A stroke:#16a34a,fill:white style B stroke:#16a34a,fill:white style C stroke:#16a34a,fill:white style D stroke:#16a34a,fill:white style E stroke:#16a34a,fill:white style F stroke:#16a34a,fill:white style G stroke:#16a34a,fill:white A((1)) --> B((2)) A --> C((3)) B --> D((4)) B --> E((5)) C --> F((6)) C --> G((7))

COMPLETE BINARY TREE

All levels are completely filled except possibly the last level, and all nodes are as far left as possible.

graph TD style A stroke:#7e22ce,fill:white style B stroke:#7e22ce,fill:white style C stroke:#7e22ce,fill:white style D stroke:#7e22ce,fill:white style E stroke:#7e22ce,fill:white style F stroke:#7e22ce,fill:white A((1)) --> B((2)) A --> C((3)) B --> D((4)) B --> E((5)) C --> F((6))

PERFECT BINARY TREE

All internal nodes have 2 children and all leaves are at the same level.

graph TD style A stroke:#ea580c,fill:white style B stroke:#ea580c,fill:white style C stroke:#ea580c,fill:white style D stroke:#ea580c,fill:white style E stroke:#ea580c,fill:white style F stroke:#ea580c,fill:white style G stroke:#ea580c,fill:white A((1)) --> B((2)) A --> C((3)) B --> D((4)) B --> E((5)) C --> F((6)) C --> G((7))

BALANCED BINARY TREE

For every node, |height(left) - height(right)| ≤ 1

graph TD style A stroke:#0284c7,fill:white style B stroke:#0284c7,fill:white style C stroke:#0284c7,fill:white style D stroke:#0284c7,fill:white style E stroke:#0284c7,fill:white style F stroke:#0284c7,fill:white A((1)) --> B((2)) A --> C((3)) B --> D((4)) C --> E((5)) C --> F((6))

SKEWED BINARY TREE

Every node has only one child.
(Left Skewed or Right Skewed)

graph TD style A stroke:#dc2626,fill:white style B stroke:#dc2626,fill:white style C stroke:#dc2626,fill:white style D stroke:#dc2626,fill:white A((1)) --> B((2)) B --> C((3)) C --> D((4))
or
graph TD style A stroke:#dc2626,fill:white style B stroke:#dc2626,fill:white style C stroke:#dc2626,fill:white style D stroke:#dc2626,fill:white A((1)) --> B((2)) B --> C((3)) C --> D((4))
1.3 KEY TERMINOLOGY
 Node : Basic unit of a tree.
Root : Topmost node of the tree.
Edge : Connection between two nodes.
graph TD A((A)):::highlight --> B((B)) A --> C((C)) classDef highlight stroke:#7e22ce,stroke-width:2px;
Parent : Immediate ancestor of a node.
graph TD A((A)) --> B((B)):::highlight classDef highlight stroke:#7e22ce,stroke-width:2px;
Child : Immediate descendant of a node.
🍃 Leaf Node : Node with no children.
graph TD A(( )) --> B(( )):::highlight B --> C(( )) classDef highlight stroke:#ea580c,stroke-width:2px;
Internal Node : Node with at least one child.
graph TD A((A)) --> B((B)):::highlight A --> C((C)):::highlight classDef highlight stroke:#0284c7,stroke-width:2px;
Siblings : Children of the same parent.
graph TD A((A)) -.-> B((B))
Depth of Node : Number of edges from root to the node.
(Root depth = 0)
graph TD A((A)) --> B((B)) B --> D((D)) A --> C((C)) B --> E((E))
Level of Node : Depth + 1
(Root level = 1)
graph TD A((A)):::highlight --> B((B)):::highlight classDef highlight stroke:#16a34a,stroke-width:2px;
Height of Node : Number of edges on the longest path from the node to a leaf.
graph TD A((A)):::highlight --> B((B)):::highlight classDef highlight stroke:#16a34a,stroke-width:2px;
Height of Tree : Height of the root node.
(Longest path from root to a leaf)
graph LR A((A)):::highlight --> B((B)):::highlight B --> C((C)):::highlight classDef highlight stroke:#7e22ce,stroke-width:2px;
Path : Sequence of nodes connected by edges.

Subtree : A tree formed by a node and its descendants.
