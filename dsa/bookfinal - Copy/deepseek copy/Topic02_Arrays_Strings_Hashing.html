🤔 WHY ARRAYS ALONE FAIL
  • Array Index Access: Fast O(1) if index is known.
  • Array Search by Value: Slow O(N) linear scan required.
  • Array Insertion at Start: Slow O(N) shift of elements!
  • HashMap Solution: Sacrifices space to map Value → Index for O(1) lookups!

🔧 PREFIX SUM UTILITY
class PrefixSum {
    private int[] prefix;

    public PrefixSum(int[] nums) {
        prefix = new int[nums.length + 1];
        // Build prefix array: prefix[i] = sum of nums[0..i-1]
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }

    // Query sum of range [L, R] in O(1) time
    public int query(int L, int R) {
        return prefix[R + 1] - prefix[L];
    }
}

PATTERN 1 — COMPLEMENT HASHING LC 1 · EASY
When to Use: Find two numbers in an unsorted array that add up to a target.
Input: nums=[2,7,11,15], target=9
Output: [0,1]
💡 AHA
For each `num`, store `target - num` in HashMap. When you see it later, you found the pair! 
public int[] twoSum(int[] nums, int target) {
    // Map to store value -> index
    Map<Integer, Integer> map = new HashMap<>();

    // Single pass: O(N) time
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i]; // What number do we need?

        // If complement already seen, we found the pair!
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }

        // Store current number and its index for future lookups
        map.put(nums[i], i);
    }

    return new int[0]; // Should never reach here (problem guarantees solution)
}
PATTERN 2 — HASHSET DUPLICATE DETECTION LC 217 · EASY
When to Use: Check if any value appears at least twice in an array.
Input: [1,2,3,1]
Output: true
💡 AHA
`set.add(num)` returns `false` if the element already exists — instant duplicate detection! 
public boolean containsDuplicate(int[] nums) {
    // HashSet tracks elements we've seen
    Set<Integer> set = new HashSet<>();

    for (int num : nums) {
        // If add() returns false, element already exists → duplicate!
        if (!set.add(num)) {
            return true;
        }
    }

    return false; // No duplicates found
}
PATTERN 3 — CHARACTER FREQUENCY COUNTING LC 242 · EASY
When to Use: Check if two strings are anagrams.
Input: s="anagram", t="nagaram"
Output: true
💡 AHA
Increment for `s`, decrement for `t`. If all counts are 0, they're anagrams! 
public boolean isAnagram(String s, String t) {
    // Must be same length to be anagrams
    if (s.length() != t.length()) return false;

    // Frequency array for 26 lowercase letters
    int[] count = new int[26];

    // One pass: increment for s, decrement for t
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++; // Add from s
        count[t.charAt(i) - 'a']--; // Subtract from t
    }

    // If all counts are zero, strings are anagrams
    for (int c : count) {
        if (c != 0) return false;
    }
    return true;
}

PATTERN 4 — HASHMAP GROUPING LC 49 · MEDIUM
When to Use: Group strings with identical character counts.
Input: ["eat","tea","tan","ate","nat","bat"]
Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
💡 AHA
Sort each string's characters → anagrams become identical keys! 
public List<List<String>> groupAnagrams(String[] strs) {
    // Map: sorted string key -> list of anagrams
    Map<String, List<String>> map = new HashMap<>();

    for (String s : strs) {
        // Convert to char array and sort to get canonical key
        char[] ca = s.toCharArray();
        Arrays.sort(ca);
        String key = String.valueOf(ca);

        // Add current string to its anagram group
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    return new ArrayList<>(map.values());
}
PATTERN 5 — BUCKET SORT FREQUENCY LC 347 · MEDIUM
When to Use: Find Top K most frequent elements in O(N) time.
Input: [1,1,1,2,2,3], k=2
Output: [1,2]
💡 AHA
Bucket index = frequency. Iterate buckets from highest to lowest frequency! 
public int[] topKFrequent(int[] nums, int k) {
    // Step 1: Build frequency map
    Map<Integer, Integer> count = new HashMap<>();
    for (int n : nums) {
        count.put(n, count.getOrDefault(n, 0) + 1);
    }

    // Step 2: Create buckets where index = frequency
    List<Integer>[] bucket = new List[nums.length + 1];
    for (int key : count.keySet()) {
        int freq = count.get(key);
        if (bucket[freq] == null) bucket[freq] = new ArrayList<>();
        bucket[freq].add(key);
    }

    // Step 3: Collect top K from highest frequency buckets
    int[] res = new int[k];
    int idx = 0;
    for (int i = bucket.length - 1; i >= 0 && idx < k; i--) {
        if (bucket[i] != null) {
            for (int num : bucket[i]) {
                res[idx++] = num;
            }
        }
    }
    return res;
}
PATTERN 6 — PREFIX & SUFFIX PRODUCT LC 238 · MEDIUM
When to Use: Calculate product of all elements except self without division.
Input: [1,2,3,4]
Output: [24,12,8,6]
💡 AHA
First pass: left products. Second pass: multiply by right products! 
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];

    // Pass 1: Left products (product of all elements to the left)
    res[0] = 1;
    for (int i = 1; i < n; i++) {
        res[i] = res[i - 1] * nums[i - 1];
    }

    // Pass 2: Right products (multiply by product of all elements to the right)
    int R = 1; // Running product of right elements
    for (int i = n - 1; i >= 0; i--) {
        res[i] *= R;   // Multiply left product with right product
        R *= nums[i];  // Update running product for next iteration
    }

    return res;
}

PATTERN 7 — SEQUENCE START IDENTIFICATION LC 128 · MEDIUM
When to Use: Find longest consecutive sequence in O(N) time.
Input: [100,4,200,1,3,2]
Output: 4
💡 AHA
`num` is the START of a sequence only if `!set.contains(num - 1)`. This guarantees O(N) total time! 
public int longestConsecutive(int[] nums) {
    // Build HashSet for O(1) lookups
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);

    int maxLen = 0;

    // Only start counting from sequence starts
    for (int n : set) {
        // If n-1 exists, n is NOT the start → skip
        if (!set.contains(n - 1)) {
            int curr = n;
            int len = 1;

            // Count consecutive numbers
            while (set.contains(curr + 1)) {
                curr++;
                len++;
            }

            maxLen = Math.max(maxLen, len);
        }
    }

    return maxLen;
}
PATTERN 8 — PREFIX SUM + HASHMAP LC 560 · MEDIUM
When to Use: Count subarrays with sum = K in O(N) time.
Input: [1,1,1], k=2
Output: 2
💡 AHA
`prefixSum - K` seen before → there's a subarray summing to K! 
public int subarraySum(int[] nums, int k) {
    // Map: prefix sum -> frequency
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1); // Empty prefix sum = 0 occurs once

    int sum = 0;
    int count = 0;

    for (int n : nums) {
        sum += n; // Current prefix sum

        // If (sum - k) was seen before, there are subarrays summing to k
        count += map.getOrDefault(sum - k, 0);

        // Record current prefix sum for future lookups
        map.put(sum, map.getOrDefault(sum, 0) + 1);
    }

    return count;
}

⭐ LC 268 · Missing Number EASY
Input: [3,0,1]
Output: 2
Pattern: XOR
public int missingNumber(int[] nums) {
    int res = nums.length; // Start with N

    // XOR cancels pairs: i ^ nums[i] cancels matching numbers
    for (int i = 0; i < nums.length; i++) {
        res ^= i ^ nums[i];
    }
    return res; // XOR of i that had no pair
}

LC 347 · Top K Frequent MEDIUM
Input: [1,1,1,2,2,3], k=2
Output: [1,2]
Pattern: Bucket Sort
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer,Integer> freq = new HashMap<>();
    for (int n : nums) freq.put(n, freq.getOrDefault(n, 0) + 1);

    List<Integer>[] bucket = new List[nums.length + 1];
    for (int key : freq.keySet()) {
        int f = freq.get(key);
        if (bucket[f] == null) bucket[f] = new ArrayList<>();
        bucket[f].add(key);
    }

    int[] res = new int[k];
    int idx = 0;
    for (int i = bucket.length - 1; i >= 0 && idx < k; i--) {
        if (bucket[i] != null) {
            for (int n : bucket[i]) res[idx++] = n;
        }
    }
    return res;
}
LC 128 · Longest Consecutive MEDIUM
Input: [100,4,200,1,3,2]
Output: 4
Pattern: HashSet Start
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);

    int max = 0;
    for (int n : set) {
        if (!set.contains(n - 1)) { // Start of sequence
            int cur = n, len = 1;
            while (set.contains(cur + 1)) { cur++; len++; }
            max = Math.max(max, len);
        }
    }
    return max;
}

⭐ LC 169 · Majority Element MEDIUM
Input: [3,2,3]
Output: 3
Pattern: Boyer-Moore Voting
💡 AHA
Candidate survives cancellation because majority > n/2 → it cannot be eliminated! 
public int majorityElement(int[] nums) {
    int candidate = 0;
    int count = 0;

    // Boyer-Moore Majority Vote Algorithm
    for (int n : nums) {
        if (count == 0) {
            candidate = n; // New candidate
        }
        // Vote: +1 for candidate, -1 against
        count += (n == candidate) ? 1 : -1;
    }

    return candidate; // Guaranteed majority exists
}
⭐ LC 36 · Valid Sudoku MEDIUM
Input: 9×9 board
Output: true/false
Pattern: Row/Col/Box Sets
public boolean isValidSudoku(char[][] board) {
    Set<String> seen = new HashSet<>();

    for (int r = 0; r < 9; r++) {
        for (int c = 0; c < 9; c++) {
            char num = board[r][c];
            if (num == '.') continue;

            // Check row, column, and 3x3 box all at once!
            String rowKey = num + " in row " + r;
            String colKey = num + " in col " + c;
            String boxKey = num + " in box " + (r/3) + (c/3);

            if (!seen.add(rowKey) || !seen.add(colKey) || !seen.add(boxKey)) {
                return false;
            }
        }
    }
    return true;
}
⭐ LC 271 · Encode & Decode Strings MEDIUM

Encoded: "5#Hello5#World"

// Encode: length + "#" + string
public String encode(List<String> strs) {
    StringBuilder sb = new StringBuilder();
    for (String s : strs) {
        sb.append(s.length()).append("#").append(s);
    }
    return sb.toString();
}

// Decode: read length until "#", then extract string
public List<String> decode(String s) {
    List<String> res = new ArrayList<>();
    int i = 0;
    while (i < s.length()) {
        int j = i;
        while (s.charAt(j) != '#') j++; // Find delimiter
        int len = Integer.parseInt(s.substring(i, j));
        res.add(s.substring(j + 1, j + 1 + len));
        i = j + 1 + len;
    }
    return res;
}
⭐ LC 287 · Find Duplicate Number MEDIUM
Input: [1,3,4,2,2]
Output: 2
Pattern: Floyd's Cycle Detection
💡 AHA
Treat array as linked list where `nums[i]` points to next index. Duplicate creates a cycle! 
public int findDuplicate(int[] nums) {
    // Phase 1: Find intersection point of slow and fast
    int slow = nums[0];
    int fast = nums[0];

    do {
        slow = nums[slow];       // Move 1 step
        fast = nums[nums[fast]]; // Move 2 steps
    } while (slow != fast);

    // Phase 2: Find cycle entry (duplicate number)
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[fast];
    }

    return slow;
}

🎤 INTERVIEW DISCUSSION — "WHY NOT SORTING?"

Interviewer: "Why not sort the array first?"

You: "Sorting destroys the original indices. Since we need to return the original positions, we cannot reorder the array. HashMap preserves indices while giving O(1) lookup."

Interviewer: "What if we sort a copy?"

You: "That would take O(N) extra space and O(N log N) time. HashMap is O(N) time and O(N) space — better time complexity."

💼 GOLDEN RULES
Rule 1 — Space-Time Tradeoff
Trading space (O(N) HashMap) for time (O(1) lookups) is the #1 FAANG optimization.
Rule 2 — Frequency Array Over HashMap
For fixed alphabets ('a'-'z'), use `int[26]` instead of HashMap for zero GC overhead.
Rule 3 — Prefix Sum + Map
For subarray sum problems, always think: prefix sum + HashMap to track seen sums.
