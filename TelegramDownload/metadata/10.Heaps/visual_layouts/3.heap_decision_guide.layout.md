# Visual Layout Specification

## Overall Grid & Structure
- **Page Dimensions**: Portrait orientation.
- **Background**: White with distinct separated content blocks.
- **Main Layout Grid**: A predominantly 2-column layout with a full-width header and a full-width footer area.
  - The left column takes up approximately 55-60% of the page width.
  - The right column takes up approximately 40-45% of the page width.
  - Major sections are enclosed in distinct blocks with headers or boundaries.

## Section-by-Section Breakdown

### Header Section (Full Width)
- **Top Row**: 
  - Left: Main title in large, bold, sans-serif font. Color: Dark Blue.
  - Right: Page number badge, white text on dark blue rectangular background with rounded corners.
- **Bottom Row**: Subtitle in smaller font, color: Dark Blue, followed by a thin horizontal line extending to the right edge.

### Left Column
- **Block 1 (Decision Tree)**:
  - **Header**: Dark blue rounded rectangle with white text and a numerical prefix.
  - **Content**: A hierarchical flowchart (tree diagram).
  - **Nodes**: Rectangular boxes with light yellow, light green, and light red backgrounds.
  - **Connectors**: Solid lines with downward-pointing arrows.
  - **Structure**: A single root node branches into 5 main children. The middle child branches into 2 further sub-nodes (diamond-shaped logic nodes), which then branch to terminal action nodes.

- **Block 3 (Complexity Table)**:
  - **Header**: Dark blue rounded rectangle with white text.
  - **Content**: A 4-column data table.
  - **Table Styling**: Light blue background for the header row. Clear, thin gray grid lines separating columns and rows. Text is center-aligned.

- **Block 4 (Key Invariants)**:
  - **Header**: Dark blue rounded rectangle with white text.
  - **Content**: Two side-by-side sub-sections, each enclosed in a bounding box.
    - **Left Box (Min Heap)**: Descriptive text followed by a binary tree diagram. Uses green accent colors (green outlines for node circles, green bottom summary banner).
    - **Right Box (Max Heap)**: Descriptive text followed by a binary tree diagram. Uses red accent colors (red outlines for node circles, red bottom summary banner).

### Right Column
- **Block 2 (Java Templates)**:
  - **Header**: Dark blue rounded rectangle with white text.
  - **Content**: A vertical stack of five distinct sub-blocks.
  - **Block Styling**: Each block features a bold subtitle positioned above a light blue bordered box containing monospaced code structure. Elements of the text feature green coloring to represent code comments.

- **Block 5 (Interview Checklist)**:
  - **Header**: Dark blue rounded rectangle with white text.
  - **Content**: A single-column vertical list. Each line item is prefixed with a square green checkmark icon.

- **Block 6 (Common Mistakes)**:
  - **Header**: Dark blue rounded rectangle with white text.
  - **Content**: A single-column vertical list. Each line item is prefixed with a red cross/X mark icon.

### Bottom Section (Full Width to Split)
- **Block 7 & Triggers (Split Row)**:
  - **Left Area (Aha Moments)**: Vertical bulleted list where each bullet is a yellow star icon.
  - **Right Area (Pattern Recognition Triggers)**: Bounding box with a red circular target icon in the top left corner. Contains a 2-column list of items, each prefixed with a blue right-pointing arrow.
- **Footer**:
  - **Content**: A single, center-aligned rectangular box with a light yellow/gray background and border. A large yellow star icon overlaps the left edge of the box. Contains bold text with a specific phrase underlined in red.

## Typography & Color Palette
- **Primary Text**: Black or dark gray for main content.
- **Headings**: Dark blue for main section titles.
- **Accent Colors**:
  - Dark Blue: Main headers, titles, page badge.
  - Light Blue: Code block borders, table headers.
  - Green: Checkmarks, Min Heap nodes/accents, code comments.
  - Red: Cross marks, Max Heap nodes/accents.
  - Yellow/Gold: Star icons, specific flow chart nodes.
- **Font Families**: Clean, sans-serif fonts for regular text. Monospaced fonts for code-like snippets.

## Alignments & Spacing
- Generous internal padding within all bordered boxes.
- Consistent vertical margin spacing between major blocks.
- List items are left-aligned with a consistent hanging indent for the bullet icons.
- Flowchart elements are symmetrically aligned relative to their parent nodes.
